## 검증 행렬과 완료 경계

실제 제품 검증은 홈·목록·가사·라임·프롬프트·설정·공유·복구를 light/dark와 320/390/768/1024/1440px에서 확인한다. 화면마다 정상·빈 상태·로딩·실패·권한 없음 중 해당 상태를 기록한다. 지원 브라우저/실제 OS·IME·AT·물리 기기의 실행 여부를 구분한다. 브라우저 에뮬레이션을 실기기 통과로 적지 않는다.

원문 손실·인가 우회·무음 저장 실패가 있으면 UI 인수와 출시를 닫지 않는다. 문제를 발견하면 재현·영향·담당·수정 및 회귀 결과를 같은 수용 ID에 연결한다. 1.1.8 보류는 이 보존 검사를 건너뛸 이유가 아니다.
