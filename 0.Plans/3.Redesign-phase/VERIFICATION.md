# 2026-09-22 계획·목업 정리 검증

이 기록은 계획 문서와 선정 목업을 정리한 **당시 작업**의 검증이다. **1.2.0 제품 P1~P5의 구현·통합 CI·서버 인수 결과가 아니다.** 이후 제품 Phase의 실제 완료 증거는 [실행 상태](<../1. Dev-phase/STATUS.md>)와 [P5 기록](1.2.0/5phase.md)에 별도로 남긴다.

## 계획과 보존 검사

- [1.2.0](1.2.0/README.md)의 Phase 문서 5개, 고유 작업 ID 30개를 확인했다. 제품 작업 체크는 모두 미완료 상태다.
- 1.1.8~1.1.14의 README와 Phase 문서 **42개**에 현재 보류 안내가 있고, 기존 **368개 체크리스트 행**과 작업 ID를 원래 Git blob과 대조해 보존했다.
- 변경·신규 Markdown의 상대 링크와 선정 목업 HTML의 로컬 asset 경로가 실제 파일로 연결되는지 확인했다.
- 실행 STATUS의 `current_version`, `current_phase`, `state`는 기존 1.1.7a 완료 값과 같다. 제품 코드·`VERSION`·package/lockfile·migration·보호된 원본 기획/목업은 변경하지 않았다.
- 선정 목업 산출물 24개 해시와 원본 시안 10개 해시를 대조했다. 기존 비공개 시안은 그대로이며, 공개 계획 사본은 비공개 폴더 없이 실행된다.
- 직접 작성한 문서·목업 diff의 공백 오류 검사를 통과했다. GSAP/Draggable 배포본 두 파일의 원본 헤더 공백과 마지막 빈 줄은 출처 해시를 유지하기 위해 그대로 보존한다. 네이티브 계획의 보류는 이전 구현·승인·발행 기록을 삭제하거나 되돌리는 작업이 아니다.

## 독립 검수와 계획 보완

독립 검수에서 현재 [릴리스 Phase 검증기](../../scripts/release-phase-state.mjs)가 `../3.Redesign-phase/1.2.0/1phase.md`를 거부하는 경로 제한을 확인했다. 제품 코드를 이번 계획 작업에 섞지 않고, **P1 완료 CI 전에 최소 도구 지원·버전 metadata 전환·기존 버전 회귀를 수행하도록 [P1-06](1.2.0/1phase.md)에 책임을 명시**했다. P5까지 미뤄 P1 완료 절차가 막히지 않게 한 것이다.

보류된 1.1.8의 선행 작업은 별도 개발선 기록과 로컬 캐시 근거를 구분해 [전환 결정](PLAN-CHANGE.md)에 남겼다. 최신 원격 배포 상태를 확인했다고 주장하지 않는다. 이전 B-1 디자인 승인과 과거 완료 기록도 유지했다.

## 미실행 범위

실제 제품 변경이 없으므로 앱 전체 테스트·생산 이미지 빌드·최종 원격 CI·배포는 이번에 수행하지 않았다. 계획 정리 뒤 2026-09-22 사용자의 후속 커밋·푸시 지시에 따라 검증한 문서·선정 목업을 `codex/1.2.0-redesign-plan`의 커밋·원격 게시 대상으로 묶는다. 문서 커밋은 `[skip ci]`를 사용하며 제품 Phase 착수·완료와 구분한다. 푸시 전 후보 변경 대조는 [Future 인수 기록](../2.Patch-phase/FUTURE-INTAKE.md)에 남긴다.
