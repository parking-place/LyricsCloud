# 0922 리뷰 → 1.2.x 계획 추적표

원 리뷰의 **BE 4 + ES 7 + UI 8 + OPS 3 = 22개 발견**, **M 10개 유지보수 제안**, **UX 24개 여정**, **D 14개 디자인 제안**을 모두 연결한다. 총 **70개 ID**이며 같은 문제의 UX/디자인 표현을 독립 결함으로 중복 집계하지 않는다. [전체 로드맵](ROADMAP.md) · [비교 브랜치 판정](BRANCH-COMPARISON-118-P4.md) · [근거 수준과 gate](QUALITY-GATES.md).

기준은 2026-09-22, `v1.1.7a/fc2463cdb47d9fd7d0042779f602c6ddb7d734cf`. 실제 원문은 사용자 지정 비공개 0922 리뷰로 보존하며 아래에는 비식별 요약·계약만 정리했다. 원본 재현 코드/로그/운영 비밀은 게시하지 않는다. source/새 브랜치 정적 비교와 실제 후보 인수 결과를 구분한다.

## 중복·제외·완료 판정

- ES-05/UI-01은 이탈 상태 계약을 공유하고 ES-06/07은 저장/초기 준비의 서로 다른 실패다. 같은 테스트 하나로 전부 닫지 않는다.
- UI-03/M-09는 요청 세대 계약을 공유한다. M-08은 원인 버전에서 먼저 실패 회귀를 만들고 1.2.8에서 잔여 경계를 인수한다.
- 과거에 해결된 rail 접근성 이름, desktop 중복 tabs, profile override 유지, 사진 export, 삭제 시 공유 회수는 신규 결함으로 등록하지 않는다.
- 비공개 리뷰에서 제안한 이전 B-1 외형 선호보다 최신 사용자 선택인 코발트 Chroma Dock을 우선한다. 기존 기능과 권한/본문 의미는 유지한다.
- 체크 완료는 해결 SHA·같은 입력의 수정 전/후·실제 검증 계층·미실행·최종 개발 인수 근거와 함께 한다. 후속 번호 배정·해결 후보 코드·UI 안내만으로 완료시키지 않는다.
