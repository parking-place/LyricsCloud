# 2026-09-22 — 1.2.0 리디자인 전환 결정

## 승인한 범위

사용자는 **Chroma Dock의 코발트 블루 시안을 3.Redesign-phase에 두고 1.2.0 계획으로 배정하며, 1.1.8 이후 계획을 보류하고 바로 1.2.0으로 넘어간다**고 지시했다. 실제 패치 폴더 이름은 `2.Patch-phase`다. `1.Patch-phhase`라는 별도 중복 폴더는 만들지 않는다.

| 결정 ID | 상태 | 적용 내용 |
|---|---|---|
| `PROD-RD-120-001` | Accepted — 사용자 선택 | Chroma Dock 구조 + 색상 시안 04 Cobalt Blue를 1.2.0 화면 설계의 기준으로 채택. light/dark 및 PC/모바일 포함 |
| `OPS-RD-120-001` | Accepted — 계획 순서·번호 | 1.1.7a 기준 → 1.2.0 리디자인. 1.1.8~1.1.14의 후속 진행은 보류. 이번 한 번의 minor 배정은 사용자 명시 지시에 따른다 |

이 결정은 기존 `PROD-NF-006`의 B-1 디자인 승인·1.1.5~1.1.7 완료 기록을 지우거나 과거 판단을 실패로 바꾸지 않는다. **새 1.2.0의 화면 기준**만 코발트 Chroma Dock으로 지정하며, 이전 기능·권한·저장·복구 의미는 유지한다. 목업의 라이브러리나 시연용 데이터 저장 방식까지 제품 기술 변경으로 승인한 것은 아니다.

## 기준 코드와 별도 개발선

이 계획을 정리한 로컬 기준은 `v1.1.7a`, SHA `fc2463cdb47d9fd7d0042779f602c6ddb7d734cf`다. [1.1.7a 계획](../2.Patch-phase/1.1.7.a/README.md)은 별도 주 개발선의 1.1.8 Windows P4 review를 기록한다. 따라서 이 checkout의 오래된 1.1.8 문서에 남은 “미착수” 문구만으로 다른 개발선의 작업을 없던 것으로 판단하지 않는다.

로컬에 캐시된 `origin/main`의 `b995ffe` 상태 기록에서는 1.1.8 P1~P3 선행 인수가 확인됐다. 이는 이번에 원격 서버의 최신 상태를 조회한 결과가 아니다. 이 계획 변경으로 그 브랜치나 완료 기록을 재작성하지 않는다. 실제 1.2.0 착수·통합 때 담당자가 기준 branch/SHA와 별도 개발선의 차이를 확인하며, 미완료 Windows 코드 전체를 편의상 병합하지 않는다.

## 이번 문서 작업과 다음 구현의 경계

- 이번 변경: 선택 목업의 독립 사본, 1.2.0 다섯 Phase, 수용 기준, 색상 명세, 패치 보류 표시와 진입 문서 연결.
- 실행 상태의 `current_version`, `current_phase`, `state`는 기존 1.1.7a 완료 기록을 유지하고 다음 **계획**만 가리킨다.
- 1.2.0 P1 착수 때 source/작업 경계·필수 인수 목록을 먼저 확인한다. 실제 제품 버전과 runtime 변경은 그 실행 작업에 포함해 검사한다.
- 배포·정식 tag·main 병합은 현재 문서 작업에 포함하지 않는다. 각 Phase 완료와 릴리스는 기존 Agent 및 운영 절차를 따른다.

## 2026-09-22 — 0922 리뷰의 후속 버전 배정과 웹 안정화 비교

사용자가 1.2.0 이후 계획을 1.2.1부터 작성하고 새 `1.1.8 p4 web stabilization` 브랜치와 현재 코드의 비교도 포함하도록 요청했다. [로드맵](ROADMAP.md)은 저장/편집·인증·운영·목록·작성 UX·공유/복구 UX·유지보수의 1.2.1~1.2.8을 배정한다. 상세 설계/호환 선택은 각 실제 P1에서 근거로 확정한다.

| 결정 ID | 상태 | 내용 |
|---|---|---|
| `OPS-RD-12X-001` | Accepted — 사용자 요청에 따른 계획 배정 | 1.2.0 다음에 1.2.1~1.2.8, 기본 5 Phase/편집 1.2.2는 6 Phase. native 1.1.8~1.1.14 보류 유지 |
| `PLAN-RD-12X-COMPARE` | 계획 반영 — 비교 완료, 제품 적용 미승인/미실행 | 원격 head c230c02와 기능 SHA0375825를 고정해 원인 22건·WC18 후보를 비교. 전체 branch 병합 대신 필요한 웹 동작·회귀를 소비 Phase에서 선별 인수 |

이번 배정은 미해결 P1을 뒤 버전에 보관해도 되는 예외가 아니다. [선행 gate](QUALITY-GATES.md)를 1.2.0 P1/P4/P5가 소비하고 필요한 최소 수정의 범위/담당/새 후보 검증을 기록한다. 후속에서는 선해결 증거와 잔여만 인수한다. 현재 실행 1.1.7a·다음 계획1.2.0·선정 코발트 목업·기존 완료/예외 기록은 유지한다. 새로운 원격 후보의 PC 인수는 최신 동일 SHA 원격 개발 인수와 구별한다.

이번 작업은 문서 계획·비교와 그 게시다. 실제 코드 포팅·버전 승격·migration·main 병합·서버 배포는 수행하지 않는다.
