# 0.5.0 Phase 4 — 접근 가능한 순서 변경, 복사·복제와 곡 연결

- 상태: **완료**
- 단계 목적: 모든 입력 방식에서 토큰 순서를 정확히 바꾸고 최종 프롬프트를 곡 작업에 재사용하게 한다.

## 목표

포인터 drag와 앞으로·뒤로 버튼을 함께 제공하고, 동시 순서 변경을 CRDT로 수렴시킨다. 최종 쉼표 문자열 복사, 프롬프트 복제, 곡 연결·해제와 수정 기록을 PC·모바일에서 완성한다.

## 선행조건

- [0.5.0 Phase 3](./3phase.md)의 token builder·자동완성·중복 정리가 완료되어야 한다.
- 정렬 interaction과 focus 복원 방식은 이 Phase의 키보드·touch·screen reader 수용 기준으로 확정하고, [프롬프트 편집 목업](../../Mock-up/09-prompt-editor/README.md)의 비드래그 대안을 포함한다.
- 곡 연결은 0.4.0에서 승인된 owner·cardinality·unlink 규칙을 재사용한다.

- mouse·touch drag와 앞으로·뒤로 버튼 순서 변경
- keyboard focus 유지와 이동 결과 안내
- 최종 쉼표 문자열 preview·전체 복사·실패 대안
- 프롬프트 복제, 핀·즐겨찾기, 수정 기록
- 곡 검색·연결·해제와 연결 상태

- 여러 사용자 공유와 presence
- 가사 cursor에 프롬프트를 삽입하는 기능

## 작업 체크리스트

- [x] **LC-050-P4-01** 포인터 drag가 touch 스크롤과 충돌하지 않고 명확한 handle에서만 시작되게 한다.
- [x] **LC-050-P4-02** 선택 토큰의 앞으로·뒤로 이동과 시작·끝 disabled 상태를 구현한다.
- [x] **LC-050-P4-03** 이동 뒤 focus를 같은 토큰에 유지하고 새 위치를 접근 가능한 문장으로 알린다.
- [x] **LC-050-P4-04** 같은 owner 두 기기의 동시 추가·삭제·이동이 결정적 sequence로 수렴하게 한다.
- [x] **LC-050-P4-05** 중복 정리된 최종 문자열 preview와 전체 복사·clipboard 실패 대안을 구현한다.
- [x] **LC-050-P4-06** 복제 전 중요 수정 기록을 남기고 재시도에도 복사본 하나만 생성한다.
- [x] **LC-050-P4-07** 곡 연결 picker의 로딩·빈 후보·실패·중복·unlink confirm 상태를 구현한다.
- [x] **LC-050-P4-08** 미구현 템플릿 행동을 dead control로 노출하지 않고 0.8.0 인계 계약을 문서화한다.

## 구체적 검증

1. mouse drag, touch drag, 앞으로·뒤로, keyboard만으로 같은 목표 순서를 만들고 직렬화 결과를 비교한다.
2. 첫·마지막 토큰과 토큰 1개·0개 상태에서 이동 버튼이 잘못된 작업을 만들지 않는지 확인한다.
3. 두 기기가 같은 토큰을 이동·삭제할 때 앱이 멈추거나 토큰을 복제하지 않고 최종 수렴하는지 검사한다.
4. 정렬 후 screen reader announcement와 focus 위치가 실제 순서와 일치하는지 확인한다.
5. 복사 허용·거부에서 preview와 clipboard 문자열이 같고 원문에 HTML이 실행되지 않는지 검증한다.
6. 다른 owner 곡 연결, 중복 연결, 연결 중 네트워크 실패와 재시도가 안전한지 테스트한다.

## 완료 조건

- [x] 복사·복제·곡 연결의 정상/오류 상태가 PC·모바일에서 검증되었다.
- [x] 템플릿은 0.8.0 전까지 잘못된 동작으로 노출되지 않는다.
