# 0.5.0 Phase 2 — 프롬프트 목록, 필터와 빠른 재사용

- 상태: **완료**
- 단계 목적: 저장된 스타일 조합을 열지 않고도 찾고 복사하거나 복제하게 한다.

## 목표

08번 목업의 태그형 카드, 제목·토큰·연결 곡 검색, 필터·정렬, 핀·즐겨찾기, 전체 복사·복제를 PC와 모바일에 함께 구현한다. 모바일에는 보이는 복사 버튼을 기본으로 두고 길게 누르기는 보조 행동으로 제공한다.

- [0.5.0 Phase 1](./1phase.md)의 프롬프트 평문·토큰·사용 이력 query가 완료되어야 한다.
- 목록 URL 상태와 공통 카드 패턴은 [0.2.0 Phase 3](../0.2.0/3phase.md)과 [0.4.0 Phase 2](../0.4.0/2phase.md)의 검증된 규칙을 재사용한다.

## 구체적 검증

1. PC와 360·390px 모바일에서 토큰 수가 0개·1개·매우 많은 카드가 깨지지 않는지 확인한다.
2. 제목·토큰·곡 검색과 최근 사용·즐겨찾기 필터를 조합하고 새로고침 뒤 같은 결과가 유지되는지 검사한다.
3. 모바일 목록을 스크롤하는 동안 길게 누르기가 의도치 않게 실행되지 않고, 성공 시 한 번만 복사되는지 확인한다.
4. 보이는 버튼·길게 누르기·수동 복사 대안의 결과가 동일한 쉼표 문자열인지 비교한다.
5. 느린 네트워크에서 복제 버튼을 반복 눌러도 복사본이 하나만 생기는지 확인한다.
6. 다른 owner와 휴지통 자료가 검색 결과·count·자동완성 기반에 나타나지 않는지 통합 테스트한다.
