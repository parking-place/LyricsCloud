## 구체적 검증

1. 실제 Suno 입력에 쓰는 한글·영문 혼합 긴 prompt fixture로 parse·편집·serialize·copy 왕복을 확인한다.
2. 360px 모바일에서 +N으로 숨은 토큰 없이 모두 펼쳐 편집하고 가상 키보드 중 복사 행동에 접근 가능한지 검사한다.
3. touch 스크롤, 길게 누르기, drag가 서로 오작동하지 않는지 실제 모바일 입력 흐름으로 검증한다.
4. 서버 중단·재연결 뒤 token sequence, 평문 preview, 수정 기록과 목록 카드가 일치하는지 확인한다.
5. 다른 owner ID 조작, 중복 복제 요청, 연결 재시도에서 자료 노출·중복 생성이 없는지 테스트한다.
