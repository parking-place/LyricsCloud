# 0.5.0 Phase 3 — 프롬프트 편집기, 자동완성과 중복 정리

- 상태: **대기**
- 단계 목적: 쉼표 입력을 토큰으로 구성하고 과거 표현을 빠르게 재사용하며 중복을 안전하게 정리한다.

## 목표

09번 목업의 신규·편집 프롬프트 제목, 토큰 builder, 쉼표 붙여넣기, owner별 자동완성, 중복 경고·정리를 PC와 모바일에 함께 구현하고 0.3.1 자동 저장 상태를 적용한다.

## 선행조건

- [0.5.0 Phase 2](./2phase.md)의 신규·복제 진입과 목록 복귀 흐름이 완료되어야 한다.
- [0.3.1 릴리즈](../0.3.1/)의 CRDT·IndexedDB·수정 기록 인터페이스를 재사용해야 한다.

## 구체적 검증

1. fem 입력의 자동완성을 키보드·touch로 선택하고 duplicate가 생길 때 경고와 정리 결과를 확인한다.
2. 쉼표 100개가 포함된 붙여넣기, 연속 쉼표, 한글 IME, 앞뒤 공백을 처리해 parser fixture와 같은 토큰이 생성되는지 검사한다.
3. 자동완성 서버 실패와 결과 0건에서 직접 입력을 계속할 수 있고 초안이 손실되지 않는지 확인한다.
4. 같은 owner 두 기기에서 제목과 토큰을 동시에 추가해 화면·CRDT·평문 문자열이 수렴하는지 검증한다.
5. 중복 정리 직전 수정 기록이 남고 undo 또는 기록 복원으로 이전 상태를 회복할 수 있는지 확인한다.
6. 390px 모바일에서 모든 토큰이 펼침을 통해 편집 가능하고 +N 표시에 숨은 삭제 불가 토큰이 생기지 않는지 시각 점검한다.

## 완료 조건

- [ ] 신규·복제·편집 mode와 validation이 PC·모바일에서 동작한다.
- [ ] 입력·붙여넣기·자동완성·중복 정리 결과가 데이터 계약과 일치한다.
- [ ] 숨겨져 편집할 수 없는 모바일 토큰이 없다.
- [ ] 자동 저장·오프라인·동시 편집 회귀가 통과한다.
