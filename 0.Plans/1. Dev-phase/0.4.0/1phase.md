# 0.4.0 Phase 1 — 라임 노트 도메인과 소유권 기반

- 상태: **로컬 완료 · 원격/개발 인수 대기**
- 단계 목적: 라임 노트, 사용자 태그, 곡 연결과 공통 표시 속성의 데이터 계약을 만든다.

## 목표

자유 형식 라임 노트를 owner별로 안전하게 저장하고 제목·본문·태그·핀·즐겨찾기·색상·곡 연결을 목록과 편집기에서 일관되게 사용할 기반을 구현한다.

## 선행조건

- [0.3.1 릴리즈](../0.3.1/)의 CRDT 어댑터, IndexedDB 초안, 평문 투영과 수정 기록 계약이 완료되어야 한다.
- 인증·DB·migration은 [아키텍처 ADR](../../../docs/adr/README.md)의 `ADR-0002`·`ADR-0003`을 따르고, 곡 연결 cardinality는 [결정 권한표](../Decision-Ownership.md)의 `PROD-0002`가 승인되어야 한다.
- 세부 ORM, CRDT 자료형, UI 패키지는 승인된 ADR 없이 임의 확정하지 않는다.

## 작업 체크리스트

- [x] **LC-040-P1-01** 라임 노트 제목·본문·공통 표시 속성의 schema와 길이 제한을 정의한다.
- [x] **LC-040-P1-02** 사용자별 태그의 표시 값·검색 정규화 값·중복 기준을 정의한다.
- [x] **LC-040-P1-03** 라임 노트와 태그 연결에 owner가 다른 행이 섞이지 않도록 무결성 제약을 구현한다.
- [x] **LC-040-P1-04** 곡 연결·연결 해제와 자료 자체 삭제를 구분하는 데이터 작업을 구현한다.

- [x] **LC-040-P1-06** 라임 본문을 0.3.1 CRDT와 IndexedDB 초안·평문 projector에 연결한다.
- [x] **LC-040-P1-07** 생성·복제·재시도에 중복 자료가 생기지 않는 요청 식별 규칙을 적용한다.
- [x] **LC-040-P1-08** soft delete 자료를 기본 목록·필터·연결 후보에서 제외한다.

## 구체적 검증

1. A 사용자의 노트에 B 사용자의 태그나 곡 ID를 연결하려는 요청이 거부되는지 DB 통합 테스트한다.
2. 같은 태그를 공백·대소문자·Unicode 표현만 바꿔 추가할 때 승인된 중복 규칙이 적용되는지 확인한다.
3. 곡 연결 해제가 라임 노트 본문과 다른 곡 연결을 삭제하지 않는지 검사한다.
4. 같은 생성 요청을 재전송해도 노트가 하나만 생성되는지 확인한다.
5. 삭제된 노트와 태그가 일반 조회·연결 후보·평문 투영에서 노출되지 않는지 확인한다.
