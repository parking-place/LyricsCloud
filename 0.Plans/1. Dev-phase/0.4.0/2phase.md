# 0.4.0 Phase 2 — 라임 노트 목록, 필터와 빠른 복사

- 상태: **대기**
- 단계 목적: 라임과 표현을 PC·모바일에서 빠르게 찾고 열거나 복사하게 한다.

## 목표

06번 목업의 검색, 태그·연결 곡 필터, 정렬, 카드 정보, 핀·즐겨찾기와 보이는 복사 행동을 PC와 모바일에 동시에 구현하고 정상·빈·오류 상태를 완성한다.

## 선행조건

- [0.4.0 Phase 1](./1phase.md)의 라임 노트·태그·곡 연결 데이터 작업이 완료되어야 한다.
- 목록 pagination과 URL 상태 방식은 [0.2.0 Phase 3](../0.2.0/3phase.md)의 곡 목록 계약을 기본으로 재사용하고, 라임에 필요한 차이는 이 Phase에서 명시한다.
- 클립보드 실패 시 수동 복사 대안 규칙이 준비되어야 한다.

## 포함 범위

- 제목·본문의 라임 목록 검색
- 태그·연결 곡 필터와 최근 수정 정렬
- 제목, 본문 일부, 태그, 곡, 시각, 핀·즐겨찾기·색상 카드
- 전체 노트 복사와 성공·실패 안내
- PC 2열, 모바일 1열과 가로 필터

## 제외 범위

- 앱 전체 통합 검색
- 가사 cursor 삽입
- 고급 발음·유사 라임 검색
- 여러 사용자 자료와 공유 컬렉션

## 작업 체크리스트

- [ ] **LC-040-P2-01** PC 2열과 모바일 1열 목록을 같은 데이터 계약으로 구현한다.
- [ ] **LC-040-P2-02** 제목·본문 검색과 태그·연결 곡 필터를 조합 가능하게 구현한다.
- [ ] **LC-040-P2-03** 검색·필터·정렬 값을 URL에 보존하고 잘못된 값은 안전하게 초기화한다.
- [ ] **LC-040-P2-04** 핀·즐겨찾기·색상을 색만이 아닌 이름과 접근 가능한 상태로 표시한다.
- [ ] **LC-040-P2-05** 카드 전체 복사 버튼을 PC·모바일에 제공하고 실제 원문만 복사한다.
- [ ] **LC-040-P2-06** 로딩, 최초 빈 화면, 검색 결과 없음, 요청 실패·재시도 화면을 구현한다.
- [ ] **LC-040-P2-07** 모바일 필터 chip을 실제 가로 스크롤과 키보드 초점 이동이 가능하게 구현한다.
- [ ] **LC-040-P2-08** 카드 열기, 핀·별 토글, 복사가 서로 오동작하지 않도록 독립 hit target을 제공한다.

## 구체적 검증

1. PC와 360·390px 모바일에서 검색·태그·곡 필터를 조합하고 새로고침 후 같은 결과가 유지되는지 확인한다.
2. 본문이 긴 노트, 태그가 많은 노트, 연결 곡이 없는 노트 카드가 겹치거나 중요한 행동을 가리지 않는지 시각 점검한다.
3. 결과 0건과 자료 0건이 서로 다른 문구와 다음 행동을 제공하는지 확인한다.
4. 클립보드 허용·거부·비보안 환경 모의 조건에서 성공 toast 또는 선택 가능한 수동 복사 대안이 나타나는지 검사한다.
5. 다른 owner와 휴지통 자료가 검색·필터 count·복사 응답에 포함되지 않는지 통합 테스트한다.
6. 모바일 스크롤 중 카드가 의도치 않게 복사되거나 열리지 않는지 실제 터치 흐름으로 확인한다.

## 완료 조건

- [ ] 목록·검색·필터·정렬이 PC·모바일에서 같은 결과를 낸다.
- [ ] 빈 화면·무결과·로딩·실패·복사 성공/실패 상태가 구현되었다.
- [ ] 핀·별·색상과 복사 행동을 키보드와 보조 기술로 구분할 수 있다.
- [ ] owner와 휴지통 격리 테스트가 통과한다.
