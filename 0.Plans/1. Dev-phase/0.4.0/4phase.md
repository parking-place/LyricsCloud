# 0.4.0 Phase 4 — 태그·곡 연결, 선택 복사와 삽입 계약

- 상태: **진행 중**
- 단계 목적: 라임을 분류·연결하고 전체 또는 선택 표현을 안전하게 재사용할 수 있게 한다.

## 목표

사용자 태그와 곡 연결의 생성·해제·필터 반영을 완성하고, 노트 전체 및 선택 영역 복사를 PC·모바일에서 제공한다. 가사 cursor 직접 삽입은 0.6.0에서 구현할 수 있도록 target·payload 계약만 확정한다.

## 선행조건

- [0.4.0 Phase 3](./3phase.md)의 라임 편집기와 저장 상태가 완료되어야 한다.
- 곡 연결 cardinality·unlink 의미는 [결정 권한표](../Decision-Ownership.md)의 `PROD-0002`, 자료 삭제·복원 의미는 `PROD-0010`의 승인 기록을 따른다.
- 선택 텍스트는 CRDT 위치 변화에 안전한 표현 방식으로 전달되어야 한다.

- 태그 추가·삭제·필터 이동
- 곡 검색·연결·해제와 연결 상태 표시
- 전체 본문·선택 영역 복사와 수동 복사 대안

- 다른 사용자 곡과 연결
- 태그 자동 생성·라임 추천
- 통합 검색 인덱스와 템플릿

## 작업 체크리스트

- [ ] **LC-040-P4-01** 태그 추가·삭제 후 목록 count와 활성 필터가 예측 가능하게 갱신되게 한다.
- [ ] **LC-040-P4-02** 곡 검색·연결·해제 UI에 로딩·빈 후보·실패·중복 연결 상태를 구현한다.
- [ ] **LC-040-P4-03** unlink가 노트 또는 곡을 삭제하지 않으며 여러 연결 중 선택한 관계만 제거하게 한다.
- [ ] **LC-040-P4-04** 전체 복사와 현재 선택 영역 복사를 명확히 구분하고 빈 선택 상태를 안내한다.
- [ ] **LC-040-P4-05** 모바일 긴 누르기 선택과 시스템 selection을 방해하지 않는 복사 행동을 제공한다.
- [ ] **LC-040-P4-06** 클립보드 실패 시 내용이 보이는 수동 복사 modal/sheet를 제공한다.
- [ ] **LC-040-P4-07** 가사 resource ID, CRDT 상대 위치, 삽입할 순수 텍스트를 담는 0.6.0 삽입 요청 계약을 문서화한다.
- [ ] **LC-040-P4-08** 열린 가사 target이 없거나 삭제·변경된 경우 삽입 불가 상태와 복사 대안을 정의한다.

## 구체적 검증

1. 태그를 생성·삭제하고 해당 태그 필터로 왕복할 때 count와 URL 상태가 일치하는지 확인한다.
2. 한 노트를 여러 곡에 연결·해제하는 승인 시나리오와 다른 owner 곡 연결 거부를 검사한다.
3. 한글·영문·줄바꿈이 섞인 전체 및 선택 텍스트가 공백 손상 없이 복사되는지 확인한다.
4. 선택 없음, 클립보드 거부, 오래된 selection, 문서가 원격 변경된 상태의 안내를 PC·모바일에서 검증한다.
5. 연결 요청 중 네트워크 오류와 재시도가 중복 관계를 만들지 않는지 확인한다.
6. 0.6.0 소비자가 mock 객체로 삽입 요청 계약을 처리하고 target 없음 오류를 구분할 수 있는지 계약 테스트한다.

## 완료 조건

- [ ] 태그와 곡 연결이 목록·편집 화면에서 일관되게 동작한다.
- [ ] 전체·선택 복사와 실패 대안이 PC·모바일에서 검증되었다.
- [ ] 연결 해제와 삭제가 혼동되지 않는다.
- [ ] 0.6.0 cursor 삽입용 계약과 오류 상태가 확정되었다.
