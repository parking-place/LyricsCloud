# 1.0.0 Phase 4 — 사용자·셀프호스트·운영 문서 인계

- 상태: **대기**
- 단계 목적: 개발자 없이도 설치·사용·백업·복구·업그레이드·장애 대응이 가능하게 한다.

## 목표

사용자 도움말, Docker 셀프호스팅 안내, 구성·보안·백업·복원·업그레이드·롤백·관측 runbook과 데이터 내보내기/탈퇴 안내를 실제 절차에 맞춰 최종화한다.

## 선행조건

- [1.0.0 Phase 3](./3phase.md)의 실제 프로덕션 구성과 배포 결과가 확정되어야 한다.
- 모든 문서는 승인된 [0.0.0 ADR 산출물](../0.0.0/)과 실제 release manifest만 설명해야 한다.
- 문서 예제에는 실사용 secret, 도메인, 계정, backup 경로와 창작물을 포함하지 않는다.

- 검증하지 않은 명령이나 복구 약속

## 구체적 검증

1. 프로젝트 경험이 없는 검토자가 README와 runbook만 보고 빈 환경을 설치하고 smoke까지 수행한다.
2. 다른 검토자가 backup 하나를 복원하고 사용자 격리·검색·가사 편집을 확인한다.
3. 문서의 모든 내부 링크, 명령, 파일 경로와 환경 변수 이름을 자동 검사한다.
4. repository 문서·예제에서 secret/토큰/실사용 데이터 pattern을 scan한다.
5. 사용자 도움말의 메뉴·버튼 이름이 15개 최종 화면과 일치하는지 대조한다.
6. 정책 기간과 선택값이 DEC-08-A~13-A와 정확히 일치하는지 확인한다.

## 완료 조건

- [ ] 신규 운영자가 문서만으로 설치·upgrade·rollback·restore를 재현했다.
- [ ] 사용자 도움말이 15개 화면과 확정 정책을 정확히 설명한다.
- [ ] 문서의 깨진 링크·명령 오류·secret·실사용 창작물이 0건이다.
- [ ] 운영 책임자에게 경보·runbook·복구 증적이 인계되었다.
