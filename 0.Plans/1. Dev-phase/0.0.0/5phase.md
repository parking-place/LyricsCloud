## 검증 방법

- 새 임시 작업 사본에서 문서의 명령을 그대로 실행해 재현성을 확인한다.
- 잘못된 설정, DB 중단, 읽기 전용 볼륨 사례에서 오류가 원인별로 구분되는지 확인한다.
- 의존성 목록을 Accepted ADR의 승인 목록과 비교한다.
- Git 추적 목록에 `.env`, DB volume, backup, export, 로그가 없고 원본 기획과 Phase 문서가 포함되는지 확인한다.
- PC·모바일 smoke 화면을 캡처해 레이아웃 기준과 대조한다.
- 보안 점검 결과에 발견 위치, 영향, 조치 여부가 모두 기록됐는지 확인한다.

- [x] 0.1.0에 차단 없이 진입 가능하다는 검토 결과가 남았다.
