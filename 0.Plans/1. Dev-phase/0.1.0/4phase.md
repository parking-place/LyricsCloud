# 0.1.0 Phase 4 — 01 로그인 화면과 공통 반응형 셸

- 상태: **검토 중**
- 버전 상태: [../STATUS.md](../STATUS.md)

## 목표

01-auth 목업을 실제 Google 인증 흐름에 연결하고, 처음 구현하는 순간부터 PC와 모바일을 함께 지원한다. 로그인 이후에는 이후 버전의 화면을 담을 공통 PC·모바일 셸을 접근 가능한 구조로 제공한다.

## 선행조건

- 0.0.0의 관련 ADR이 모두 Accepted 상태이며 이 Phase는 승인 결과를 따라야 한다.
- 0.1.0 Phase 2의 Google 인증 흐름이 동작해야 한다.
- 0.1.0 Phase 3의 보호 route와 profile 조회가 동작해야 한다.
- 공통 디자인 토큰과 breakpoint가 준비되어야 한다.

## 포함 범위

- PC 로그인 소개 영역과 단일 Google 로그인 카드
- 모바일 한 열 로그인 화면과 엄지 영역의 큰 로그인 버튼
- 기본, 인증 진행, 취소·실패, 허용되지 않은 계정 상태
- 로그인 유지와 여러 기기 작업 안내
- 이용 안내·개인정보 안내의 명확한 링크와 현재 정책 버전 표시
- 키보드 focus, 상태 알림, 오류 재시도
- 인증 후 PC의 상단 창작 탭·접이식 좌측 메뉴 골격
- 모바일 header·하단 주요 탭·빠른 추가 자리
- 아직 구현되지 않은 route를 실제 기능처럼 보이지 않게 표시

## 제외 범위

- 곡 카드와 곡 작성
- 실제 빠른 추가 메뉴
- 설정 화면과 회원 탈퇴
- 어두운 테마 선택 UI
- CRDT·동기화 상태 UI

## 작업 체크리스트

- [x] LC-010-P4-01 — 1440px PC 화면에 제품 설명, 창작 흐름, 로그인 카드를 목업 계층대로 배치한다.
- [x] LC-010-P4-02 — 390×844 모바일 화면에 로고, 핵심 설명, 동기화 안내, 로그인 행동을 한 열로 배치한다.
- [x] LC-010-P4-03 — Google 로그인 버튼을 로그인 시작 경로와 연결하고 중복 클릭을 진행 중 상태로 막는다.
- [x] LC-010-P4-04 — 인증 취소, 네트워크 실패, 초대되지 않은 계정에 각각 이해 가능한 문장과 재시도를 제공한다.
- [x] LC-010-P4-05 — 로그인 완료 안내를 스크린리더가 읽도록 상태 영역을 제공하고 focus를 다음 화면 제목으로 옮긴다.
- [x] LC-010-P4-06 — PC 셸의 창작 탭, 좌측 메뉴 접기·펼치기, profile·로그아웃 위치를 키보드로 사용할 수 있게 한다.
- [x] LC-010-P4-07 — 모바일 셸의 header, 하단 탭, safe-area, 빠른 추가 자리를 가상 키보드와 겹치지 않게 만든다.
- [x] LC-010-P4-08 — 공개 로그인 route와 인증 후 셸이 서로의 navigation·개인 내용을 캐시하지 않게 한다.
- [x] LC-010-P4-09 — 미구현 route는 비활성 상태와 예정 문구를 표시하고 빈 링크나 무반응 버튼을 두지 않는다.
- [x] LC-010-P4-10 — 320px부터 1440px까지 수평 overflow와 잘린 버튼이 없는지 확인한다.
- [x] LC-010-P4-11 — 로그인 전에 이용·개인정보 안내를 키보드와 모바일에서 열고 원래 인증 화면으로 돌아올 수 있게 한다.

## 검증 방법

- PC 1440px과 모바일 390×844에서 목업과 나란히 시각 비교한다.
- 키보드만으로 로그인, 재시도, 메뉴 접기, 로그아웃까지 이동한다.
- 스크린리더로 진행·실패·완료 상태가 중복 없이 읽히는지 확인한다.
- 느린 네트워크에서 로그인 버튼이 여러 요청을 만들지 않는지 확인한다.
- iOS Safari와 Android Chrome 기준 safe-area와 큰 글자 설정에서 버튼이 가려지지 않는지 확인한다.
- 인증된 페이지를 로그아웃 후 뒤로 가기로 열어도 개인 셸이 다시 표시되지 않는지 확인한다.
- 이용·개인정보 링크가 빈 경로나 임시 `#`가 아니며 새 창을 쓰는 경우에도 안전한 관계 속성과 접근 가능한 이름이 있는지 확인한다.

## 완료 조건

- [x] 01-auth의 PC·모바일 화면이 같은 Phase에서 완성됐다.
- [x] 기본·진행·실패 상태가 실제 인증 결과와 연결됐다.
- [x] 키보드와 스크린리더로 주요 행동을 수행할 수 있다.
- [x] 보호 셸의 PC·모바일 navigation 골격이 동작한다.
- [x] 미구현 기능이 동작하는 것처럼 표시되지 않는다.
- [x] 인증 화면과 개인 화면의 캐시 경계가 지켜진다.
- [x] 로그인 전 이용·개인정보 안내에 실제로 접근할 수 있다.
