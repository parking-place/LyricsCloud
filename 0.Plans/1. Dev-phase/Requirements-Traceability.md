## 기능 요구사항 추적

아래 71개 ID는 [`Sketch.md` 49절](../Sketch.md)의 글머리를 원문 순서대로 1:1 분해한 기준선입니다. 승인 후에는 ID를 다른 의미에 재사용하지 않으며, 범위가 바뀌면 기존 행을 남기고 상태·결정 기록·대체 ID를 연결합니다. "최초 구현·확장"은 기능이 처음 작동하는 Phase와 후속 통합 시점을, "주 검증·완료 증거"는 해당 요구사항을 직접 닫는 Phase를 뜻합니다. 모든 행은 [1.0.0 Phase 1](./1.0.0/1phase.md)에서 증거를 전수 확인하고 [Phase 5](./1.0.0/5phase.md)에서 최종 재검증합니다.
