# 0.3.1 Phase 2 — IndexedDB 온라인 우선 초안과 탭 병합

- 상태: **대기**
- 단계 목적: 네트워크 상태와 관계없이 입력을 먼저 로컬에 보존하고 같은 계정의 여러 탭을 자동 병합한다.

## 목표

가사 편집 입력을 메모리와 IndexedDB에 즉시 보존하고, 연결 가능할 때 서버와 동기화하는 온라인 우선 흐름을 PC와 모바일에 함께 구현한다. 같은 브라우저의 여러 탭은 동일 owner 문서로 수렴하며 로그아웃 후 다른 계정에 초안이 노출되지 않아야 한다.

## 선행조건

- [0.3.1 Phase 1](./1phase.md)의 CRDT 문서·업데이트·소유권 계약이 완료되어야 한다.
- IndexedDB 구조와 탭 통신 방식은 [0.0.0 ADR 산출물](../0.0.0/)에서 승인된 선택을 따른다.
- 가사 편집기의 입력 transaction·한글 IME 처리 계약이 준비되어야 한다.

## 포함 범위

- 메모리·IndexedDB의 최신 CRDT 상태와 미전송 업데이트 큐
- 온라인 우선 초기 로드, 열린 앱의 오프라인 편집, 온라인 재진입과 재연결 재전송
- 같은 owner·문서의 여러 탭 자동 병합과 중복 편집 표시
- 변경 있음, 로컬 저장, 동기화 중, 서버 저장, 오프라인, 재시도 상태
- PC 편집기와 모바일 편집기에서 동일한 데이터 안전 규칙

## 제외 범위

- 모든 목록과 자료를 완전 오프라인으로 탐색하는 기능
- 네트워크가 없는 cold start·새로고침: 정적 앱 셸 service worker가 추가되는 0.9.0에서 검증
- 다른 사용자와 문서를 공유하거나 presence를 표시하는 기능
- 서비스 워커가 인증된 창작물 응답을 캐시하는 방식
- 서버 스냅샷 압축과 수정 기록 생성

## 작업 체크리스트

- [ ] **LC-031-P2-01** owner·문서별 IndexedDB 저장소와 schema version 전환 규칙을 구현한다.
- [ ] **LC-031-P2-02** 입력 transaction 직후 로컬 상태와 미전송 큐를 원자적으로 기록한다.
- [ ] **LC-031-P2-03** 초기 진입 시 서버본과 로컬 미전송 업데이트를 순서에 의존하지 않고 병합한다.
- [ ] **LC-031-P2-04** 같은 문서를 연 두 탭이 승인된 탭 통신 방식으로 변경을 교환하고 중복 적용하지 않게 한다.
- [ ] **LC-031-P2-05** 연결 끊김·재연결·지수형 재시도와 명시적 다시 시도 행동을 구현한다.
- [ ] **LC-031-P2-06** PC·모바일에 저장 중, 이 기기에 임시 저장됨, 동기화 중, 서버에 저장됨, 저장 실패 상태를 구현한다.
- [ ] **LC-031-P2-07** 한글 IME 조합 중간 상태를 확정 업데이트로 잘못 기록하지 않게 한다.
- [ ] **LC-031-P2-08** 로그아웃·계정 전환·탈퇴 시작 시 해당 owner의 로컬 초안과 캐시를 안전하게 제거한다.

## 구체적 검증

1. PC와 390px 모바일에서 열린 편집기에 입력한 직후 네트워크를 끊고 계속 편집한 다음, 연결 복구 후 새로고침해도 마지막 확정 입력이 복구되는지 E2E로 확인한다.
2. 같은 브라우저 두 탭에서 같은 줄과 다른 줄을 교차 편집해 두 탭이 자동으로 같은 본문에 수렴하는지 확인한다.
3. 오프라인 중 앱을 닫은 뒤 네트워크를 복구해 다시 열고 IndexedDB 초안을 서버와 병합했을 때 업데이트 누락·중복이 없는지 검사한다.
4. 저장 요청 실패와 재시도 중 화면 문구가 실제 로컬·서버 상태를 거짓으로 표시하지 않는지 상태 전이 테스트한다.
5. 한글 조합, 대량 붙여넣기, 선택 삭제, 모바일 화면 회전 중 초안 손실이 없는지 확인한다.
6. A 계정 로그아웃 후 B 계정 로그인 시 A의 제목·본문·미전송 수량이 노출되지 않는지 검사한다.

## 완료 조건

- [ ] 입력 직후 로컬 보존과 재연결 동기화가 PC·모바일에서 통과한다.
- [ ] 같은 owner의 여러 탭이 수동 충돌 선택 없이 같은 상태로 수렴한다.
- [ ] 모든 저장 상태가 실제 영속화 수준과 일치한다.
- [ ] 계정 경계와 한글 IME 회귀 테스트가 통과한다.
- [ ] 오프라인 cold start를 완료 기능처럼 표시하지 않고 0.9.0 PWA 검증으로 추적한다.

- 탭 병합 어댑터와 저장 상태 컴포넌트
- PC·모바일 오프라인/IME/계정 격리 테스트
