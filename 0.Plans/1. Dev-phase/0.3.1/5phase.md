# 0.3.1 Phase 5 — 다중 탭·기기 동기화 통합 검증과 릴리즈

- 상태: **로컬 검증 review — 실제 기기·원격 선행 검증 대기는 STATUS.md 참조**
- 단계 목적: 동일 사용자의 자동 병합과 복구 체계를 실제 장애 조건에서 검증해 후속 자료 편집기에 제공한다.

## 목표

IndexedDB 초안, 여러 탭·기기 CRDT 병합, 서버 영속화, 평문 투영, 자동 저장 상태, 수정 기록·비교·복원을 하나의 회귀 묶음으로 검증하고 0.3.1 릴리즈 증적을 남긴다.

## 선행조건

- [0.3.1 Phase 1](./1phase.md)부터 [Phase 4](./4phase.md)까지 완료되어야 한다.
- 로컬·테스트 환경의 동기화 서버와 PostgreSQL 구성이 [0.0.0 ADR 산출물](../0.0.0/)로 재현 가능해야 한다.
- 여러 사용자 공유가 아닌 동일 owner 동기화만 승인 범위임을 확인해야 한다.

## 구체적 검증

1. 서로 다른 네트워크의 PC·모바일에서 같은 가사의 같은 문장과 다른 문장을 수정해 모든 복제본이 수렴하는지 확인한다.
2. 클라이언트 확인 응답, 서버 저장, 평문 투영 각 지점에서 장애를 주입하고 재시도 후 손실·중복을 검사한다.
3. 브라우저 강제 종료 뒤 IndexedDB 초안으로 복구하고 서버본과 자동 병합되는지 확인한다.
4. 복원 직후 오프라인 기기가 과거 업데이트를 전송해도 무음으로 복원 결과를 잃지 않고 CRDT 규칙대로 수렴하는지 확인한다.
5. 360px 모바일과 일반 PC에서 저장 중·로컬 임시 저장·재시도·완료 문구가 잘리거나 겹치지 않는지 점검한다.
6. 동기화 지연, 스냅샷 크기, projector 지연을 기록하되 창작물 본문이 증적과 로그에 포함되지 않는지 검사한다.
