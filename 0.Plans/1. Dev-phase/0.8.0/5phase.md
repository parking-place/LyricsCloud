# 0.8.0 Phase 5 — 전체 내보내기와 데이터 수명주기 릴리즈

- 상태: **대기**
- 단계 목적: DEC-13-A 내보내기와 13~15번 화면의 기능을 검증해 0.8.0을 마감한다.

## 목표

사용자의 곡·가사·라임 노트·프롬프트·템플릿·설정을 TXT/Markdown과 JSON 묶음으로 내보내고, 템플릿·설정·휴지통·탈퇴 흐름을 통합 검증한다.

## 선행조건

- [0.8.0 Phase 1](./1phase.md)부터 [Phase 4](./4phase.md)까지 완료되어야 한다.
- 내보내기 작업의 서버 실행 방식과 임시 파일 정책은 [0.0.0 ADR 산출물](../0.0.0/)을 따른다.
- 외부 저장소나 전송 서비스는 선택된 것으로 간주하지 않으며 브라우저 직접 다운로드만 기본 범위로 한다.

## 구체적 검증

1. 특수문자·한글·같은 제목·긴 가사가 포함된 계정을 내보내 모든 파일이 UTF-8로 열리는지 확인한다.
2. JSON을 schema 검증기로 검사하고 모든 관계 ID가 묶음 안의 유효한 대상 또는 명시적 null인지 확인한다.
3. 사용자 A가 사용자 B의 export job ID를 조회·다운로드할 수 없는지 통합 테스트한다.
4. 내보내기 중 자료 수정 시 부분적으로 서로 다른 시점의 결과가 섞이지 않는지 확인한다.
5. 13~15번 화면을 PC·모바일에서 템플릿 → 설정 → 삭제 → 복원 → 내보내기 순으로 회귀한다.
6. 실패를 강제로 발생시킨 뒤 임시 파일·작업 상태·재시도 동작을 검사한다.
