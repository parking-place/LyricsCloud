# 0.8.0 Phase 3 — 키보드 중심 작업과 단축키 안내

- 상태: **대기**
- 단계 목적: 장시간 PC 작업을 마우스 이동 없이 수행하되 모바일·한글 입력을 방해하지 않게 한다.

## 목표

새 가사, 검색, 전체 복사, 집중 모드, 보조 패널, 이전·다음 가사 이동의 단축키를 일관되게 제공하고 설정 화면에서 발견·확인할 수 있게 한다.

## 선행조건

- [0.8.0 Phase 2](./2phase.md)의 설정 화면과 편집기 표시 상태가 완료되어야 한다.
- 가사 편집기, 검색, 좌·우 패널과 복사 명령이 안정된 명령 인터페이스를 제공해야 한다.
- 운영체제별 키 표기와 충돌 정책은 [결정 권한표](../Decision-Ownership.md)의 `PROD-0009`로 이 Phase에서 확정한다.

## 포함 범위

- 핵심 명령의 기본 단축키와 도움말
- Windows/Linux의 Ctrl, macOS의 Command 표기
- 입력 영역·한글 IME·브라우저 예약 키 충돌 회피
- 키보드 포커스 이동과 실행 후 원래 편집 위치 복귀
- 복사 실패 대안과 상태 안내

## 제외 범위

- 전역 운영체제 단축키 등록
- 모바일 하드웨어 키보드 전용 기능 보장
- 사용자가 임의 스크립트를 단축키에 연결하는 기능

## 작업 체크리스트

- [ ] `LC-080-P3-01` `PROD-0009` 결정 기록에 모든 명령, 기본 키, 운영체제별 표기, 실행 가능 문맥과 충돌 정책을 명령 표로 만든다.
- [ ] `LC-080-P3-02` 브라우저 예약 키와 텍스트 편집 기본 동작을 가로채지 않는 키 조합을 적용한다.
- [ ] `LC-080-P3-03` `compositionstart`부터 `compositionend`까지 앱 단축키 실행을 억제한다.
- [ ] `LC-080-P3-04` 단축키 도움말을 설정 화면과 검색 가능한 명령 안내에서 제공한다.
- [ ] `LC-080-P3-05` 집중 모드·패널 토글 후 가사 커서와 스크롤을 복원한다.
- [ ] `LC-080-P3-06` 이전·다음 가사 이동 전에 로컬 초안 보존과 선택된 저장/병합 규칙을 실행한다.
- [ ] `LC-080-P3-07` 전체 복사 실패 시 선택 가능한 텍스트와 수동 복사 안내를 제공한다.
- [ ] `LC-080-P3-08` 키보드로 모든 도움말을 열고 닫으며 원래 초점으로 돌아오게 한다.

## 구체적 검증

1. 한글 조합 중 단축키 문자와 유사한 입력을 해도 명령이 실행되지 않는지 확인한다.
2. Chrome, Firefox, WebKit에서 브라우저 기본 저장·검색·탭 이동을 불필요하게 막지 않는지 검사한다.
3. 미전송 초안이 있는 상태에서 이전·다음 가사 이동 후 내용이 보존되는지 E2E로 검증한다.
4. 키보드만 사용해 검색, 결과 열기, 집중 모드, 패널, 복사, 도움말을 순회한다.
5. 단축키 표의 모든 항목과 실제 등록 명령을 자동 테스트로 대조한다.

## 완료 조건

- [ ] 기획서의 핵심 키보드 작업에 명령과 안내가 존재한다.
- [ ] 한글 IME·브라우저 기본키·자동 저장과 충돌하지 않는다.
- [ ] 키보드만으로 핵심 작업과 도움말을 사용할 수 있다.
- [ ] 단축키 실행 전후 커서·초안·초점 손실 테스트가 통과한다.
