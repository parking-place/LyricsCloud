# 0.8.0 Phase 2 — 사용자 설정과 테마

- 상태: **대기**
- 단계 목적: 기기와 문서가 달라도 일관된 글쓰기 환경을 제공한다.

## 목표

밝음·어두움·기기 맞춤 테마와 기본 글꼴·크기·줄 간격·자간·집중 모드 설정을 계정에 저장하고, 특정 가사의 표시 재정의를 분리한다.

## 선행조건

- [0.8.0 Phase 1](./1phase.md)의 공통 화면·폼 패턴을 사용할 수 있어야 한다.
- 사용자 설정 및 가사별 표시 설정의 데이터 경계가 정의되어 있어야 한다.
- 허용 글꼴 목록, 값 범위와 자산 제공 방식은 이 Phase의 `LC-080-P2-03` 제품/UI 결정 산출물로 기록하고 승인 전 외부 폰트나 임의 CSS 경로를 고정하지 않는다.

## 포함 범위

- 밝음, 어두움, 기기 설정 맞춤 테마
- 계정 기본 글꼴·글자 크기·줄 간격·자간·집중 모드
- 가사별 표시 재정의와 기본값 복귀
- 서버 저장 설정과 즉시 적용되는 로컬 화면 상태
- 잘못된 값의 안전한 기본값 처리

## 제외 범위

- 사용자 입력 외부 폰트 URL과 임의 CSS
- 콘텐츠 본문에 표시 스타일을 삽입하는 방식
- 운영체제 전체 설정 변경

## 작업 체크리스트

- [ ] `LC-080-P2-01` 계정 기본값과 가사별 재정의의 병합 우선순위를 문서화한다.
- [ ] `LC-080-P2-02` 테마 선택을 서버 설정과 `prefers-color-scheme`에 맞춰 초기 깜박임 없이 적용한다.
- [ ] `LC-080-P2-03` 글꼴·크기·줄 간격·자간에 허용 목록과 상하한 검증을 둔다.
- [ ] `LC-080-P2-04` 설정 미리보기, 저장, 취소, 기본값 복원 흐름을 구현한다.
- [ ] `LC-080-P2-05` 가사별 재정의를 제거하면 계정 기본값이 즉시 다시 적용되게 한다.
- [ ] `LC-080-P2-06` 다른 기기에서 변경된 설정을 다음 진입 또는 승인된 변경 감지 방식으로 반영한다.
- [ ] `LC-080-P2-07` 테마별 텍스트·버튼·상태 색상의 대비와 포커스 표시를 검증한다.
- [ ] `LC-080-P2-08` 설정 저장 실패 시 화면 값과 서버 값의 차이를 명확히 알리고 재시도할 수 있게 한다.
- [ ] `LC-080-P2-09` 모바일에서는 글쓰기 설정을 초점 관리가 되는 시트로 제공하고 닫은 뒤 편집 위치를 복원한다.

## 구체적 검증

1. 시스템 테마 변경 시 `기기 설정 맞춤`만 자동 전환되는지 확인한다.
2. 계정 기본 설정 변경 후 새 가사와 기존 일반 가사에 적용되고 개별 재정의 가사는 유지되는지 검사한다.
3. URL이나 스크립트가 포함된 글꼴 값과 범위 밖 숫자를 API 수준에서 거부하는지 확인한다.
4. 새로고침·재로그인·다른 기기 진입 후 설정이 동일한지 E2E로 검증한다.
5. 밝음·어두움 양쪽에서 핵심 텍스트와 저장 상태의 자동 대비 검사를 수행한다.
6. 모바일 설정 시트를 열고 값을 미리 본 뒤 취소·저장했을 때 각각 편집 상태가 예상대로 유지되는지 확인한다.

## 완료 조건

- [ ] 세 가지 테마와 글쓰기 기본 설정이 계정에 저장된다.
- [ ] 가사별 재정의와 기본값 복귀가 예측 가능하게 동작한다.
- [ ] 유효성·동기화 실패·접근성 테스트가 통과한다.
- [ ] 사용자 입력 스타일이 CSS/외부 자원 실행 경로가 되지 않는다.
