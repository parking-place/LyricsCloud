# 0.9.0 Phase 2 — PC·모바일 반응형 셸과 편집 조작성

- 상태: **대기**
- 단계 목적: 모든 화면이 일반 PC와 실제 모바일 너비에서 기능 손실 없이 동작하게 한다.

## 목표

공통 내비게이션, 목록, 폼, 대시보드, 편집기와 보조 패널을 반응형으로 마감하고 모바일 가상 키보드·안전 영역·긴 텍스트 작업을 안정화한다.

## 선행조건

- [0.9.0 Phase 1](./1phase.md)의 뷰포트·화면 차이·UI 토큰 기준선이 승인되어야 한다.
- 15개 화면의 핵심 기능 회귀 테스트가 실행 가능해야 한다.
- 자체 운영 배포의 외부 프록시·지역은 [0.0.0 ADR 산출물](../0.0.0/) 전까지 임의 확정하지 않는다.

## 포함 범위

- 데스크톱 좌측 메뉴·우측 보조 패널과 모바일 시트/내비게이션
- 목록·카드·폼의 반응형 재배치와 터치 영역
- CodeMirror 한글 IME, 선택, 스크롤, 가상 키보드 대응
- `100dvh`, safe-area, 화면 회전과 확대
- 주요 행동의 터치·키보드 동등 경로

## 제외 범위

- 네이티브 iOS/Android 앱
- 모바일에서만 존재하는 별도 데이터 모델
- 길게 누르기만으로 접근 가능한 필수 기능

## 작업 체크리스트

- [ ] `LC-090-P2-01` 공통 앱 셸의 데스크톱·태블릿·모바일 전환점을 토큰으로 통일한다.
- [ ] `LC-090-P2-02` 모바일 내비게이션과 보조 패널을 초점 관리가 되는 모달/시트 패턴으로 구현한다.
- [ ] `LC-090-P2-03` 목록·필터·빠른 추가가 320~430px 너비에서 가로 스크롤 없이 사용되게 한다.
- [ ] `LC-090-P2-04` 편집기의 `dvh`, safe-area, 가상 키보드 및 화면 회전 레이아웃을 보정한다.
- [ ] `LC-090-P2-05` 한글 IME 조합·긴 텍스트 선택·송폼 이동 뒤 커서와 스크롤을 보존한다.
- [ ] `LC-090-P2-06` 모든 필수 아이콘 행동에 충분한 터치 영역, 이름과 보이는 대안을 제공한다.
- [ ] `LC-090-P2-07` 길게 눌러 프롬프트 복사는 보조 기능으로 두고 명시적 복사 버튼을 유지한다.
- [ ] `LC-090-P2-08` 패널/집중 모드 전환 전 미전송 초안이 유실되지 않게 한다.

## 구체적 검증

1. 320, 360, 390, 768, 1280, 1440px에서 레이아웃 오버플로와 가려진 조작 요소를 검사한다.
2. iOS 계열 WebKit과 Android 계열 Chromium에서 가상 키보드가 편집 커서와 저장 상태를 가리지 않는지 확인한다.
3. 한글을 연속 입력하면서 회전·패널 전환·집중 모드를 수행해 잘린 글자나 중복 입력이 없는지 검증한다.
4. 터치와 키보드 각각으로 새 자료, 검색, 복사, 패널, 저장 실패 재시도를 수행한다.
5. 15개 화면의 모바일 핵심 경로를 Playwright 뷰포트 테스트로 실행한다.

## 완료 조건

- [ ] 15개 화면의 PC·모바일 핵심 기능이 동일하게 접근 가능하다.
- [ ] 가상 키보드·한글 IME·화면 회전 회귀가 통과한다.
- [ ] 필수 기능이 hover 또는 길게 누르기에만 의존하지 않는다.
- [ ] 반응형 변경으로 자동 저장·커서·초안 손실이 발생하지 않는다.
