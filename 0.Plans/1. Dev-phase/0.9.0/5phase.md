# 0.9.0 Phase 5 — 실기기 검증과 화면 마감 승인

- 상태: **대기**
- 단계 목적: 에뮬레이션을 넘어 실제 PC·모바일에서 15개 화면과 PWA를 승인한다.

## 목표

지원 브라우저와 실제 iOS/Android 기기에서 설치, 로그인, 편집, 복사, 오프라인 초안, 업데이트와 모든 화면의 핵심 경로를 검증해 0.9.0 UI/PWA 마감을 승인한다.

## 선행조건

- [0.9.0 Phase 1](./1phase.md)부터 [Phase 4](./4phase.md)까지 자동 테스트와 시각 기준선이 통과해야 한다.
- 테스트 환경의 HTTPS·OAuth callback·배포 방식은 [0.0.0 ADR 산출물](../0.0.0/)을 따라야 한다.
- 테스트 기기에는 실제 사용자 창작물이 아닌 합성 계정·자료만 사용한다.

- 지원 데스크톱 브라우저와 실제 iOS Safari·Android Chrome
- 15개 화면 PC·모바일 시각·기능 회귀
- PWA 설치·재실행·업데이트·로그아웃 데이터 정리
- 한글 IME, 긴 텍스트 선택, 클립보드, 가상 키보드
- 성능 체감과 P0/P1 결함 분류

- 네이티브 앱 스토어 배포
- 0.9.1의 운영 백업·보안 침투 검증

- [ ] `LC-090-P5-02` 15개 화면을 네 기준 뷰포트에서 시각 회귀하고 승인 차이를 기록한다.

- [ ] `LC-090-P5-04` 실제 Android 기기에서 동일 흐름과 뒤로 가기·화면 회전을 검증한다.

## 구체적 검증

1. 새 계정으로 로그인부터 곡·가사·라임·프롬프트·검색·설정·삭제·내보내기까지 end-to-end 점검한다.
2. 10,000줄에 가까운 합성 텍스트에서 입력·스크롤·송폼 이동·복사의 체감 지연과 오류를 기록한다.
3. Wi-Fi 끊김, 느린 연결, 인증 만료를 실제 기기에서 재현해 초안 보존을 확인한다.
4. 홈 화면 설치본과 일반 브라우저 탭에서 세션·캐시·뒤로 가기 차이를 비교한다.
5. 모든 P0/P1 수정 후 전체 시각·기능 회귀를 다시 실행한다.

## 완료 조건

- [ ] 15개 화면의 PC·모바일 추적 항목과 목업 추가 제안이 검증 증적을 가진다.
- [ ] 지원 대상 실제 iOS·Android에서 핵심 사용자 흐름이 통과한다.
- [ ] 설치·오프라인 초안·업데이트·계정 전환에서 창작물 손실이나 노출이 없다.
- [ ] 미해결 P0/P1 결함이 0개이며 0.9.1 기능 동결을 시작할 수 있다.
