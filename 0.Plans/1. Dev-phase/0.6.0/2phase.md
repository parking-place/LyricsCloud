# 0.6.0 Phase 2 — 곡-라임·프롬프트 연결 관리

- 상태: **완료**
- 단계 목적: 곡에 필요한 라임과 프롬프트를 안전하게 연결·해제하고 한곳에서 찾게 한다.

## 목표

곡 대시보드에서 라임 노트와 프롬프트를 검색·연결·해제하고, 각 자료 편집기와 목록에서 같은 관계를 확인하도록 완성한다. 관계 제거와 자료 삭제를 명확히 구분하며 owner가 다른 자료는 어떤 후보나 count에도 나타나지 않게 한다.

## 선행조건

- [0.6.0 Phase 1](./1phase.md)의 연결 preview·count와 영역별 오류 처리가 완료되어야 한다.
- 0.4.0·0.5.0의 곡 연결 데이터 작업은 [결정 권한표](../Decision-Ownership.md)의 `PROD-0002` cardinality·unlink 계약과 `PROD-0010` 삭제·복원 계약을 따라야 한다.
- soft delete와 연결 관계의 처리 규칙이 승인되어야 한다.

## 구체적 검증

1. 연결 자료가 없는 곡에서 라임과 프롬프트를 각각 연결하고 count·preview·자료 편집기가 동시에 갱신되는지 확인한다.
2. 같은 관계를 반복 요청하거나 네트워크 실패 후 재시도해도 한 관계만 남는지 검사한다.
3. unlink 후 자료가 원래 라이브러리에는 남고 dashboard에서만 제거되는지 확인한다.
4. 다른 owner, 휴지통 자료, 삭제된 곡을 후보 ID로 직접 보내도 존재 정보가 노출되지 않는지 테스트한다.
5. PC keyboard와 모바일 touch로 검색·다중 선택·취소·적용·해제를 수행하고 focus가 올바른 곳으로 돌아오는지 확인한다.
6. 연결 목록 0건, 후보 0건, 결과 0건, 요청 실패가 서로 다른 안내와 다음 행동을 제공하는지 점검한다.
