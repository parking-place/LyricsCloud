# 0.6.0 Phase 4 — 커서 삽입, 자료 복사와 전역 빠른 추가

- 상태: **대기**
- 단계 목적: 보조 자료를 현재 가사에 정확히 가져오고 어느 화면에서든 새 아이디어를 즉시 기록하게 한다.

## 목표

라임의 전체 또는 선택 표현을 현재 가사의 CRDT cursor에 하나의 undo 가능한 작업으로 삽입하고, 프롬프트·라임·가사를 안전하게 복사한다. PC·모바일 전역 빠른 추가와 모바일 빠른 아이디어를 승인된 자료 유형에 연결한다.

## 선행조건

- [0.6.0 Phase 3](./3phase.md)의 자료 panel과 editor focus 복원이 완료되어야 한다.
- [0.4.0 Phase 4](../0.4.0/4phase.md)의 라임 선택 텍스트·삽입 요청 계약을 충족해야 한다.
- 빠른 아이디어의 저장 대상과 새 가사의 부모 곡 선택 규칙은 [0.0.0 Phase 1](../0.0.0/1phase.md)에 쟁점이 등록되어 있어야 하며, 이 Phase에서 [결정 권한표](../Decision-Ownership.md)의 `PROD-0005`로 확정한다.

- [ ] **LC-060-P4-02** 라임 전체/선택 표현을 하나의 undo 가능한 transaction으로 삽입하고 focus를 editor로 되돌린다.
- [ ] **LC-060-P4-03** target 가사가 삭제·전환·원격 변경되거나 cursor가 무효일 때 안전한 안내와 복사 대안을 제공한다.
- [ ] **LC-060-P4-04** 가사 전체·송폼 구간, 라임, 프롬프트 복사의 성공·실패·수동 복사 상태를 통일한다.
- [ ] **LC-060-P4-05** PC 상단과 모바일 FAB/More에서 곡·가사·라임·프롬프트 빠른 추가를 접근 가능하게 한다.
- [ ] **LC-060-P4-06** 새 가사에서 현재 곡 사용 또는 부모 곡 선택, 취소·빈 후보·권한 실패 흐름을 구현한다.
- [ ] **LC-060-P4-07** `PROD-0005`에 빠른 아이디어 자료 유형과 새 가사의 부모 곡 선택 규칙을 승인 기록으로 남기고, 그 결과에 따라 최소 입력을 저장해 나중에 제목·곡 연결을 보완할 수 있게 한다.
- [ ] **LC-060-P4-08** 오프라인 빠른 생성·연속 탭·재시도가 중복 자료를 만들지 않고 IndexedDB에서 서버로 동기화되게 한다.

## 구체적 검증

1. Hook 중간 cursor, 선택 영역 대체, 문서 시작·끝에서 라임을 삽입하고 한 번의 undo로 원상 복구되는지 확인한다.
2. panel이 열린 동안 다른 탭의 원격 편집으로 cursor 주변이 바뀌어도 CRDT 상대 위치에 안전하게 삽입되는지 검사한다.
3. target 없음·삭제됨·전환됨·권한 오류에서 삽입이 실행되지 않고 선택 표현을 복사할 수 있는지 확인한다.
4. PC·모바일 모든 주요 화면에서 빠른 추가를 열고 네 자료 유형의 올바른 신규 흐름으로 이동하는지 E2E로 검증한다.
5. 모바일 오프라인에서 빠른 아이디어를 저장하고 앱 강제 종료·재연결 후 하나의 자료로 복구되는지 확인한다.
6. clipboard 거부와 모바일 selection에서 내용 손실 없이 수동 복사 modal/sheet가 제공되는지 검사한다.
7. 한글 IME 조합 중 panel 삽입을 요청해 조합 문자가 잘리거나 두 번 들어가지 않는지 확인한다.

## 완료 조건

- [ ] 라임 cursor 삽입이 focus·selection·undo·동기화 규칙을 지킨다.
- [ ] target 오류와 clipboard 실패에서 원문을 잃지 않는 대안이 제공된다.
- [ ] 전역 빠른 추가와 모바일 빠른 아이디어가 PC·모바일에서 동작한다.
- [ ] 오프라인·연속 요청에서 중복 자료가 생성되지 않는다.
