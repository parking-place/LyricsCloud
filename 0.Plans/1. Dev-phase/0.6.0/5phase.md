## 구체적 검증

1. 깨끗한 계정이 PC에서 곡을 만들고 모바일에서 같은 가사를 이어 쓴 뒤 다시 PC에서 수렴된 내용을 확인한다.
2. 가사 작성 중 panel을 벗어나지 않고 라임을 찾아 cursor에 삽입하고 프롬프트를 복사해 전체 창작 흐름이 끊기지 않는지 확인한다.
3. 각 panel 탭과 dashboard 영역을 개별 실패시켜 나머지 편집·로컬 초안·복사 기능이 계속 가능한지 검사한다.
4. 오프라인 빠른 아이디어와 새 자료가 재연결 뒤 한 번만 생성되고 올바른 곡에 연결되는지 확인한다.
5. 360px 모바일, 일반 PC, keyboard-only에서 모든 핵심 행동과 닫기·취소·재시도에 도달할 수 있는지 검증한다.
6. 다른 owner의 곡·가사·라임·프롬프트 ID를 panel과 연결 API에 넣어 제목·count·존재 여부가 노출되지 않는지 테스트한다.

## 완료 조건

- [ ] 0.6.0의 모든 고유 ID가 증적과 연결된다.
- [ ] 신규 곡부터 라임 삽입·프롬프트 복사까지 PC·모바일 수직 흐름이 통과한다.
- [ ] 모든 목업 미표현 상태가 데이터 손실 없이 안내·복구된다.
- [ ] 동일 owner 자동 병합과 다른 owner 격리 회귀가 통과한다.
- [ ] 0.7.0 탐색 기능이 사용할 deep link·card·평문 계약이 준비되었다.
