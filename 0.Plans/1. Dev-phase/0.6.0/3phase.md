# 0.6.0 Phase 3 — 가사 편집 우측 자료 패널

- 상태: **대기**
- 단계 목적: 가사 화면을 떠나지 않고 다른 곡·가사·라임·프롬프트를 탐색하게 한다.

## 목표

05번 목업의 보조 패널을 Sketch 요구에 맞춰 다른 곡, 현재 곡의 다른 가사, 라임 노트, 프롬프트 네 탭으로 완성한다. PC에서는 접이식 우측 패널, 모바일에서는 스크롤 가능한 bottom sheet로 구현하고 검색·연결 범위·빈·오류 상태를 제공한다.

## 선행조건

- [0.6.0 Phase 2](./2phase.md)의 곡 연결 query와 owner 격리가 완료되어야 한다.
- 가사 편집기의 CRDT cursor·selection·focus 계약은 [0.3.1 릴리즈](../0.3.1/)에서 사용할 수 있어야 한다.
- panel routing·상태 보존 방식은 [0.1.0 Phase 4](../0.1.0/4phase.md)의 공통 셸과 [0.3.1 Phase 2](../0.3.1/2phase.md)의 편집 상태 계약을 재사용하며, 패널 고유 동작은 이 Phase에서 확정한다.

## 작업 체크리스트

- [ ] **LC-060-P3-01** 다른 곡·다른 가사·라임·프롬프트 네 탭의 공통 결과 계약을 정의한다.
- [ ] **LC-060-P3-02** 다른 곡에서 곡 전환 또는 새 화면 열기의 명확한 행동과 미저장 초안 보존을 구현한다.
- [ ] **LC-060-P3-03** 다른 가사 탭에 제목·상태·preview·수정 시각과 현재 가사 구분을 표시한다.
- [ ] **LC-060-P3-04** 라임·프롬프트에서 연결 자료 우선/전체 범위 전환과 검색을 구현한다.
- [ ] **LC-060-P3-05** PC 패널 접기·펼치기와 focus mode 전후의 마지막 탭·검색어·너비 상태를 복원한다.
- [ ] **LC-060-P3-06** 모바일 bottom sheet에 제목·닫기·drag handle·내부 스크롤·가상 키보드 대응을 구현한다.
- [ ] **LC-060-P3-07** 탭별 로딩, 연결 자료 없음, 검색 결과 없음, 요청 실패·재시도, 삭제된 항목 상태를 구현한다.
- [ ] **LC-060-P3-08** panel을 keyboard와 screen reader로 열고 탭 이동·검색·닫기 후 editor focus를 복원하게 한다.

## 구체적 검증

1. 가사를 입력 중 panel을 열고 다른 탭을 탐색한 뒤 닫아도 초안·cursor·selection이 유지되는지 확인한다.
2. 다른 곡을 선택할 때 저장 중·로컬 임시 저장·동기화 완료 각 상태에서 안전하게 전환되는지 검사한다.
3. 연결 자료 0건과 검색 결과 0건, API 실패를 탭별로 구분하고 다른 탭은 계속 사용할 수 있는지 확인한다.
4. 360·390px 모바일에서 긴 결과를 sheet 내부로 스크롤하고 가상 키보드 중 닫기·검색에 접근 가능한지 검증한다.
5. PC panel 접기→focus mode→해제→펼치기 후 마지막 탭과 editor focus가 복원되는지 확인한다.
6. 다른 owner·휴지통 자료가 다른 곡/가사/라임/프롬프트 어떤 탭에도 노출되지 않는지 테스트한다.

## 완료 조건

- [ ] panel 탐색 중 가사 초안·cursor·selection이 손실되지 않는다.
- [ ] 빈·무결과·로딩·오류 상태와 내부 스크롤이 구현되었다.
- [ ] keyboard·screen reader·owner 격리 회귀가 통과한다.
