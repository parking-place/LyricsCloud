# 0.3.0 Phase 5 — 05 편집 화면·곡 화면 통합과 0.3.1 인계

- 상태: **진행 중**
- 버전 상태: [../STATUS.md](../STATUS.md)

## 목표

가사 생성부터 편집·송폼 이동·복사·복제·삭제까지를 곡 목록과 대시보드에 연결하고, 05-lyrics-editor의 기본 PC·모바일 화면을 완성한다. CRDT 동기화와 수정 기록을 도입할 0.3.1의 안정된 편집기 경계를 남긴다.

## 선행조건

- 0.3.0 Phase 1부터 Phase 4까지의 CRUD, CodeMirror, 송폼, 복사, 집중 모드가 완료되어야 한다.
- 0.2.0의 곡 목록·폼·대시보드가 회귀 테스트 가능한 상태여야 한다.
- Accepted CRDT ADR의 문서 경계와 0.3.1 인계 형식이 확인되어야 한다.

## 포함 범위

- 곡 대시보드의 가사 카드·개수·빈 상태
- 새 가사 생성과 editor 이동
- 가사 제목·본문·메모·상태·favorite·pin
- 가사 복제와 soft delete
- 현재 곡의 다른 가사 전환
- PC의 송폼·중앙 editor·다른 가사 영역 기본 구성
- 모바일 editor·송폼·복사·다른 가사 시트
- 곡 목록의 lyric_count와 곡 제목·가사 내용 검색
- 기본 저장 상태와 전체 흐름 E2E
- 0.3.1 CRDT·수정 기록 연결을 위한 editor adapter 계약

- 사용자 글꼴·크기·자간·줄 간격 설정

- [ ] LC-030-P5-02 — PC·모바일의 새 가사 행동이 정확한 song 아래 lyric을 만들고 해당 editor로 이동하게 한다.
- [ ] LC-030-P5-03 — 05 PC 화면에 송폼 목차, 중앙 CodeMirror, 현재 곡 다른 가사 전환 영역을 실제 데이터로 연결한다.
- [ ] LC-030-P5-04 — 05 모바일 화면에 본문 중심 layout과 송폼·복사·다른 가사 시트를 같은 기능으로 제공한다.
- [ ] LC-030-P5-05 — 가사 복제 뒤 원본과 복사본이 다른 ID·제목을 갖고 복사본 editor가 열리게 한다.
- [ ] LC-030-P5-06 — 가사 soft delete 뒤 다음 가사 또는 곡 대시보드로 안전하게 이동하고 lyric_count를 갱신한다.
- [ ] LC-030-P5-07 — favorite, pin, status, memo 변경이 editor와 대시보드 카드에 일관되게 반영되게 한다.
- [ ] LC-030-P5-08 — 02 곡 검색에 활성 가사 제목·본문 일치를 추가하되 삭제된 가사와 다른 사용자 내용은 제외한다.
- [ ] LC-030-P5-09 — 곡 생성→가사 생성→한글 작성→송폼 이동→복수 구간 복사→복제→삭제 흐름을 PC·모바일 E2E로 만든다.
- [ ] LC-030-P5-10 — editor 변경을 transaction 형태로 주고받을 수 있는 adapter 경계를 문서화하되 특정 CRDT 패키지 코드를 넣지 않는다.
- [ ] LC-030-P5-11 — 0.3.0 화면에서 버전 비교·수정 기록·동기화 완료를 사용할 수 있는 것처럼 표시하지 않는다.

## 검증 방법

- 가사 0개, 1개, 20개인 곡에서 대시보드 목록·개수·전환을 확인한다.
- PC 1440px과 모바일 390×844에서 동일한 가사를 편집하고 송폼·복사 결과를 비교한다.
- 한글 본문을 저장하고 새로고침·다른 가사 전환·브라우저 재진입 후 같은 현재본이 열리는지 확인한다.
- 가사 복제·삭제 뒤 dashboard, song list lyric_count, 검색 결과가 동시에 일치하는지 확인한다.
- 사용자 A의 가사 검색어가 B의 곡 검색 결과·미리보기에 노출되지 않는지 확인한다.
- 다중 장치 CRDT, 수정 기록, 버전 비교 테스트가 0.3.0 완료 조건으로 잘못 포함되지 않았는지 검토한다.

## 다음 Phase 인계

0.3.1에는 Accepted ADR을 기준으로 CodeMirror transaction과 CRDT document를 연결하고, 여러 기기 자동 병합, IndexedDB 미전송 update, 서버 영속화·압축, resource revision 체크포인트, 수정 기록·복원·버전 비교를 구현한다. 0.3.0의 전체 텍스트 현재본은 migration 입력으로 보존하며 무음 덮어쓰기를 허용하지 않는다.
