# 06. 라임 노트 목록

## 화면 목적

라임, 단어, 표현, 펀치라인 아이디어를 쌓아두고 곡 작업 중 빠르게 다시 찾는 보관함입니다.

## 주요 기능

- 노트 제목과 내용 전체 검색
- 사용자 태그와 연결된 곡으로 목록 좁히기
- 제목, 내용 일부, 최근 수정일, 즐겨찾기, 핀 확인
- 노트 전체 빠른 복사
- 새 라임 노트 만들기
- 선택한 노트를 가사 편집 화면의 자료 패널에서 사용

## PC 화면

- 상단 검색과 태그 필터 아래에 2열 카드 목록을 배치합니다.
- 각 카드에서 라임 일부와 연결 곡을 열기 전에 확인할 수 있습니다.
- 즐겨찾기와 핀은 색만이 아니라 별·핀 모양과 이름으로 구분합니다.

## 모바일 화면

- 카드 한 열과 가로 태그 필터를 사용합니다.
- 모든 카드에 보이는 `복사` 행동을 두고, 길게 누르기는 보조 방식으로만 안내합니다.
- 화면 아래 빠른 추가로 떠오른 라임을 즉시 기록할 수 있습니다.

## 주요 상태

- 기본 상태: 최근 수정순 목록
- 검색 결과: 검색어가 포함된 문장 일부 강조
- 빈 상태: `떠오른 단어나 표현을 짧게라도 남겨보세요`
