# 14. 가사·프롬프트 템플릿

## 화면 목적

반복해서 쓰는 가사 구조와 프롬프트 기본 조합을 저장하고 새 작업의 출발점으로 사용하는 화면입니다.

## 주요 기능

- 가사 템플릿과 프롬프트 템플릿 전환
- 템플릿 제목과 내용 미리보기
- 새 템플릿 작성, 기존 템플릿 수정·복제·삭제
- 새 가사 또는 프롬프트에 선택한 템플릿 적용
- 현재 가사 구조 또는 프롬프트를 템플릿으로 저장

## PC 화면

- 왼쪽 목록에서 템플릿을 선택하고 오른쪽 넓은 영역에서 전체 내용을 미리 봅니다.
- 적용 행동은 편집 행동과 분리해 다음 결과가 분명하게 보이도록 합니다.

## 모바일 화면

- 가사·프롬프트 종류를 상단에서 바꾸고 템플릿 카드를 세로로 보여줍니다.
- 카드를 열면 전체 미리보기와 `이 템플릿으로 시작` 행동이 이어집니다.

## 주요 상태

- 기본 템플릿과 사용자 템플릿 구분
- 적용 대상이 정해진 상태
- 사용자 템플릿이 없는 빈 상태
