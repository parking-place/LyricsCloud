# 13. 휴지통

## 화면 목적

실수로 삭제한 창작물을 안전하게 되돌리거나, 필요 없는 자료를 확인 후 완전히 삭제하는 화면입니다.

## 주요 기능

- 삭제한 곡, 가사, 라임 노트, 프롬프트 함께 표시
- 자료 종류, 원래 위치, 삭제 시각 확인
- 하나 또는 여러 항목을 원래 위치로 복원
- 완전 삭제 전 대상과 결과 확인
- 자료 종류로 목록 좁히기

## PC 화면

- 행 형태 목록으로 자료명, 원래 위치, 삭제일, 복원, 완전 삭제를 한눈에 보여줍니다.
- 완전 삭제는 일반 행동과 떨어뜨리고 경고 색과 문장으로 구분합니다.
- 확인 창에는 삭제할 자료명을 직접 표시합니다.

## 모바일 화면

- 각 삭제 자료를 한 장의 카드로 보여주고 `복원`을 먼저, `완전 삭제`를 두 번째로 배치합니다.
- 확인 창은 화면 아래 시트로 열리며 취소를 쉽게 선택할 수 있습니다.

## 주요 상태

- 삭제 자료 목록
- 복원 완료: `원래 위치로 복원했습니다`
- 완전 삭제 확인: 되돌릴 수 없다는 문장 표시
- 빈 상태: `휴지통이 비어 있습니다`
