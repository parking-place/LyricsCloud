# 03. 새 곡 작성·곡 정보 수정

## 화면 목적

곡의 기본 정보와 현재 작업 단계를 정하고, 곧바로 가사 작업을 시작할 준비를 하는 화면입니다. 새 곡 작성과 기존 곡 정보 수정에 같은 구성을 사용합니다.

## 주요 기능

- 곡 제목 입력
- 설명 또는 작업 메모 입력
- 작업 상태 선택
- 사용자가 의미를 정하는 색상 표시 선택
- 핀 고정, 즐겨찾기 설정
- 곡을 만든 뒤 빈 곡 대시보드 또는 새 가사 작성으로 이동

## PC 화면

- 왼쪽의 넓은 입력 영역과 오른쪽의 상태·표시 설정 영역으로 나눕니다.
- 오른쪽에는 저장 후 이어질 작업을 미리 안내합니다.
- 제목이 비어 있을 때 필요한 안내를 입력란 바로 아래에 보여줍니다.

## 모바일 화면

- 제목, 메모, 상태, 색상 순서로 한 열에 배치합니다.
- 완료 버튼은 화면 아래에서 쉽게 찾을 수 있게 유지합니다.
- 긴 메모를 작성해도 현재 선택한 상태와 완료 행동을 놓치지 않게 합니다.

## 주요 상태

- 새 곡: 기본 상태는 `아이디어`
- 수정: 현재 정보가 채워진 상태로 시작
- 입력 누락: 곡 제목을 적어달라는 문장 표시
- 완료: `곡을 만들었습니다` 안내 후 다음 작업 제시
