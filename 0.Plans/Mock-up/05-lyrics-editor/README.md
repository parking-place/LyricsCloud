# 05. 가사 편집

## 화면 목적

서비스의 중심 화면입니다. 가사를 쓰는 동안 다른 버전, 송폼, 라임, 프롬프트를 확인하고 복사하는 흐름이 끊기지 않도록 합니다.

## 주요 기능

- 가사 제목과 본문 작성
- 자동 저장 상태와 저장 시각 확인
- 송폼 태그 구분과 원하는 구간으로 이동
- 가사 전체 또는 선택한 송폼 구간 복사
- 가사 복제, 즐겨찾기, 상태 변경, 삭제
- 글꼴, 글자 크기, 자간, 줄 간격 조절
- 집중 모드 전환
- 곡의 다른 가사 버전, 프롬프트, 라임 노트 확인
- 라임 표현을 현재 가사에 삽입
- 수정 기록 확인과 이전 상태 복원
- 본문과 분리된 작업 메모 확인

## PC 화면

- 좌측은 송폼 목차, 중앙은 넓은 가사 편집 영역, 우측은 자료 패널입니다.
- 우측 패널에서 다른 가사, 프롬프트, 라임 노트를 탭으로 전환합니다.
- 상단에는 자동 저장, 복사, 버전 비교, 집중 모드가 명확한 이름으로 표시됩니다.
- 집중 모드에서는 좌우 패널을 숨기고 글의 행 길이와 여백은 읽기 편한 범위로 유지합니다.

## 모바일 화면

- 가사 본문이 화면 대부분을 차지합니다.
- 송폼, 자료, 복사, 더보기는 편집기 하단 도구 영역에 둡니다.
- 라임이나 프롬프트는 제목과 닫기 행동이 있는 별도 시트에서 확인합니다.
- 키보드가 열린 상태에서도 전체 복사와 자동 저장 상태를 확인할 수 있습니다.

## 주요 상태

- 저장 완료: `방금 저장됨`
- 저장 중: `변경 내용을 저장하는 중…`
- 동기화 지연: 현재 내용은 보존되었고 다시 연결되면 이어서 반영된다는 안내
- 복사 완료: `가사를 복사했습니다` 또는 `선택한 Hook을 복사했습니다`
- 수정 기록: 변경 시각과 요약, 미리보기, 복원 확인

## 추가 제안

`버전 비교`를 열면 현재 가사와 선택한 이전 버전을 나란히 확인하고 필요한 문장만 가져올 수 있도록 합니다. 모바일에서는 위·아래 전환 방식으로 같은 내용을 확인합니다.
