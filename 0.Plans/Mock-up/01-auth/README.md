# 01. 로그인·가입

## 화면 목적

처음 방문한 사용자가 서비스의 용도를 짧게 이해하고 Google 계정으로 시작하는 화면입니다. 가입과 로그인은 같은 진입 버튼으로 단순하게 보여줍니다.

## 주요 기능

- Google 계정으로 회원가입 또는 로그인
- 로그인 상태 유지 안내
- 다른 기기에서도 같은 작업을 이어갈 수 있다는 안내
- 이용 안내와 개인정보 안내 확인

## PC 화면

- 왼쪽에는 `가사 → 라임 → 프롬프트 → 다시 가사`로 이어지는 창작 흐름을 소개합니다.
- 오른쪽에는 로그인 카드 하나만 두어 다음 행동이 분명하게 보입니다.
- 장식보다 제품의 목적과 로그인 행동에 시선이 먼저 가도록 구성합니다.

## 모바일 화면

- 로고, 핵심 문구, 로그인 카드가 한 열로 이어집니다.
- 로그인 버튼은 화면 아래쪽 엄지 영역에서 쉽게 선택할 수 있도록 크게 표시합니다.
- 동기화 안내는 로그인 직전에 다시 확인할 수 있습니다.

## 주요 상태

- 기본 상태: Google 계정으로 계속하기
- 로그인 진행 상태: 계정을 확인하는 중
- 로그인 실패 상태: 다시 시도할 수 있는 안내
