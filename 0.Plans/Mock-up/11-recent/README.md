# 11. 최근 작업

## 화면 목적

작업을 중단한 뒤 돌아온 사용자가 자료 종류를 기억하지 않아도 멈춘 곳에서 바로 이어서 작업하는 화면입니다.

## 주요 기능

- 곡, 가사, 라임 노트, 프롬프트, 메모를 최근 수정순으로 함께 표시
- 오늘, 어제, 이전 날짜 단위로 구분
- 자료 종류, 연결 곡, 상태, 마지막 수정 시각 확인
- 마지막 편집 위치 또는 해당 자료 바로 열기
- 특정 자료 종류만 좁혀 보기

## PC 화면

- 날짜별 타임라인과 오른쪽의 현재 집중 작업 요약을 함께 보여줍니다.
- 최근에 이어서 쓸 가능성이 높은 가사에는 `계속 편집` 행동을 강조합니다.

## 모바일 화면

- 날짜 제목 아래에 카드 목록을 한 열로 배치합니다.
- 제목과 수정 시각을 우선 보여주고 연결 곡과 자료 종류를 보조 정보로 둡니다.

## 주요 상태

- 기본 상태: 오늘 작업부터 표시
- 종류 필터 적용 상태
- 빈 상태: 자료를 열거나 수정하면 이곳에 표시된다는 안내
