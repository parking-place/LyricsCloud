# 08. 프롬프트 목록

## 화면 목적

Suno에서 자주 쓰는 음악 스타일 조합을 저장하고, 열어보지 않아도 빠르게 복사하거나 유사한 버전으로 복제하는 화면입니다.

## 주요 기능

- 제목, 프롬프트 내용, 태그 검색
- 즐겨찾기, 연결 곡, 최근 사용 기준으로 목록 좁히기
- 제목, 태그형 미리보기, 최근 수정일, 즐겨찾기, 핀 확인
- 전체 프롬프트 복사
- 기존 프롬프트 복제
- 새 프롬프트 만들기

## PC 화면

- 태그를 여러 줄의 짧은 칩으로 보여주어 조합의 성격을 빠르게 파악합니다.
- 카드에서 복사, 복제, 즐겨찾기 행동을 바로 확인할 수 있습니다.
- 핀 고정과 즐겨찾기 항목은 목록 위쪽에서 구분해 보여줍니다.

## 모바일 화면

- 카드 안에는 핵심 태그만 먼저 보이고 나머지 개수를 표시합니다.
- 길게 눌러 복사할 수 있음을 보조 문구로 알려주되 `복사` 버튼을 항상 표시합니다.
- 복사 완료 메시지는 화면 아래에서 문장으로 확인합니다.

## 주요 상태

- 기본 상태: 핀과 즐겨찾기 우선
- 복사 완료: `프롬프트를 복사했습니다`
- 빈 상태: `자주 쓰는 스타일 조합을 만들어보세요`
