# 04. 곡 상세·작업 대시보드

## 화면 목적

한 곡에 연결된 가사 버전, 프롬프트, 라임 노트, 작업 메모를 한곳에서 확인하고 다음 작업을 선택하는 시작점입니다.

## 주요 기능

- 곡 제목, 설명, 작업 상태, 최근 수정 시각 확인
- 가사·프롬프트·연결 라임 노트 수 확인
- 여러 가사 버전 열기, 즐겨찾기, 복제, 삭제
- 새 가사 작성과 가사 템플릿 선택
- 곡에 연결된 라임 노트와 프롬프트 열기
- 곡 메모 작성·확인
- 곡 정보 수정, 핀, 즐겨찾기, 색상 표시

## PC 화면

- 상단에는 곡의 현재 상태와 핵심 수치를 요약합니다.
- 아래는 가사 버전 목록을 넓게, 연결 자료와 메모를 보조 열로 배치합니다.
- 최근 수정한 가사를 가장 먼저 보여주되 최종 후보와 즐겨찾기 상태도 함께 구분합니다.

## 모바일 화면

- 상태와 핵심 수치를 작은 요약 카드로 먼저 보여줍니다.
- 가사, 연결 자료, 메모는 세로 흐름으로 이어집니다.
- 새 가사 버튼은 화면 상단과 빠른 추가에서 모두 찾을 수 있습니다.

## 주요 상태

- 기본 상태: 최근 가사와 연결 자료 표시
- 가사 없음: `첫 가사를 시작해보세요`와 새 가사 버튼 표시
- 연결 자료 없음: 라임 노트 또는 프롬프트 연결 안내
