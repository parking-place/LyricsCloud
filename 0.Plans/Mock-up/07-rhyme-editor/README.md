# 07. 라임 노트 편집

## 화면 목적

형식에 얽매이지 않고 라임과 표현을 기록하고, 관련 곡에 연결하거나 가사에 가져다 쓰는 화면입니다.

## 주요 기능

- 노트 제목과 자유 형식 내용 작성
- 태그 추가·삭제
- 관련 곡 연결
- 즐겨찾기, 핀, 색상 표시
- 전체 복사와 선택 영역 복사
- 열려 있는 가사에 선택한 표현 삽입
- 자동 저장 상태와 수정 기록 확인
- 휴지통으로 이동

## PC 화면

- 넓은 노트 입력 영역과 태그·연결 곡·노트 정보 보조 영역으로 나눕니다.
- 자주 쓰는 태그는 입력 위치 가까이에서 제안합니다.
- 복사와 가사 삽입은 서로 다른 행동임을 이름과 설명으로 구분합니다.

## 모바일 화면

- 제목과 내용 입력을 먼저 보여주고 태그와 연결 곡은 아래에서 이어집니다.
- `복사`와 `가사에 삽입`을 하단 행동 영역에서 분명히 구분합니다.
- 수정 기록은 전체 화면 시트로 열어 긴 이전 내용을 읽을 수 있습니다.

## 주요 상태

- 저장됨, 저장 중, 동기화 지연
- 연결된 곡 있음·없음
- 선택한 표현을 삽입할 가사가 열려 있지 않은 상태 안내
