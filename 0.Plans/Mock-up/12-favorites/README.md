# 12. 즐겨찾기·핀 고정

## 화면 목적

자주 다시 쓰는 자료와 지금 집중하는 자료를 종류에 관계없이 한곳에서 빠르게 여는 화면입니다.

## 주요 기능

- 곡, 가사, 라임 노트, 프롬프트 즐겨찾기 모아보기
- 핀 고정 항목을 즐겨찾기보다 먼저 표시
- 자료 종류와 연결 곡으로 좁히기
- 자료 바로 열기, 핀 해제, 즐겨찾기 해제
- 최근 사용 시각 확인

## PC 화면

- `지금 집중 중`과 `즐겨찾기`를 두 구역으로 분리합니다.
- 다양한 자료가 섞여도 종류 이름과 연결 곡이 항상 보이도록 합니다.

## 모바일 화면

- 핀 고정 항목은 가로 요약 카드, 나머지는 세로 목록으로 표시합니다.
- 별과 핀은 색만 다르게 하지 않고 아이콘과 상태 문구를 함께 사용합니다.

## 주요 상태

- 핀과 즐겨찾기가 모두 있는 상태
- 특정 자료 종류만 보는 상태
- 빈 상태: 자주 쓰는 자료의 별을 눌러 모으라는 안내
