# 15. 설정

## 화면 목적

장시간 글쓰기 환경, 화면 테마, 단축키, 계정 정보를 사용자의 작업 방식에 맞추고 안전하게 관리하는 화면입니다.

## 주요 기능

- 밝은 화면, 어두운 화면, 기기 설정에 맞춤 선택
- 기본 글꼴, 글자 크기, 줄 간격, 자간 설정
- 집중 모드 기본 사용 여부 설정
- 특정 가사에만 다른 표시 설정을 적용하는 방법 안내
- 주요 키보드 단축키 확인
- 사용자 정보와 동기화 상태 확인
- 로그아웃
- 회원 탈퇴와 탈퇴 전 확인

## PC 화면

- 왼쪽에서 `화면`, `글쓰기`, `단축키`, `계정` 항목을 고르고 오른쪽에서 세부 내용을 봅니다.
- 글쓰기 설정 옆에는 짧은 가사 미리보기를 두어 변화의 의미를 이해할 수 있게 합니다.
- 회원 탈퇴는 다른 설정과 분리된 경고 구역에 둡니다.

## 모바일 화면

- 설정 항목이 세로 목록으로 이어지며 각 항목의 현재 값을 함께 표시합니다.
- 글꼴·간격 조절은 별도 시트에서 미리보기와 함께 확인합니다.
- 로그아웃과 회원 탈퇴는 화면 가장 아래에 배치합니다.

## 키보드 안내

- 새 자료 추가
- 통합 검색
- 가사 전체 복사
- 집중 모드 전환
- 자료 패널 열기·닫기
- 이전·다음 가사 이동
- 단축키를 사용하지 않는 사람도 모든 기능을 화면에서 찾을 수 있어야 합니다.

## 주요 상태

- 설정 변경 후 자동 반영 안내
- 동기화 정상·지연 상태
- 로그아웃 확인
- 회원 탈퇴 확인: 보관된 자료가 사라지고 되돌릴 수 없음을 명시
