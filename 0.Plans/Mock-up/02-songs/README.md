# 02. 곡 목록

## 화면 목적

사용자가 작업 중인 곡을 상태와 우선순위 중심으로 훑어보고 곧바로 이어서 작업하는 메인 화면입니다.

## 주요 기능

- 곡 제목 또는 가사 내용 검색
- 최근 수정순, 최근 생성순, 오래된 순, 제목순, 즐겨찾기 우선 정렬
- 작업 상태, 색상, 연결 자료 기준으로 목록 좁히기
- 제목, 메모, 가사 수, 최근 수정일, 상태, 즐겨찾기, 핀 확인
- 새 곡 만들기와 빠른 추가

## PC 화면

- 좌측 메뉴와 상단 창작 공간 탭을 함께 사용합니다.
- 카드 2열로 정보를 충분히 보여주고, 핀 고정 곡을 먼저 배치합니다.
- 검색, 상태 필터, 정렬을 한 줄에 두어 많은 곡을 빠르게 정리할 수 있습니다.

## 모바일 화면

- 곡 카드는 한 열로 보여주며 제목, 메모, 상태, 가사 수, 수정일을 두 줄 안에서 확인할 수 있습니다.
- 상태 필터는 가로로 넘겨보는 칩 형태입니다.
- 하단 메뉴 위의 `+` 버튼으로 새 곡, 가사, 라임, 프롬프트를 빠르게 추가합니다.
- 길게 누르지 않아도 카드의 더보기 위치에서 주요 행동을 확인할 수 있습니다.

## 주요 상태

- 기본 상태: 핀 고정 곡과 최근 수정 곡이 함께 표시됨
- 필터 상태: 적용 중인 조건과 `초기화`가 함께 표시됨
- 빈 상태: `첫 번째 곡을 만들어보세요`와 새 곡 버튼 표시

## 추가 제안

상태뿐 아니라 `연결 자료 있음`, `가사 없음` 같은 작업 조건으로도 목록을 좁힐 수 있게 하여 다음 작업이 필요한 곡을 빨리 찾습니다.
