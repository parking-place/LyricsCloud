# LyricsCloud 화면 설계·목업 모음

`Sketch.md`의 기능을 실제 화면 단위로 다시 묶은 문서와 정적 목업입니다. 화면 구성과 사용자 경험만 다루며, 기술 선택·데이터 구조·개발 방식은 포함하지 않습니다.

## 보는 방법

- [`index.html`](./index.html): 전체 화면 목록
- 각 폴더의 `README.md`: 해당 페이지의 목적, 기능, PC·모바일 구성, 주요 상태
- 각 폴더의 `mockup.html`: 같은 페이지의 PC 화면과 모바일 화면 비교
- 모든 목업의 버튼과 입력 요소는 화면 검토용이며 실제로 동작하지 않습니다.

## 공통 화면 원칙

- PC에서는 세 가지 창작 공간(곡·가사, 라임 노트, 프롬프트)을 상단에서 전환하고, 최근 작업·즐겨찾기·검색·휴지통·설정은 좌측 메뉴에서 찾습니다.
- 모바일에서는 한 화면에 하나의 주요 작업만 보여주며, 핵심 공간은 하단 메뉴로 이동합니다.
- 가사 편집 화면은 PC에서 좌측 송폼 탐색, 중앙 편집기, 우측 자료 패널의 3단 구성을 사용합니다. 모바일에서는 편집기를 중심에 두고 자료와 송폼 목록을 별도 시트로 엽니다.
- 상태·우선순위는 색상만으로 구분하지 않고 항상 상태명이나 아이콘을 함께 표시합니다.
- 모바일의 길게 눌러 복사는 보조 동작이며, 모든 복사 대상에는 눈에 보이는 복사 버튼도 둡니다.
- 저장과 복사 결과는 `방금 저장됨`, `가사를 복사했습니다`처럼 문장으로 확인할 수 있습니다.

## 기획에 보완한 항목

원문 방향을 해치지 않는 범위에서 아래 내용을 문서와 목업에 함께 반영했습니다.

- 가사 두 버전을 나란히 확인하는 `버전 비교`
- 목록에서 상태·연결 곡·태그를 함께 좁힐 수 있는 필터
- 모바일에서 곡·라임·메모를 즉시 적는 `빠른 아이디어`
- 자동 저장 옆에 저장 중·동기화 지연 상태를 명확히 알리는 문구
- 드래그가 어려운 사용자를 위한 프롬프트 태그 `앞으로`·`뒤로` 이동 수단
