# 09. 프롬프트 편집

## 화면 목적

Suno 프롬프트를 독립된 태그 단위로 구성하고, 중복 없이 원하는 순서로 정리해 바로 복사하는 화면입니다.

## 주요 기능

- 프롬프트 제목 작성
- 쉼표로 나뉜 요소를 태그 형태로 확인·수정
- 과거에 사용한 태그 자동 제안
- 중복 태그 발견과 한 번에 정리
- 태그 순서 변경
- 프롬프트 템플릿 불러오기
- 관련 곡 연결
- 전체 복사, 복제, 즐겨찾기, 수정 기록, 삭제
- 자동 저장 상태 확인

## PC 화면

- 넓은 태그 구성 영역과 자동완성·연결 곡·프롬프트 정보 영역으로 나눕니다.
- 각 태그에 순서 손잡이와 삭제 위치를 보여줍니다.
- 중복 항목은 태그 자체와 별도 안내 문장 두 곳에서 확인할 수 있습니다.

## 모바일 화면

- 태그를 두세 줄 안에서 훑을 수 있도록 줄바꿈합니다.
- 끌어서 옮기기 외에도 선택한 태그를 `앞으로`, `뒤로` 이동하는 행동을 제공합니다.
- 전체 복사 버튼은 키보드가 열린 상태에서도 쉽게 찾을 수 있습니다.

## 주요 상태

- 자동완성: 입력 중인 글자와 일치하는 과거 태그 제안
- 중복: 이미 포함된 항목명과 정리 버튼 표시
- 복사 완료: 쉼표로 정리된 최종 문자열이 복사되었음을 안내

## 추가 제안

손가락이나 키보드로도 순서를 정확히 바꿀 수 있도록 드래그 외의 이동 수단을 함께 제공합니다.
