# 10. 통합 검색

## 화면 목적

곡, 가사, 라임 노트, 프롬프트가 어디에 있든 하나의 검색어로 찾아 원래 작업 위치를 바로 여는 화면입니다.

## 주요 기능

- 곡 제목, 가사 제목·내용, 라임 노트 제목·내용, 프롬프트 제목·내용·태그 검색
- 전체 또는 자료 종류별 결과 좁히기
- 검색어가 포함된 문장 일부와 연결된 곡 확인
- 결과 선택 후 해당 자료 또는 편집 위치 바로 열기
- 최근 검색어와 검색 전 안내

## PC 화면

- 넓은 검색 입력란과 종류별 필터를 상단에 둡니다.
- 결과는 `곡`, `가사`, `라임 노트`, `프롬프트` 그룹으로 나누어 보여줍니다.
- 종류는 색상뿐 아니라 텍스트 배지와 아이콘으로도 구분합니다.

## 모바일 화면

- 검색 입력란을 화면 상단에서 가장 크게 보여줍니다.
- 결과 종류 필터는 가로 칩으로 넘겨봅니다.
- 각 결과는 제목, 종류, 일치 문장, 연결 곡 순서로 짧게 보여줍니다.

## 주요 상태

- 검색 전: 검색 가능한 범위와 최근 검색어 안내
- 결과 있음: 검색어 강조와 전체 결과 수 표시
- 결과 없음: 철자 또는 다른 표현으로 다시 검색하도록 안내
