# 1.0.4 — 문장형 프롬프트 표시·1,000자 경고

상태: **계획 검토 / 구현 미착수**. 번호는 미발행 작업 배정이며 배포 승인이 아니다.

## 목표

문장형을 마침표 기준으로 보기 좋게 표시하고 모든 프롬프트 복사 경로에서 동일한 1,000자 초과 경고를 제공한다.

## 요구사항

`NF-REQ-022`, `NF-REQ-023`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 선행조건과 승인

- [1.0.3 P5](../1.0.3/5phase.md)의 실제 인수와 현재 파일 담당 경계 확인.

## 설계의 고정 조건

- U+002E 마침표를 포함하는 lossless span으로 표시하며 span 연결이 정확히 raw가 되게 한다.
- 1,000자는 최종 복사 payload의 Unicode code point 수로 정하고 공백·줄바꿈도 포함한다.
- 경고는 초과 시 안내만 한다. 입력·저장·복사를 차단하거나 자동으로 줄이지 않는다.

## 대표 수용 사례

| ID | 입력·상황 | 기대 결과 |
|---|---|---|
| `AC-1.0.4-01` | a.. b. / 3.5 / https://example.invalid/a.b / 끝 미완성 | 표시 구간을 이어붙이면 원문과 완전히 같다. |
| `AC-1.0.4-02` | 최종 복사 999·1000·1001자 | 1001에만 초과 경고가 생기며 세 경우 모두 복사된다. |
| `AC-1.0.4-03` | emoji·분해 한글·CRLF가 섞인 자료 | 계약된 문자 수와 copy payload가 일치한다. |
| `AC-1.0.4-04` | 같은 자료를 목록/패널/편집기에서 복사 | 출력 및 길이 경고 판정이 같다. |

## 범위 밖

다른 패치의 신규 기능·사용자 미선택 아이디어·승인 없는 운영/플랫폼 변경은 제외한다.
