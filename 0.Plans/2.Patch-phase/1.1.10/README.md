# 1.1.10 — Android 네이티브 개발안·읽기와 복사

상태: **계획 검토 / 구현 미착수**. 번호는 미발행 작업 배정이며 배포 승인이 아니다.

## 목표

Android 앱의 UI·인증·수명주기 개발안을 승인받고 읽기·복사의 최소 앱을 별도로 검증한다.

## 요구사항

`NF-REQ-041`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 선행조건과 승인

- [1.1.9 P5](../1.1.9/5phase.md)의 실제 인수와 현재 파일 담당 경계 확인.
- 네이티브 개발안/기술 실험과 실제 구현 승인을 구분한다. 플랫폼별 사용자 승인이 없으면 P2로 진행하지 않는다.

## 설계의 고정 조건

- 네이티브 개발안 문서화와 실제 구현 승인을 구분한다. Windows 기술 승인이 Android 선택을 대신하지 않는다.
- Kotlin/Compose와 필요한 editor/CRDT adapter 후보를 Gboard/Samsung Keyboard·프로세스 복구 실험으로 비교한다.
- Google 플랫폼 공식 sign-in/시스템 브라우저 인증과 API access를 구분하고 web client secret을 binary에 넣지 않는다.

## 대표 수용 사례

| ID | 입력·상황 | 기대 결과 |
|---|---|---|
| `AC-1.1.10-01` | 기술/구현 승인 없음 | 개발안·실험 증거만 남기고 앱 코드를 배포하지 않는다. |
| `AC-1.1.10-02` | 회전/메모리 회수 중 로그인·조회 | 잘못된 계정 세션이 생성되지 않고 상태가 안전하게 복구된다. |
| `AC-1.1.10-03` | 웹/Android 같은 자료 복사 | 출력 계약과 경고 단위가 같다. |
| `AC-1.1.10-04` | 공유 권한 철회/서버 지원 종료 | API/cache 접근이 정책대로 제한되며 안내가 제공된다. |

## 범위 밖

다른 패치의 신규 기능·사용자 미선택 아이디어·승인 없는 운영/플랫폼 변경은 제외한다.
