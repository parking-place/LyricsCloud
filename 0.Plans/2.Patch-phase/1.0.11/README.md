# 1.0.11 — Suno 링크 미리보기·안전한 메타데이터

상태: **계획 검토 / 구현 미착수**. 번호는 미발행 작업 배정이며 배포 승인이 아니다.

## 목표

허용된 공식 경로로 가져올 수 있는 제목·재생시간·썸네일을 작업 링크 카드에 표시한다.

## 요구사항

`NF-REQ-032`, `NF-REQ-033`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 선행조건과 승인

- [1.0.10 P5](../1.0.10/5phase.md)의 실제 인수와 현재 파일 담당 경계 확인.

2. [P2 — 핵심 기반·저장과 서버](2phase.md)

## 설계의 고정 조건

- 자동 metadata의 공식 접근 가능 범위와 이용 조건을 구현 시 확인한다. 비공개 곡 인증·스크래핑 우회는 금지한다.
- 수동 링크는 자동 조회 실패와 무관하게 사용 가능해야 한다. 실패를 성공으로 표시하지 않는다.
- 외부 조회는 SSRF·리다이렉트·DNS·크기/시간·이미지 추적 문제를 별도로 다룬다.

## 대표 수용 사례

| ID | 입력·상황 | 기대 결과 |
|---|---|---|
| `AC-1.0.11-01` | 정상 공개 링크와 공식적으로 얻을 수 있는 metadata | 세 필드가 검증된 값으로 표시되고 새 탭 열기가 된다. |
| `AC-1.0.11-02` | 외부 주소가 redirect로 127.0.0.1/사설망 이동 | 요청을 차단하며 내부 응답은 사용자에게 노출하지 않는다. |
| `AC-1.0.11-03` | 404·429·비공개·썸네일 오류 | 저장된 링크가 사라지지 않고 수동 정보로 사용할 수 있다. |
| `AC-1.0.11-04` | 공식 자동 취득 경로를 확보하지 못함 | 해당 수용조건을 미완료로 남기고 우회 구현 없이 별도 범위 승인을 요청한다. |

## 범위 밖

다른 패치의 신규 기능·사용자 미선택 아이디어·승인 없는 운영/플랫폼 변경은 제외한다.
