- 상태: **완료 — no-go** (`complete`, 공식 provider 계약 부재로 구현 중단)
- 단계 목적: Suno 링크 미리보기·안전한 메타데이터의 계약·실패 사례·담당 경계을 완료하고 다음 단계에 검증 가능한 입력을 전달한다.

## 포함 범위

`NF-REQ-032`, `NF-REQ-033`. 아래 작업에서 다루는 현재 패치의 범위만 수행한다. 여러 버전에 걸친 요구는 이 패치의 부분 범위를 검증한 것으로 기록한다.

## 제외 범위

다른 패치의 기능·사용자가 선택하지 않은 Future 아이디어·승인 없는 기술 교체·운영 변경은 제외한다.

## 수정 책임 경로와 인터페이스

- `apps/worker/src`
- `packages/database/src`
- `apps/web/src/components`
- `packages/config/src`
- `tests/e2e`

경로는 책임 영역이다. 신규 제안 표시는 아직 생성된 파일이 아니며 실제 이름·runner·package export는 P1 인수에서 확정한다. 디렉터리 전체를 리팩터링하라는 권한이 아니다. **입력**은 선행 계약·source SHA·fixture·권한 문맥이고 **출력**은 현 단계의 코드/설계·실행 증거·후속 호환 계약이다.

## 작업 체크리스트

- [x] `LC-NF-1.0.11-P1-01` 공식 Platform·현행 이용약관을 확인했다. 기존 링크 metadata 공개 계약은 확인되지 않았고 인증 우회·스크래핑은 금지했다.
- [x] `LC-NF-1.0.11-P1-02` 1.0.10 수동 링크 계약을 불변으로 두고 자동 조회 성공을 주장하지 않았다.
- [x] `LC-NF-1.0.11-P1-03` 공식 provider가 생길 때만 SSRF·리다이렉트·DNS·크기/시간·이미지 추적 경계를 구현한다. 현재는 outbound 요청 자체를 추가하지 않는다.
- [x] `LC-NF-1.0.11-P1-04` 정상 provider 부재를 `AC-1.0.11-04`로 판정하고 01~03을 실행 불가/미완료로 기록했다.
- [x] `LC-NF-1.0.11-P1-05` schema·API·순서·copy·권한은 변경하지 않으며 runtime 되돌림이 필요 없는 no-go를 ADR에 기록했다.
- [x] `LC-NF-1.0.11-P1-06` 문서 담당 경계와 출발 source `e13e7635354588baee08b25250d8bc43e2545a8e`를 [P1 인수 기록](../../../docs/runbooks/1.0.11-phase1-provider-gate.md)에 고정했다.

## 구체적 검증

| 수용 ID | 입력·상황 | 기대 결과 |
|---|---|---|
| `AC-1.0.11-01` | 정상 공개 링크와 공식적으로 얻을 수 있는 metadata | 세 필드가 검증된 값으로 표시되고 새 탭 열기가 된다. |
| `AC-1.0.11-02` | 외부 주소가 redirect로 127.0.0.1/사설망 이동 | 요청을 차단하며 내부 응답은 사용자에게 노출하지 않는다. |
| `AC-1.0.11-03` | 404·429·비공개·썸네일 오류 | 저장된 링크가 사라지지 않고 수동 정보로 사용할 수 있다. |
| `AC-1.0.11-04` | 공식 자동 취득 경로를 확보하지 못함 | 해당 수용조건을 미완료로 남기고 우회 구현 없이 별도 범위 승인을 요청한다. |

P1은 위 기대 결과와 실제 구현 가능 경계를 승인하는 단계다. P2/P3은 관련 재현·수정과 사용자 흐름을 실행하며, P4에서 전체 교차 검증하고 P5에서 실제 결과를 인수한다. 표가 있다는 이유로 테스트 완료로 처리하지 않는다.

## 실행·증거 기록

[공통 명령·검증](../QUALITY-GATES.md)을 먼저 읽는다. 기존 runner의 영향받은 검사를 우선 사용하고 필요할 때만 회귀를 보강한다. 지원 환경에서 관련 DB/E2E를 선택하며 동일 변경의 full suite는 로컬/CI 중 한 곳과 필수 게이트만 따른다. native은 승인된 SDK/플랫폼 명령을 기록한다. 없는 도구·실제 IME·물리 기기 검증을 모사 결과로 통과시켰다고 표시하지 않는다. 문서-only Phase는 링크·범위·결정·설계 검토로 별도 인수한다.

- [x] 제품 코드·개발 배포·main Release·운영을 변경하지 않았다.
