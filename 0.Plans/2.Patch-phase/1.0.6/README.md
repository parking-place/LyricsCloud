# 1.0.6 — Extend 작업 메모·송폼 삽입 메뉴

상태: **P2 완료 / P3 착수**. 2026-09-11 사용자가 1.0.14까지의 Phase 실행과 각 버전 정식 릴리스를 승인했다. 구현·검증·동일 SHA 개발 인수 뒤에만 이 버전의 릴리스 권한을 소비한다.

## 목표

Extend 표식은 원문에 남기면서 Suno 전체 복사에서 제외하고, 현재 커서에 기본 송폼을 안전하게 삽입한다.

## 요구사항

`NF-REQ-026`, `NF-REQ-027`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 설계의 고정 조건

- 정확한 Extend 표식의 토큰/행 제거 범위를 정한다. 뒤의 가사 섹션까지 삭제하지 않는다.
- [Extend: 3:00:24] 시간 문자열은 사용자 메모로 보존하고 임의 시간 단위 변환을 하지 않는다.
- 우클릭은 보조 수단이다. 키보드 호출과 모바일 보이는 삽입 버튼을 함께 둔다.
- 기본 메뉴는 `Intro`, `Verse`, `Pre-Chorus`, `Chorus`, `Hook`, `Bridge`, `Outro`의 정식 marker를 한 단일 source에서 제공한다.
- 우클릭은 브라우저 기본 메뉴를 강제로 없애지 않고 삽입 메뉴를 준비한다. 키보드 메뉴키/`Shift+F10`과 모바일의 보이는 버튼은 같은 메뉴와 명령을 사용한다.
- 클릭 때 캡처한 CRDT 상대 caret을 실행 때 해석하고, 선택 본문을 삭제하지 않은 채 한 transaction으로 삽입한다. 해석 실패·IME 조합 중에는 원문을 바꾸지 않고 안내한다.
