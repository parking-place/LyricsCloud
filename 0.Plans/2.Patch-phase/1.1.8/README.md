# 1.1.8 — Windows 네이티브 개발안·읽기와 복사

상태: **계획 검토 / 구현 미착수**. 번호는 미발행 작업 배정이며 배포 승인이 아니다.

## 목표

Windows 앱의 기술·인증·IME/CRDT 개발안을 먼저 승인받고, 승인된 경우 읽기·복사 중심의 최소 앱을 제공한다.

## 요구사항

`NF-REQ-040`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 선행조건과 승인

- [1.1.7 P5](../1.1.7/5phase.md)의 실제 인수와 현재 파일 담당 경계 확인.
- 네이티브 개발안/기술 실험과 실제 구현 승인을 구분한다. 플랫폼별 사용자 승인이 없으면 P2로 진행하지 않는다.

## 설계의 고정 조건

- 필수 요청은 네이티브 개발안이며 실제 앱 구현은 사용자 승인 이후만 진행한다. 승인 전 P2 진입을 막는다.
- WinUI/Avalonia/부분 WebView 등 후보를 비교하고 한국어 편집·Yjs 호환의 최소 실험을 수행한다.
- 첫 앱 범위는 읽기·복사이며 편집 완료 제품으로 설명하지 않는다. 문서/실험만으로 release tag를 발행하지 않는다.

## 대표 수용 사례

| ID | 입력·상황 | 기대 결과 |
|---|---|---|
| `AC-1.1.8-01` | 네이티브 기술·범위 승인이 없음 | 개발안/실험 보고서만 전달하고 앱 구현·발행을 하지 않는다. |
| `AC-1.1.8-02` | 시스템 브라우저 인증 취소/잘못된 callback | 세션이 생성되거나 다른 앱으로 token이 전달되지 않는다. |
| `AC-1.1.8-03` | 계정 전환·공유 회수 후 캐시 읽기 | 권한 없는 새 자료를 읽거나 다른 계정 cache를 보여주지 않는다. |
| `AC-1.1.8-04` | 웹/Windows 동일 자료 복사 | 문장형·송폼·Extend·길이 경고 계약이 같다. |
