# 1.0.1 — 입력 무결성·베타코드·Private Beta 필수 마감

상태: **실행 중 / P1~P7 개발 인수 완료, P8 active**. 번호는 P10 정식 인수 전까지 미발행 작업 배정이다.

## 목표

실제 Windows 한글 입력과 고장 UI를 복구하고 해시 기반 허용 목록·일회용 베타코드 가입을 안전하게 운영할 준비를 마친다.

## 요구사항

`NF-REQ-001`, `NF-REQ-002`, `NF-REQ-003`, `NF-REQ-004`, `NF-REQ-005`, `NF-REQ-006`, `NF-REQ-007`, `NF-REQ-008`, `NF-REQ-009`, `NF-REQ-010`, `NF-REQ-011`, `NF-REQ-012`, `NF-REQ-013`, `NF-REQ-014`, `NF-REQ-015`, `NF-REQ-016`, `NF-REQ-017`, `NF-REQ-018`, `NF-REQ-019`, `NF-REQ-020`, `NF-REQ-021`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 선행조건과 승인

- P6 실제 최종 SHA·결함·검증 인수의 실제 인수와 현재 파일 담당 경계 확인.

## 설계의 고정 조건

- P6 최종 코드·데이터 보존 결함을 인수한다.
- 해시 허용 목록과 원자적인 베타 가입을 승인한다.
- 메이저 고정·패치 우선·릴리스 별칭 정책을 적용한다.
