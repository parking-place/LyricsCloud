# 1.0.1 Phase 6 — 공개 개발 UI 버튼·테마·겹침·사이드바 복구

상태: **개발 배포 대기**. 공통 primary action과 겹침·rail 원인을 수정하고 로컬 양 테마·반응형 회귀를 통과했다.

## 목표와 경계

동일 SHA의 dev.example.test에서 다크모드·새 가사·연결 관리 버튼을 실제 클릭/키보드로 확인한다. localhost만 통과해 종료하지 않는다.

담당 경로: web components·공통 UI·스타일·portal. 정확한 파일·명령은 착수 당시 소스로 확정한다. 다른 Phase 기능·후속 선택 아이디어·승인 없는 운영 변경은 포함하지 않는다.

## 선행조건·입출력

- [P5](5phase.md)의 산출물·해당 구현 인수, 소비할 ADR/PROD/OPS와 파일 소유권을 확인한다.
- 입력은 정확한 SHA·계약·합성 fixture·실제 환경과 잔여 결함이다. 출력은 아래 작업의 산출물과 수용 증거·실패 복구·다음 담당자의 경계다.
- [베타 계약](../contracts/BETA-ACCESS.md), [버전 정책](../VERSIONING.md), [릴리스 정책](../RELEASE-POLICY.md), [품질 게이트](../QUALITY-GATES.md)를 소비한다.
- P2는 P1의 승인된 코드/운영 계약을 즉시 소비한다. P3/P4 전에는 신규 가입을 열지 않으며 CLI 인수를 UI·로고 최종 승인까지 기다리게 하지 않는다.

## 작업 체크리스트

- [x] `LC-NF-1.0.1-P6-01` 우상단 다크모드 버튼, 새 가사, 연결 관리의 클릭 불능과 테마 미적용을 각각 수정한다. CSP 완화나 전역 이벤트 무시로 우회하지 않는다.
- [x] `LC-NF-1.0.1-P6-02` 겹침 현상과 닫힌 좌측 사이드바의 아이콘을 공통 크기·viewBox·flex-shrink·z-index·포커스 규칙으로 수정한다. PC·모바일·200% 확대에서 확인한다.
- [x] `LC-NF-1.0.1-P6-03` CSP·정적 asset·service worker·portal 이벤트 경계를 실제 개발 SHA에서 대조하고 버튼 재현 원인만 수정한다.

## 구체적 수용 기준

1. 동일 SHA의 dev.example.test에서 다크모드·새 가사·연결 관리 버튼을 실제 클릭/키보드로 확인한다. localhost만 통과해 종료하지 않는다.
2. light/dark·portal·접힘/펼침·PC/모바일·200% 확대·가상 키보드에서 겹침과 sidebar icon 오류를 확인한다.

## 검증과 완료 조건

- [ ] 영향받은 실제 트리거와 결과를 기존 검사 중심으로 검증하고 명령·환경·SHA·미실행을 기록했다. 동일 입력/환경의 성공 증거를 재사용한다.
- [ ] 원문·권한·기존 사용자·복구 불변조건과 위 수용 기준에 실제 증거가 있다.
- [ ] 구현 Phase의 필수 CI·동일 SHA 개발 배포·공개 smoke와 상태 기록을 인수했다. 문서-only 변경은 링크·범위·결정 검토로 구분했다.
- [ ] [FUTURE-INTAKE](../FUTURE-INTAKE.md)에 따라 저장소 전역 Future 변경을 push 전 및 Phase 완료 때 한 번 대조하고 동일 변경은 재처리하지 않았다.
- [ ] 실제 OS/기기·Google 설정·백업·외부 승인 잔여를 숨기지 않았으며 main/release 서버 변경을 별도 현재 승인 없이 실행하지 않았다.
