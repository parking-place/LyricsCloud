# 1.0.7 — 목록 보기 선택·밀도 설정

상태: **P1 계약 완료 / P2 구현 대기**. 번호는 현재 작업 배정이며 릴리스 완료 표시는 아니다.

## 목표

곡·라임 노트·프롬프트 목록에서 리스트와 소·중·대 그리드를 선택하고 개인별로 기억한다.

## 요구사항

`NF-REQ-029`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 선행조건과 승인

- [1.0.6 P5](../1.0.6/5phase.md)의 실제 인수와 현재 파일 담당 경계 확인.

## 다섯 Phase

1. [P1 — 계약·실패 사례·담당 경계](1phase.md) — 완료
2. [P2 — 핵심 기반·저장과 서버](2phase.md)
3. [P3 — PC·모바일 사용자 흐름](3phase.md)
4. [P4 — 실패·권한·복구 회귀](4phase.md)
5. [P5 — 문서·개발 인수·후속 연결](5phase.md)

## 설계의 고정 조건

- 보기 설정은 자료 유형별 개인 설정이고 자료 자체·다른 사용자의 화면을 바꾸지 않는다.
- 그리드 크기 변경은 정렬 명령이 아니다. 기존 순서와 필터를 유지한다.
- 좁은 화면에서 큰 그리드는 안전하게 한 열로 표시하고 긴 제목은 접근 가능한 대안을 둔다.

## 대표 수용 사례

| ID | 입력·상황 | 기대 결과 |
|---|---|---|
| `AC-1.0.7-01` | 검색·필터·현재 페이지 상태에서 보기 4종 전환 | 같은 자료 집합과 순서를 유지한다. |
| `AC-1.0.7-02` | 계정 A는 리스트, B는 큰 그리드 | 계정 전환으로 A의 설정이 B에 새지 않는다. |
| `AC-1.0.7-03` | 320px·200% 확대·긴 한글 제목 | 액션과 내용이 겹치지 않고 키보드 이동이 가능하다. |
| `AC-1.0.7-04` | 다른 탭이 글꼴 설정 갱신 중 밀도 저장 | 무관한 글꼴 설정을 되돌리지 않는다. |

## 범위 밖

다른 패치의 신규 기능·사용자 미선택 아이디어·승인 없는 운영/플랫폼 변경은 제외한다.

[세부 계약](../contracts/LIBRARY-SUNO.md) · [품질 게이트](../QUALITY-GATES.md) · [버전 규칙](../VERSIONING.md) · [릴리스 정책](../RELEASE-POLICY.md). 코드가 바뀌지 않은 연구/검증만으로 제품 tag를 발행하지 않는다. P5는 후보 인수이며 정식 main/Release/운영 변경은 별도 현재 승인 뒤 실행한다.
