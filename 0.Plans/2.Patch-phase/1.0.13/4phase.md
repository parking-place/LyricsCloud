# 1.0.13 Phase 4 — 세 언어·접근성·실패 인수

상태: **blocked**. 실제 provider와 P2~P3 구현이 없어 세 언어·실제 OS/기기 수용을 수행하지 않았다.

## 선행조건과 담당 경계

[P3](3phase.md)의 실제 산출물과 [결정 권한](../Decision-Ownership.md)을 인수한다. [세부 계약](../contracts/DICTIONARY-FONTS.md)을 따른다. 정확한 파일·SDK·명령은 착수 때 기존 구조 안에서 확정한다. 입력은 승인 범위·source SHA·fixture·실제 환경, 출력은 아래 산출물·수용 증거·미실행과 다음 단계 조건이다. 공통 파일은 한 작성자만 맡는다.

## 작업 체크리스트

- [ ] `LC-NF-1.0.13-P4-01` 세 언어의 없는 단어·동음어·혼합문장·로딩/오류·연속 이동을 시험한다. mock 응답과 실제 제공자 결과를 구별한다.
- [ ] `LC-NF-1.0.13-P4-02` 실제 Windows 한국어 IME, 일본어 입력, 모바일 터치와 화면 낭독 focus를 확인한다.
- [ ] `LC-NF-1.0.13-P4-03` 제공자 장애/허용 철회 때 조회만 비활성화하고 기존 단어·창작물·copy가 보존되는지 확인한다.

## 수용 기준

`AC-1.0.13-04`: 언어별 실제 이용 가능성·권리 증거와 UI 수용이 모두 있고 지원 불가 언어는 명확히 미완료로 남는다.

## 검증·완료·인계

- [ ] 위 작업과 수용 기준에 실제 증거·환경·SHA를 연결하고 실패/미실행을 기록했다.
- [ ] 원문·인가·복구·기존 사용자 계약을 유지하고 [품질 게이트](../QUALITY-GATES.md)의 영향 검사만 수행했다. 같은 성공 결과를 반복하지 않았다.
- [ ] 설계/문서 단계는 검토와 결정 증거로, 구현 단계는 필수 CI·동일 SHA 개발 공개 smoke 및 플랫폼별 실제 앱 증거로 인수했다.
- [ ] [Future 검수](../FUTURE-INTAKE.md)를 push 전/Phase 완료 시 대조하고 같은 변경은 이전 기록을 참조했다.
- [ ] SDK/외부 제공·실제 OS/기기·서명/스토어·release gate의 상태를 숨기지 않았다.

[P5](5phase.md)에 산출물·지원 범위·계약·남은 gate를 전달한다. 모든 배정 Phase 인수 뒤에도 main/release 서버 변경은 [릴리스 정책](../RELEASE-POLICY.md)의 별도 현재 승인을 따른다.
