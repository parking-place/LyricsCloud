# 1.0.13 Phase 1 — 제공 경로·사용 조건 검증

상태: **완료 / no-go**. 2026-09-12 공식 공개 제공 경로·권리 gate 부재를 확인했고 P2~P4를 보류했다.

## 선행조건과 담당 경계

[1.0.12](../1.0.12/README.md)의 실제 산출물과 [결정 권한](../Decision-Ownership.md)을 인수한다. [세부 계약](../contracts/DICTIONARY-FONTS.md)을 따른다. 정확한 파일·SDK·명령은 착수 때 기존 구조 안에서 확정한다. 입력은 승인 범위·source SHA·fixture·실제 환경, 출력은 아래 산출물·수용 증거·미실행과 다음 단계 조건이다. 공통 파일은 한 작성자만 맡는다.

## 작업 체크리스트

- [x] `LC-NF-1.0.13-P1-01` 공식 NAVER API 목록·이용약관을 확인하고 세 언어 모두 공개 뜻풀이 경로·신청/인증·비용·출처/캐시 권리 미확인을 ADR-NF-006에 기록했다. 백과사전 검색을 사전 API로 대체하지 않았다.
- [x] `LC-NF-1.0.13-P1-02` hover/focus/터치·언어 교정·짧은 뜻·원문 링크와 IME/selection/copy 불변조건을 PROD-NF-007에 정의했다.
- [x] `LC-NF-1.0.13-P1-03` 정식 제휴·권리가 확인된 다른 provider·새 탭 보조 대안을 비교하고, 앞의 두 계약만 재개 조건으로 인정하며 단순 링크는 tooltip 완료로 세지 않도록 판정했다.

## 수용 기준

`AC-1.0.13-01`: **PASS (no-go)**. 한국어·영어·일어별 제공/조건 표와 보류 이유·재개 조건이 있고 미확인 API를 전제로 코딩하지 않았다.

## 검증·완료·인계

- [x] 공식 웹 문서 확인 환경과 판정일을 연결하고 실제 제공자 요청·SDK·구현·기기 검증 미실행을 기록했다.
- [x] runtime·DB·API·UI를 변경하지 않아 원문·인가·복구·기존 사용자 계약을 그대로 유지했다.
- [x] 설계/문서 no-go이므로 구현 CI·동일 SHA 개발 공개 smoke를 성공으로 가장하지 않았다.
- [x] [Future 검수](../FUTURE-INTAKE.md)를 push 전 대조했고 원본 blob이 동일함을 확인했다.
- [x] 외부 제공·실제 OS/기기·정식 제품 release gate의 미완료 상태를 숨기지 않았다.

[P2](2phase.md)에 산출물·지원 범위·계약·남은 gate를 전달한다. 모든 배정 Phase 인수 뒤에도 main/release 서버 변경은 [릴리스 정책](../RELEASE-POLICY.md)의 별도 현재 승인을 따른다.
