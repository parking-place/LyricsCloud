# 1.0.13 — 라임노트 다국어 NAVER 사전 조회

상태: **계획 검토 / 구현 미착수**. 미발행 배정이며 실제 발행 시 다음 가용 patch를 재확인한다. 요구 `NF-REQ-043`를 [전체 추적표](../Requirements-Traceability.md)로 연결한다.

선행: [1.0.12](../1.0.12/README.md)의 인수와 해당 결정 gate. 코드 변경 없는 개발안/외부 gate 보류는 제품 출시로 세지 않는다.

## 대표 수용과 범위

- `AC-1.0.13-01`: 한국어·영어·일어별 제공/조건 표와 승인 또는 보류 이유가 있고 미확인 API를 전제로 코딩하지 않는다.
- `AC-1.0.13-02`: 승인된 fixture와 허용 실제 요청에서 성공/timeout/429/빈 결과가 구별되고 오류가 편집·저장을 막지 않는다.
- `AC-1.0.13-03`: 마냥/bright/光 같은 합성 입력에서 언어별 결과와 원문 출처가 맞고 키보드/터치·IME를 방해하지 않는다.
- `AC-1.0.13-04`: 언어별 실제 이용 가능성·권리 증거와 UI 수용이 모두 있고 지원 불가 언어는 명확히 미완료로 남는다.
- `AC-1.0.13-05`: 사용자 요구의 tooltip과 세 언어가 검증됐거나 정확한 미완료 상태가 기록돼 있다.
