# 1.0.2 — Private Beta 초기 사용 안정화

상태: **P1~P5 후보 인수 완료**. 계약, 핵심 저장·서버, 복구 사용자 흐름, 교차 회귀와 최종 전체 CI·동일 SHA 개발 인수를 완료했다. 정식 배포 승인은 아니다.

## 목표

1.0.1 실제 사용에서 보고된 결함을 닫고 초대 가입·저장·배포의 운영 회귀를 보강한다. 새 창작 기능을 섞지 않는다.

## 요구사항

`NF-REQ-001`, `NF-REQ-002`, `NF-REQ-003`, `NF-REQ-004`, `NF-REQ-005`, `NF-REQ-006`, `NF-REQ-007`, `NF-REQ-008`, `NF-REQ-011`, `NF-REQ-012`, `NF-REQ-014`, `NF-REQ-015`, `NF-REQ-019`, `NF-REQ-020`, `NF-REQ-021`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 설계의 고정 조건

- 사용자가 제공한 재현과 비식별 오류만 이슈로 등록하고 실제 창작물·메일·코드를 수집하지 않는다.
- P6·1.0.1에서 필수였던 P0/P1을 이 버전으로 미뤄 출시하는 것은 금지한다.
- 코드 변경이 필요 없는 관찰 결과만 있으면 문서 인수로 끝내고 제품 릴리스 번호는 소비하지 않는다.
