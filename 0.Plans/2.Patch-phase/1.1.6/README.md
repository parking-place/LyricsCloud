# 1.1.6 — 승인 디자인 적용·편집과 복구 화면

상태: **P1~P5·정식 릴리스 완료**. P5 후보 `7f4ac5bad29d910a26e5256e9714cd3b94a49015`의 개발 인수와 main/tag `f8d24c610ce24a1ff926e77204783473b936da88`의 운영 인수를 통과했다. 실제 OS/물리 기기·OS IME/AT/OS zoom은 미실행으로 분리했다.

## 목표

창작 편집기·자료 패널·가입/공유/복구 화면에 승인 디자인을 적용하고 전 기능을 다시 검증한다.

## 요구사항

`NF-REQ-037`, `NF-REQ-039`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 선행조건과 승인

- [1.1.5 P5](../1.1.5/5phase.md)의 실제 인수와 현재 파일 담당 경계 확인.

## 설계의 고정 조건

- 보이는 편집창 변화와 CRDT/CodeMirror 생명주기를 분리한다.
- 원문·selection·undo·scroll·IME·미전송 queue가 디자인 변경 전후 유지되어야 한다.
- beta/공유/탈퇴/복구의 보안 의미는 꾸미기 과정에서 축약하지 않는다.
