## 실행·증거 기록

[공통 명령·검증](../QUALITY-GATES.md)을 먼저 읽는다. 기존 runner의 영향받은 검사를 우선 사용하고 필요할 때만 회귀를 보강한다. 지원 환경에서 관련 DB/E2E를 선택하며 동일 변경의 full suite는 로컬/CI 중 한 곳과 필수 게이트만 따른다. native은 승인된 SDK/플랫폼 명령을 기록한다. 없는 도구·실제 IME·물리 기기 검증을 모사 결과로 통과시켰다고 표시하지 않는다. 문서-only Phase는 링크·범위·결정·설계 검토로 별도 인수한다.

- 후보 SHA: `5092d12fc67c83b165bf83cf83210b49d62b4e4a`
- 원격: PR [#33](https://github.com/parking-place/LyricsCloud/pull/33), Actions run [34460759490](https://github.com/parking-place/LyricsCloud/actions/runs/34460759490) 전체 verify와 web·collaboration·migrate·worker 개발 image 게시/서명 PASS
- 개발 인수: 같은 후보 SHA, `version=1.0.3`, `channel=dev`, `phase=p5`, `schema=1000_prompt_modes.sql`, 네 상시 서비스 healthy와 공개 route PASS
- 기능 smoke: legacy capability 409, 최신 client 연결, collaboration 재시작 뒤 같은 document 재접속, 연속 공백·구두점·줄바꿈 raw 조회/복제 PASS. 합성 사용자는 즉시 제거했다.
- 경계: 1.0.3 `main`·tag·정식 image 별칭·릴리스 서버는 변경하지 않았다. `OPS-100-001` 외부 backup 예외와 이전 실제 기기 인수 기록은 유지한다.
