# 1.0.3 — 프롬프트 태그형·문장형 선택 기반

상태: **P1~P4 완료 / P5 착수**. 번호는 미발행 작업 배정이며 정식 배포 승인이 아니다.

## 목표

기존 프롬프트를 훼손하지 않고 태그형과 문장형을 선택·저장·복구하는 최소 완결 흐름을 제공한다.

## 요구사항

`NF-REQ-022`. 세부 의미와 완료 판정은 [요구사항 추적표](../Requirements-Traceability.md)를 따른다. 하나의 요구가 여러 패치에 걸치면 모든 담당 범위를 검증하기 전 전체 요구를 완료 처리하지 않는다.

## 선행조건과 승인

- [1.0.2 P5](../1.0.2/5phase.md)의 실제 인수와 현재 파일 담당 경계 확인.

## 설계의 고정 조건

- 보기 모드 전환과 구조 변환을 분리한다. 선택만으로 쉼표·마침표·공백을 바꾸지 않는다.
- 기존 태그 occurrence와 문장 raw의 호환 읽기·쓰기 정책을 정하고 구버전이 알 수 없는 mode를 덮어쓰지 못하게 한다.
- 첫 단계의 문장형은 원문 편집/복사가 가능한 완결 기능이다. 마침표별 카드 표현과 길이 경고는 별도 패치다.

## 대표 수용 사례

| ID | 입력·상황 | 기대 결과 |
|---|---|---|
| `AC-1.0.3-01` | 태그형 → 문장형 보기 → 태그형 보기 | 입력하지 않았다면 원문과 기존 복사 출력이 바뀌지 않는다. |
| `AC-1.0.3-02` | 서로 다른 탭에서 mode와 본문 동시 변경 | 혼합 mode/body나 오래된 덮어쓰기가 없다. |
| `AC-1.0.3-03` | 문장형 offline 편집 후 재접속·복제·복원 | 구두점·공백·줄바꿈·mode가 보존된다. |
| `AC-1.0.3-04` | 구버전 클라이언트로 새 mode 접속 | 안내/읽기 제한 또는 호환 처리를 하며 원문을 잃지 않는다. |
