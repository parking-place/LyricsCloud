# LyricsCloud 제품 로드맵

**major 1 고정·patch 우선·기본 5 Phase, 의존성/업무량에 따라 추가 허용.** 1.0.1은 10 Phase이며 CLI는 P2다. 미발행 계획 배정이며 구현 완료·일정·운영 승인이 아니다.

## 진행과 결정 gate

1.0.0 P6 실제 인수 → 1.0.1 Private Beta 마감 → 1.0.2~1.0.12 개인 창작 확장/점검 → 1.0.13 사전·1.0.14 폰트/통합 → 공유 권한 모델 승인 후 1.1.0~1.1.4 → UX의 약 5개 morphism 시안·사용자 선택·new_Mock-up·최종 승인 → 1.1.5~1.1.6 적용 → 1.1.7 실제 UI/UX 동선 개선 → Windows 1.1.8~1.1.9·Android 1.1.10~1.1.11·Linux 1.1.12·macOS 1.1.13·iOS 1.1.14 개발안/조건부 구현.

사전 제공/권리와 플랫폼 SDK/패키징 gate가 남으면 해당 요구는 미완료다. 개발안·설계만으로 제품 tag를 발행하지 않는다. 빈 안정화 릴리스로 수를 채우지 않으며 hotfix가 먼저 발행되면 미착수 계획만 다음 가용 patch로 확정한다. 실제 발행된 버전·Git·migration은 불변이다. 새 OS/기능/자릿수로 minor를 자동 올리지 않는다. 1.12.91은 형식 예제다.
