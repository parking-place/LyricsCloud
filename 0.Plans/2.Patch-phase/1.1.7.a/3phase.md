# 1.1.7.a P3 — PC/모바일 편집 UI·홈 이동

상태: **구현 중**. [P2](2phase.md)의 저장/파일/override 계약과 P1의 클릭 대상이 선행한다. P2 PR #147 merge `d319d4f`에서 별도 P3 Phase 브랜치를 시작했으며 1.1.8 Windows/main은 포함하지 않는다.

## 작업

- [ ] `LC-PLAN-117A-P3-01`: 기존 `/settings#account`에 닉네임 입력, 현재/새 사진 preview, 기기 파일 선택·교체·제거/기본값 복귀, 명시적 저장·취소를 PC/모바일 함께 제공한다. Google 이메일은 읽기 전용임을 표시하고 탈퇴 위험 구역과 편집 액션을 분리한다.
- [ ] `LC-PLAN-117A-P3-02`: 서버 저장 성공 전 preview와 실제 저장된 프로필을 구분한다. 업로드 진행/실패·세션 만료·유효성/충돌 오류를 문장·`role=status/alert`로 알리고, 실패 시 입력/선택 사진을 복구 가능하게 보존한다. 한글 IME 조합 중 저장/검증을 확정하지 않는다.
- [ ] `LC-PLAN-117A-P3-03`: 저장 성공 후 셸 rail/모바일 헤더 avatar·닉네임, 홈 인사말과 설정 계정 값을 갱신한다. 다른 탭·재진입·새로고침 시 서버 값이 기준이며 다른 계정의 로컬 미리보기/사진 cache를 보여주지 않는다. 이미지 없거나 로드 실패면 접근 가능한 이름 첫 글자/기본 아이콘 fallback을 제공한다.
- [ ] `LC-PLAN-117A-P3-04`: P1에서 사용자가 지목한 로고/mark를 기존 재사용 브랜드 안에서 `/workspace`로 연결한다. 레이아웃상 우측 상단 대상이 별도라면 승인된 위치만 변경하고 좌측/모바일 브랜드 동작의 일관성을 검토한다. 설정/로그아웃/도움말 아이콘을 홈 버튼으로 바꾸지 않는다. 키보드 focus와 충분한 터치 영역, 홈에서의 재실행 상태를 제공한다.
- [ ] `LC-PLAN-117A-P3-05`: 로고 클릭도 기존 저장 이탈 guard/return 흐름에 연결한다. 미전송 입력·저장 오류·오프라인·IME 조합에서 이동을 취소하거나 명시적으로 안전하게 진행하고, 취소 시 같은 문서/selection/입력을 유지한다. 공유·Suno 새 탭에서 돌아오는 1.1.7 복귀 계약도 유지한다.

## 검증·인계

PC와 모바일의 light/dark, 320px 좁은 화면, 접힌 rail에서 `AC-117A-01,04,05`의 클릭·키보드·터치·저장/오류 흐름을 E2E와 스크린샷으로 확인한다. 정적 목업은 기준이지만 이번 요청의 신규 편집 UI를 이미 구현된 것으로 취급하지 않는다. 실패/미실행은 기록해 [P4](4phase.md)에 넘긴다.
