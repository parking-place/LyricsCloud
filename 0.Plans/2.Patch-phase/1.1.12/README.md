# 1.1.12 — Linux 개발안·검증·조건부 앱 인수

상태: **계획 검토 / 구현 미착수**. 미발행 배정이며 실제 발행 시 다음 가용 patch를 재확인한다. 요구 `NF-REQ-045`를 [전체 추적표](../Requirements-Traceability.md)로 연결한다.

선행: [1.1.11](../1.1.11/README.md)의 인수와 해당 결정 gate. 코드 변경 없는 개발안/외부 gate 보류는 제품 출시로 세지 않는다.

## 대표 수용과 범위

- `AC-1.1.12-01`: Linux 개발안과 SDK/패키징 후보의 채택 근거·미확인이 구별되고 사용자 승인 전 기술을 고정하지 않는다.
- `AC-1.1.12-02`: 기술 spike가 실제 OS에서 핵심 계약을 만족한다. 실패하면 SDK 변경 비교 또는 보류를 기록하고 구현 승인을 요청하지 않는다.
- `AC-1.1.12-03`: 개발안/목업 승인과 실제 앱 구현/배포 승인이 분리돼 있고 P4 착수 조건이 명확하다.
- `AC-1.1.12-04`: 승인 범위의 실제 앱에서 작성·copy·협업과 복구가 동작한다. 미승인이라면 미착수로 두고 문서만으로 앱 완료를 선언하지 않는다.
- `AC-1.1.12-05`: 디지털 검증과 실제 OS/기기·서명/스토어 미실행이 구별되며 실체 없는 제품 tag를 발행하지 않는다.
