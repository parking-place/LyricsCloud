# Tests

테스트는 구현 위치의 단위 테스트와 이 디렉터리의 시스템 경계 테스트로 나눕니다.

- [`e2e`](./e2e/): 15개 화면과 핵심 사용자 흐름의 실제 브라우저 검증
- [`integration`](./integration/): 웹·협업 서비스·worker·PostgreSQL 연결 검증
- [`db`](./db/): schema, migration, 두 사용자 데이터 격리, 검색·삭제 규칙
- [`fixtures`](./fixtures/): 저작권·개인정보가 없는 합성 한국어 테스트 자료

실행 명령과 환경 분리는 `0.0.0`에서 테스트 도구가 확정되면 이 문서에 추가합니다.
