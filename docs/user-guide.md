# LyricsCloud 1.1 사용자 안내

LyricsCloud는 곡을 중심으로 여러 가사 버전, 라임 노트와 Suno 프롬프트를 관리하는 창작 공간이다. 로그인한 같은 계정의 브라우저·기기·탭 사이에서 편집 내용이 병합되고, 지정한 다른 계정에는 특정 가사의 읽기 또는 본문 쓰기를, 만료되는 공개 링크에는 읽기만 공유할 수 있다. 공개 링크 쓰기·guest identity와 AI 생성은 아직 제공하지 않는다.

1.0.14는 설정의 글꼴에서 `Noto Sans KR`를 계정 기본값으로 고르고, 각 가사 표시 설정에서 별도 글꼴로 덮어쓸 수 있다. 선택은 서버에 저장되어 재진입 뒤에도 유지되며 가사·라임·프롬프트 원문·복사·undo는 바뀌지 않는다. 폰트가 늦거나 차단되면 system sans로 표시하면서 입력과 저장을 계속한다.

## 지정 사용자에게 가사 읽기 공유

설정에서 내 공유 코드를 확인해 안전한 별도 채널로 전달한다. owner는 가사 편집 화면의 `공유`에서 상대방의 코드를 입력하고 `읽기 권한 부여`를 누른다. 상대방은 생성된 공유 주소로 로그인해 제목·본문·상태를 읽고 owner의 변경을 실시간으로 받는다. 화면의 `읽기 전용` 표시는 수정·삭제·권한 변경이 허용되지 않는다는 뜻이다.

공유는 선택한 한 가사에만 적용된다. 곡/가사 메모, 연결 라임·프롬프트, 다른 가사, 수정 기록은 전달되지 않는다. owner가 `권한 회수`를 누르거나 만료되면 열려 있던 공유 화면도 종료되고 다시 읽을 수 없다. 오프라인일 때 보던 마지막 내용은 새 서버 자료가 아니며, 재연결 시 권한을 다시 확인한다. 공유 코드는 비밀번호가 아니지만 공개 게시하지 말고, 잘못 전달했다면 해당 가사의 권한을 회수한다.

## 지정 사용자와 가사 본문 공동 편집

owner는 이미 읽기 권한이 있는 지정 사용자의 `본문 쓰기`를 켤 수 있다. writer는 같은 공유 화면에서 본문만 편집하며 owner와 다른 writer의 입력, 서버가 확인한 cursor와 online/idle 상태를 실시간으로 본다. 제목·상태·메모·연결 자료·수정 기록·공유 권한·삭제·소유권·계정 설정은 writer 권한에 포함되지 않는다.

권한을 읽기 전용으로 낮추면 화면과 실시간 읽기는 유지되지만 cursor와 새 쓰기는 즉시 중단된다. 회수하면 읽기 연결도 종료된다. 경계에서 서버가 거부한 로컬 입력은 `복구할 원문`에 보존되며 복사하거나 내려받을 수 있다. owner가 나중에 쓰기를 다시 켜도 이 원문은 자동으로 본문에 합쳐지지 않으므로 현재 서버 본문을 확인한 뒤 필요한 부분만 직접 반영한다. 다른 계정·가사·공유 권한의 복구 원문과 섞이지 않는다.

## 공개 링크로 가사 읽기 공유

가사 편집 화면의 `공유`에서 공개할 필드와 1·7·30일 만료를 고르고 확인한 뒤 링크를 한 번 복사한다. 링크 원문은 대화상자를 닫으면 다시 표시되지 않으므로 필요한 상대에게 신뢰할 수 있는 채널로 전달한다. 기존 링크를 교체하면 이전 링크는 즉시 무효화된다.

방문자는 로그인 없이 별도 공개 화면에서 승인된 제목·본문·상태만 읽는다. 주소의 `#` 뒤 capability는 첫 처리 직후 제거되며, 화면은 수정·메모·연결 자료·수정 기록·내보내기·workspace 진입을 제공하지 않는다. owner가 회수하거나 만료되면 열려 있던 탭도 새 내용을 받지 않고 일반화된 만료 안내로 전환한다. 잘못 공유했다면 즉시 `공개 링크 회수`를 누른다.

## 시작하기

기존 사용자는 Google 로그인을 마치면 곡 목록이 열린다. 처음 가입할 때는 초대 코드와 Google 계정 이메일을 입력한 뒤 같은 계정으로 본인 확인한다. 가입 중 오류가 나면 입력을 유지한 채 `다시 시도`, `기존 계정으로 로그인`, `취소` 중 하나를 선택할 수 있다. `새 곡`에서 제목과 작업 상태를 정하고, 곡 대시보드의 `＋ 새 가사`로 첫 가사를 만든다. PC에서는 왼쪽 메뉴와 상단 창작 탭을, 모바일에서는 하단 메뉴와 `더보기`를 사용한다.

## 목록 보기 선택

곡·라임 노트·프롬프트 목록 상단의 보기 선택에서 `리스트`, `작게`, `중간`, `크게`를 고를 수 있다. 선택은 로그인 계정과 자료 유형별로 저장되므로 다른 브라우저에서 다시 열어도 유지되고, 새 계정은 리스트로 시작한다. 보기를 바꿔도 현재 검색·필터·정렬·페이지와 항목 순서는 바뀌지 않는다. 저장에 실패하거나 다른 탭의 더 최신 변경과 충돌하면 최신 설정을 다시 읽고 안내하며, 창작물 본문이나 다른 표시 설정은 되돌리지 않는다.

곡·라임 노트·프롬프트 목록에서 항목의 이동 손잡이를 끌거나 위·아래 이동 버튼과 키보드 명령을 사용하면 정렬이 `사용자정렬`로 바뀌고 계정·자료 유형별로 저장된다. 검색·필터 중에는 화면에 보이는 자료를 기준으로 이동하며 숨은 자료·핀·보기 설정은 그대로 남는다. 프롬프트 카드를 옮겨도 카드 안의 토큰 순서와 복사 원문은 바뀌지 않는다. 모바일에서 라임·프롬프트 본문을 길게 눌러 복사하는 동작과 이동 손잡이는 분리되어 한 동작에서 둘 다 실행되지 않는다. 저장에 실패하면 화면 순서를 이전 상태로 되돌리고 재시도 안내를 보여 준다. 다른 탭에서 먼저 순서를 바꿨다면 최신 순서를 다시 읽은 뒤 다시 이동한다.

## 가사와 연결 자료

- 편집 중 상태가 `로컬 임시 저장`, `동기화 중`, `서버 저장됨`, `재시도` 중 무엇인지 먼저 확인한다. `로컬 임시 저장`은 이 브라우저에만 남았다는 뜻이며 서버 저장 완료가 아니다.
- 로컬 저장 실패 안내가 나오면 화면을 닫기 전에 `현재 입력 복사`로 원문을 다른 안전한 위치에 보관하고 재시도한다. 실패 안내는 입력을 지우거나 저장 성공으로 바뀌지 않는다.
- `[Verse]`, `[Chorus]` 같은 송폼은 원문을 바꾸지 않고 목차·구간 복사에 사용된다. `[Verse: whisper]`처럼 콜론 뒤 부태그를 적으면 목차 탐색은 `Verse`를 사용하고 부태그는 덜 강조해 보여 주지만 저장·검색·수정 기록·복사에서는 대괄호 전체를 보존한다.
- `[Extend: 3:00:24]` 같은 Extend 작업 표식은 저장·검색·수정 기록·내보내기와 `Extend 포함 원문 복사`에 그대로 남고 Suno용 `전체 복사`에서만 표식 줄이 제외된다. 뒤 가사나 주변 빈 줄은 자동으로 잘라내지 않는다.
- PC에서는 편집기를 우클릭하거나 메뉴키/`Shift+F10`을 누르고, 모바일에서는 `＋ 송폼 삽입`을 눌러 기본 송폼을 현재 위치에 넣는다. 선택한 가사는 지워지지 않으며, 한 번의 실행은 한 번의 undo로 취소된다. 한글 조합 중에는 조합을 먼저 마친다.
- `수정 기록` 복원은 현재 내용을 먼저 새 기록으로 남긴 뒤 과거 본문을 현재본으로 적용한다. 이름 있는 가사 버전과 자동 수정 기록은 서로 다른 자료다.
- 라임과 프롬프트를 곡에 연결하거나 해제해도 독립 원본은 보존된다.
- Clipboard를 쓸 수 없으면 선택 가능한 원문을 보여 주는 수동 복사 창을 사용한다.
- 가사 전체 복사의 최종 LF 문자열이 3,000자를 넘으면 실제 Unicode 문자 수와 권장 기준 안내가 표시된다. 3,001자 이상도 입력·저장·복사되며 자동으로 자르지 않는다.

곡 대시보드의 `Suno 작업`에서는 사용한 모델을 미지정·참고 제안·사용자 지정 값으로 기록하고, 곡마다 최대 20개의 Suno 곡/공유 링크를 수동 제목·메모와 함께 저장할 수 있다. 각 링크는 위·아래로 옮기거나 수정·제거할 수 있으며 새 탭으로 열린다. `제거`는 LyricsCloud에 저장한 URL·제목·메모만 지우고 Suno 원곡은 삭제하지 않는다.

자동 제목·썸네일·생성 시간은 아직 조회하지 않는다. HTTPS Suno 곡/짧은 공유 주소가 아니면 저장하지 않으며, 네트워크 실패 때 열린 입력과 같은 브라우저 탭 초안을 유지한다. 화면의 `저장됨` 안내를 확인하기 전에는 서버 저장 완료로 보지 않는다. 곡을 휴지통으로 보내면 작업공간도 보이지 않고 곡을 복원하면 함께 돌아온다.

## 태그형·문장형 프롬프트

- `태그형`은 각 태그의 표시와 순서를 유지하고 전체 복사에서는 `, `로 연결한다. `문장형`은 쉼표·마침표·연속 공백·줄바꿈을 입력한 그대로 저장하고 복사한다.
- 이미 저장된 양쪽 표현이 있으면 모드 선택은 보기만 바꾸며 어느 원문도 다시 만들지 않는다.
- 반대 표현이 비어 있을 때만 변환 미리보기가 열린다. 원문과 결과를 확인하고 명시적으로 승인해야 변환되며, 직후 `되돌리기` 또는 수정 기록 복원으로 이전 표현을 회수할 수 있다.
- 여러 탭 중 한 탭에서 원문이 바뀌면 다른 탭의 오래된 변환 미리보기는 거부된다. 최신 원문을 다시 확인한 뒤 변환한다.
- 구버전 화면이 문장형 자료를 편집할 수 없다는 안내를 받으면 새 버전으로 다시 열어야 한다. 재시도로 원문을 태그처럼 덮어쓰지 않는다.
- 문장형 보기에서는 ASCII 마침표(`.`)까지를 한 구간으로 나눠 읽기 쉽게 표시한다. 소수·URL·연속점·마지막 미완성 문장을 포함한 원문은 바뀌지 않으며 편집기에서 그대로 수정할 수 있다.
- 목록·편집기·가사 자료 패널의 최종 복사 문자열이 1,000자를 넘으면 실제 Unicode 문자 수와 안내가 표시된다. 1,001자 이상도 입력·저장·복사되며 자동으로 자르지 않는다. Clipboard를 쓸 수 없을 때의 수동 복사 창도 같은 원문과 안내를 제공한다.

## 키보드 단축키

| 명령 | Windows/Linux | macOS |
|---|---|---|
| 새 가사 | `Ctrl+Alt+N` | `Command+Option+N` |
| 통합 검색 | `Ctrl+Alt+K` | `Command+Option+K` |
| 단축키 도움말 | `Ctrl+Alt+/` | `Command+Option+/` |
| 가사 전체 복사 | `Alt+Shift+C` | `Option+Shift+C` |
| 집중 모드 전환 | `Alt+Shift+F` | `Option+Shift+F` |
| 자료 패널 열기·닫기 | `Alt+Shift+P` | `Option+Shift+P` |
| 이전 / 다음 가사 | `Alt+Shift+[` / `]` | `Option+Shift+[` / `]` |

입력 필드, 열린 대화상자와 한글 조합 중에는 전역 단축키가 실행되지 않는다. 화면의 `?` 또는 설정의 키보드 영역에서 검색 가능한 도움말을 열 수 있다.

## PWA와 오프라인 초안

지원 브라우저의 설치 메뉴에서 홈 화면 또는 앱으로 설치할 수 있다. LyricsCloud는 온라인 우선 앱이다. 설치본도 최초 로그인, 서버 자료 조회와 최종 동기화에는 네트워크가 필요하다.

편집 중 가사·라임·프롬프트 초안과 전송 대기열은 계정별 브라우저 저장소에 보존된다. 오프라인에서 앱을 닫아도 같은 계정으로 다시 열면 복구하고, 연결 뒤 서버와 병합한다. 미전송 초안이 있으면 새 앱 업데이트 적용을 막고 저장 뒤 승인을 요청한다. 로그아웃 또는 다른 계정으로 전환하면 현재 계정의 로컬 개인 자료·cache·최근 위치를 제거한다. 로그아웃 전 전송할 수 없는 초안은 내려받기 또는 명시적 폐기를 선택해야 한다.

## 삭제, 탈퇴와 내보내기

- 일반 삭제 자료는 휴지통에 정확히 30일 보관된다. 기간 안에는 복원할 수 있고, 이후 worker가 완전 삭제한다.
- 회원 탈퇴를 시작하면 모든 일반 세션과 자료 접근이 즉시 차단된다. Google 재인증 뒤 7일 안에만 명시적으로 철회할 수 있으며 이후 계정과 자료가 완전 삭제된다.
- 설정의 전체 내보내기는 한 시점의 내 자료를 TXT/Markdown과 `lyricscloud.export.v1` JSON으로 묶은 ZIP이다. 직접 보관할 이동용 사본이며 서버 복구용 운영 backup이 아니다.
- 운영 backup은 서비스 장애 복구를 위한 암호화된 전체 DB 사본이라 사용자가 개별 파일로 받거나 휴지통처럼 탐색할 수 없다. 현재 공식 릴리스 서버에는 사용자 요청으로 아직 구축되지 않아 24시간 RPO를 보장하지 않는다.

문제가 생기면 상태 문구와 익명 `requestId`만 운영자에게 전달한다. 제목, 본문, 검색어, 세션 값이나 내보내기 ZIP을 공개 Issue에 첨부하지 않는다. 지원 범위와 안전한 보고 방법은 [지원 정책](./support.md)을 따른다.

가입·저장·PWA 업데이트 실패의 단계별 복구는 [1.0.2 사용자 입력·가입 복구](./runbooks/1.0.2-user-recovery.md)를 따른다.
