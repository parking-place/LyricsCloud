## 재분류와 중단 조건

- 데이터 손실, 교차 사용자 노출, 인증 우회, 무음 저장 실패, 전체 서비스 불능은 P0으로 즉시 승격한다.
- 핵심 흐름의 우회 없는 실패, 주요 모바일 불능, 삭제·복원·내보내기 오류는 P1으로 승격한다.
- 다중 web replica로 topology를 바꾸기 전에 `RC-100-001`을 닫지 못하면 scale-out을 금지한다.
- production DB·host 손실 징후가 있는 동안 `OPS-100-001`이 열려 있으면 신규 쓰기를 중단하고 운영 책임자가 영향과 복구 가능성을 판단한다.

각 항목은 별도 Phase branch, 전체 CI, 네 signed image와 동일 SHA 개발 서버 smoke를 거쳐야 한다. migration 또는 dependency 의미 변경이 필요하면 영향과 application-first rollback을 먼저 기록한다.
