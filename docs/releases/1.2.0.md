# LyricsCloud 1.2.0 릴리스 노트 초안 — Chroma 개발 후보

상태: P1~P4 개발 인수 완료, P5 최종 후보 검증 중. 현재 정식 운영 버전은 `1.1.7a`; `1.2.0`의 `main` 통합·정식 tag·운영 배포는 승인/실행되지 않았다.

## 달라진 화면

- 선택형 `LC_UI_VARIANT=chroma`에서 코발트 light/dark Chroma Dock을 제공한다. PC 도크와 모바일 더보기, 실제 창작 자료 기반 홈·목록·검색, 가사/라임/프롬프트 편집과 자료 4탭, 설정·프로필·공유·휴지통 화면이 같은 시각 언어를 사용한다. 기본 B-1 및 `classic` 복귀 선택은 유지한다.
- 새 화면도 기존 CodeMirror/Yjs 원문·selection/undo·초안/outbox·공유 권한·deep link·문서 키를 그대로 사용한다. 단순 목업의 207개 설명을 실제 제품의 207개 새 기능으로 착각하지 않도록 [대응표](../../0.Plans/3.Redesign-phase/1.2.0/FEATURE-MAP.md)에 실제 route/컴포넌트와 시연 범위를 구분했다.
- 320~1440px, 두 테마, 큰 글꼴·reduced-motion/transparency·forced-colors를 자동 검증했다. 첫 공개 후보의 모바일 강제 색상 로그아웃 대비 오류는 시스템 버튼색으로 보정한 뒤 같은 빠른 전환 20회에서 재검증했다.

## 설치·업그레이드·복귀

제품/runtime/private package `1.2.0`과 schema `1152_prompt_dictionary_cascade.sql`을 확인한다. P1~P4에서 새 DB/API/협업 protocol은 추가하지 않았고 기존 migration·DB volume·계정별 브라우저 초안/원문을 보존한다. Chroma가 맞지 않으면 `LC_UI_VARIANT=b1` 또는 `classic`으로 application-first rollback하며 DB down/drop이나 자료 삭제를 하지 않는다. 브라우저 구 build PWA 탭과 미전송 입력을 먼저 확인한다. 정식 설치/승인은 [별도 절차](../runbooks/1.2.0-release.md)를 따른다.

## 알려진 제한과 운영 위험

실제 OS Windows/iOS/Android 기기, 실제 한글 IME·가상 키보드·AT/스크린리더는 사용자 요청으로 **미실행**이며 Linux 자동화 PASS로 대신하지 않는다. 첫 화면의 B-1 대비 소표본 성능 관찰(+10.6% p95)은 P5 인계·추가 측정 대상이다. UI-04/05/07 P2 개선, 외부 Google 장애, 운영 backup/timer·릴리스 proxy·실제 PC 설치물 rollback은 이번 개발 인수 PASS가 아니다. `OPS-100-001` 외부 backup 예외로 24시간 RPO/host-loss 복구를 보장하지 않는다. 원문 손실·거짓 저장·권한 우회가 발견되면 배포를 중단한다.

검증 출처와 P0/P1·미실행 경계는 [최종 추적](../architecture/1.2.0-FINAL-TRACEABILITY.md), 현재 지원 환경은 [지원 정책](../support.md)에 기록한다. 실제 사용자 원문·사진·세션은 공개 이슈에 올리지 말고 [비공개 보안 정책](../../SECURITY.md)을 따른다.
