# LyricsCloud 1.0.5 — 서브 송폼·가사 복사 안내

상태: P1~P5 후보 인수 완료, 사용자가 승인한 정식 릴리스 실행 대상.

## 주요 변경

- `[TAG:sub tag]`에서 첫 콜론 앞 주 이름으로 송폼을 탐색하고 suffix는 낮은 강조로 표시하면서 저장·검색·revision·복사 원문을 그대로 보존한다.
- 가사 최종 LF 복사 payload가 Unicode code point 3,000자를 넘을 때만 비차단 안내를 표시하며 저장과 자동·단축키·수동 복사는 계속 허용한다.
- 한글 suffix 조합 중 다른 탭의 변경을 안전하게 보류하고 조합 종료 뒤 CRDT로 합류해 cursor·undo·탐색을 보존한다.

## 검증

PostgreSQL 18 migration 반복과 unit/integration 270건, Chromium PC/mobile 전체 316건 중 284건과 조건부 32 skip을 통과했다. 신규 기능은 Chromium·Firefox·WebKit 5-project에서 11건을 통과했고, P5 전체 CI와 네 개발 image 게시·서명, 동일 SHA 개발 HTTPS, 공개 suffix·주 이름 탐색·3,001자 exact copy 및 collaboration 재시작 뒤 동일 document key·DB 원문 보존을 확인했다.

## 알려진 제한과 운영 위험

- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- 실제 Windows/iOS/Android 물리 입력은 이 후보에서 새로 수행하지 않았으며 자동 브라우저 결과로 대체하지 않는다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.

AI 생성·Suno API, 다사용자 공동 편집과 공개 공유는 1.0.5 범위가 아니다.
