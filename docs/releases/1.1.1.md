# LyricsCloud 1.1.1 — 공개 링크 읽기

상태: **Phase 5 정식 릴리스 후보**. 동일 SHA 개발 인수 뒤 승인된 main·annotated `v1.1.1` tag·exact digest 운영 배포와 GitHub Release를 실행한다.

## 주요 변경

- owner가 공개 필드와 1·7·30일 만료를 확인한 뒤 한 가사의 비로그인 읽기 링크를 발급·교체·회수할 수 있다.
- 링크 방문자는 제목·본문·상태만 읽기 전용으로 보고 owner 변경을 실시간으로 받는다. 링크 fragment는 첫 처리 직후 주소에서 제거된다.
- 빈 가사 최초 공개, PC·모바일 재진입, offline·재연결, collaboration 재시작과 열린 탭 회수 경계를 제공한다.

## 설치와 업그레이드

`v1.1.1`의 네 서비스 이미지를 같은 source SHA의 exact digest로 고정하고 migrate를 먼저 실행한다. 최신 schema는 `1110_public_lyric_read_links.sql`이다. application-first rollback으로 1.1.0 image를 먼저 복원하며 DB volume은 삭제하지 않는다. schema나 자료 무결성이 의심되면 쓰기를 중단하고 격리 restore한다.

## 공개 링크와 보안

링크 capability는 256비트이며 서버에는 digest만 저장한다. 공개 응답은 선택한 한 가사의 승인 필드만 포함하고 workspace·메모·연결 자료·다른 가사·revision·export·ACL·presence·write를 허용하지 않는다. 링크 만료·회수는 열린 WebSocket과 이후 요청을 함께 차단하며 no-store/noindex/no-referrer를 유지한다.

## 알려진 제한과 운영 위험

- 실제 OS/물리 기기는 1.1.1 P4/P5에서 새로 실행하지 않았다. Linux에서 Chromium·Firefox·WebKit desktop과 Chromium·WebKit mobile viewport 자동화를 수행했다.
- 링크를 받은 사람은 만료 전 허용 필드를 볼 수 있으므로 신뢰할 수 있는 채널로 전달하고 잘못 공유했다면 즉시 회수해야 한다.
- public write·guest 표시 이름/수명주기·공동 cursor는 후속 1.1.2~1.1.4 범위다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련은 사용자 승인 예외로 미구축이다.

## 릴리스 검증

P4 제품 후보 `b920049f5b00bbe44809d1d96bec0f5fd7650c4c`에서 Actions push `34697600730`·PR `34697608114`의 최종 전체 검증, 네 dev image 게시·서명, 실제 PostgreSQL 권한/복구 통합, 5-browser 공개 링크 행렬을 통과했다. 동일 SHA 개발 서버 `1.1.1/dev/p4`, schema `1110_public_lyric_read_links.sql`에서 서비스 재시작 뒤 capability 유지, 회수, private API 차단과 실제 PC/mobile 공개 UI를 확인하고 합성 fixture를 제거했다.

P5 최종 후보·main/tag CI·운영 exact digest와 공개 smoke 결과는 실행 뒤 이 절에 추가한다.

## 지원과 보안

미해결 P0/P1은 0건이다. raw capability 노출, 승인 밖 자료·private API 접근, 공개 write 성공, 회수 뒤 새 데이터 전달, 원문 유실은 배포 중단 조건이다. 일반 문제와 보안 문제는 각각 [지원 정책](../support.md)과 [비공개 보안 보고](../../SECURITY.md)를 따른다.
