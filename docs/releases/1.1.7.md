# LyricsCloud 1.1.7 — UI/UX 동선 개선과 플랫폼 인계

상태: **릴리스 후보 준비 중**. P1~P4 제품 변경·개발 인수를 완료했고 P5 최종 후보 gate를 진행한다.

승인된 B-1 통합 작업공간과 모바일 더보기 구조를 유지하며 CodeMirror 편집기 인스턴스와 원문을 재생성하지 않는다.

## 주요 변경

- 곡 대시보드에서 새 라임·프롬프트를 만들고 완료하면 호출 화면의 정확한 내부 URL로 돌아간다. 기존 직접 URL은 기존 기본 목록 복귀를 유지한다.
- 목록 filter·sort·view query를 곡·가사·공유·Suno 작업 뒤에도 보존하고, dialog/mobile More는 닫힌 뒤 trigger focus를 복원한다.
- 접힌 desktop rail의 키보드 tooltip과 40px target, drag/context 기능의 버튼·키보드 대안을 유지한다.
- reduced transparency·increased contrast·forced colors에서 불투명하고 판독 가능한 fallback을 제공하며 reduced motion과 200% 확대 대리 reflow를 유지한다.

## 호환성과 알려진 제한

API·DB·29개 migration·CodeMirror/Yjs 원문·copy/export·owner/actor/capability/epoch는 1.1.6과 호환된다. 시각 rollback은 `LC_UI_VARIANT=classic`, application-first rollback은 `v1.1.6` exact image다. 실제 OS의 Windows/Linux/macOS/Android/iOS 앱·SDK·물리 기기, OS IME·보조 기술·OS zoom, 패키징·서명·스토어는 이번 웹 릴리스에서 실행하지 않았다. 외부 backup은 `OPS-100-001` 승인 예외로 미구축이다.

## 검증

P2~P4의 실제 PostgreSQL·5-browser·동일 SHA 개발 공개 인수를 완료했다. P5 최종 CI·네 signed image·동일 SHA 개발/정식 운영 인수 결과는 완료 뒤 추가한다.
