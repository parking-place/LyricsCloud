# LyricsCloud 1.0.7 — 목록 보기 선택·밀도 설정

상태: P1~P4 인수 완료, P5 최종 후보 검증과 정식 릴리스 실행 대상.

## 주요 변경

- 곡·라임 노트·프롬프트 목록에서 리스트, 작은 그리드, 중간 그리드, 큰 그리드 중 하나를 선택한다.
- 보기 설정은 계정과 자료 유형별로 서버에 저장되어 다른 브라우저에서도 유지되며, 처음 사용하는 계정은 리스트로 시작한다.
- 보기 전환은 검색·필터·정렬·현재 페이지와 스크롤 문맥을 유지한다.
- 좁은 화면과 200% 확대에서는 큰 그리드도 안전하게 한 열로 접히고 긴 한글 제목과 액션이 겹치지 않는다.
- 다른 탭이 별도 표시 설정을 저장한 경우 독립 CAS로 무관한 설정을 되돌리지 않고, 오래된 보기 저장은 최신 값을 다시 읽어 명시적으로 복구한다.

## 검증

PostgreSQL 18 migration 반복과 unit/integration 283건, Chromium 전체 340건 중 301건과 조건부 36 skip을 통과했다. 새 기능은 Chromium·Firefox·WebKit의 desktop/mobile 5-project에서 30건을 통과했고, 동일 SHA 개발 HTTPS에서 계정·자료유형별 저장, stale 복구와 서비스 재시작 뒤 지속성을 확인했다. P5 전체 CI와 같은 SHA 개발 인수 결과는 최종 후보 문서에 동결한다.

## 알려진 제한과 운영 위험

- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- 실제 Windows/iOS/Android 물리 입력은 이 후보에서 새로 수행하지 않았으며 자동 브라우저 결과로 대체하지 않는다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.

사용자 지정 정렬, AI 생성·Suno API, 공개 공유는 1.0.7 범위가 아니다.
