# LyricsCloud 1.0.8 — 곡 목록 사용자정렬

상태: P1~P5 후보 인수 완료, 사용자가 승인한 정식 릴리스 실행 대상.

## 주요 변경

- 곡 목록을 드래그하거나 보이는 이동 버튼·키보드 명령으로 옮기면 `사용자정렬`로 전환하고 계정별 순서를 저장한다.
- 검색·필터 중에는 보이는 곡을 anchor로 이동하며 숨은 곡과 핀·보기 설정을 삭제하거나 덮어쓰지 않는다.
- 새로고침·재로그인·서비스 재시작 뒤에도 같은 순서를 복원한다.
- 두 탭의 오래된 이동, 응답 역전, 같은 요청 재전송은 CAS와 idempotency로 중복 적용하지 않는다.
- 다른 계정의 곡이나 anchor는 API 소유권 검사와 PostgreSQL forced RLS가 거부한다.

## 검증

P4에서 실제 PostgreSQL 298건, Chromium desktop/mobile 316건과 조건부 36 skip, Chromium·Firefox·WebKit 5-project 신규 기능 30건을 통과했다. P5 후보 `800c66593c8801fd55dad013448b1ef4b037d85a`는 Actions `34560691621` 전체 verify와 네 dev image 게시·서명을 통과했다. 동일 SHA 개발 공개 환경에서 desktop/mobile 이동·manual URL·새로고침 복원·좁은 화면 overflow 없음과 네 서비스 health를 확인했다.

## 알려진 제한과 운영 위험

- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- 실제 Windows/iOS/Android 물리 입력은 이 후보에서 새로 수행하지 않았으며 자동 브라우저 결과로 대체하지 않는다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.
- 1.0.8 사용자정렬은 곡 목록만 대상이며 라임 노트·프롬프트의 저장 순서는 1.0.9 범위다.
