# LyricsCloud 1.1.7a 릴리스 노트

상태: 최종 P5 후보 검증 중. 실제 정식 tag·image·운영 서버 배포 결과는 완료 뒤 갱신한다. 이번 한 번의 제품 이름은 `1.1.7a`이고, 계획 폴더 `1.1.7.a` 및 npm package `1.1.7`과 구별한다.

## 새 기능

- `설정 → 계정 → 내 프로필`에서 닉네임과 로컬 프로필 사진을 따로 고르고 명시적으로 저장·취소·Google 기본값으로 되돌릴 수 있다. 입력/선택만 한 상태는 미저장이다. 다음 로그인과 서버 재시작에도 저장한 사용자 지정값을 유지한다.
- 데스크톱 우측 상단 mark, 모바일 우측 상단 홈 icon, 기존 브랜드에서 창작 홈으로 이동한다. 미저장 입력이 있으면 기존 이탈 보호와 확인을 따르며 취소는 원문을 유지한다.
- 사진은 서버에서 안전한 WebP로 재인코드해 owner 전용으로 보관한다. 공유·공개 링크에는 사진을 자동 표시하지 않고 현재 닉네임은 기존 owner 이름 표시 설정에 따른다.

## 설치와 업그레이드

`v1.1.7`의 기존 DB/볼륨/secret/beta 코드를 보존하면서 추가 migration `1151_profile_customization.sql`을 먼저 적용하고, 네 signed image의 승인된 exact digest만 배포한다. 이전 `v1.1.7` 앱으로 application-first rollback이 가능하지만 1151 자료를 삭제하지 않고, 롤백 중 신규 DB 사진은 fallback/미표시일 수 있다. 사용자 export ZIP에는 현재 사진 WebP가 포함될 수 있어 공개하지 말아야 한다.

## 알려진 제한과 운영 위험

AI 생성·음원 업로드·Windows 네이티브 앱은 이번 범위가 아니다. Linux Chromium/Firefox/WebKit 대리·개발 서버 공개 합성 검증과 달리 실제 Windows Edge/IME, iOS/Android 물리 기기, screen reader/OS zoom은 이번 버전에서 새로 실행하지 않았다. 외부 암호화 backup·24시간 RPO·격리 restore는 `OPS-100-001` 명시적 사용자 예외로 미구축이어서 호스트 손실 시 자료 복구 지점이 없다. 미해결 제품 P0/P1은 0건이지만 사용자 자료 손실·인증 우회·사진 교차 노출이 관측되면 출시를 중단한다.

지원과 보안 문제는 [지원 정책](../support.md)과 [비공개 보안 보고](../../SECURITY.md)를 따른다. 실제 이메일·사진·창작 원문이나 session을 공개 Issue에 넣지 않는다.
