# LyricsCloud 1.0.6 — Extend 원문 분리·송폼 삽입

상태: P1~P5 후보 인수 완료, 사용자가 승인한 정식 릴리스 실행 대상.

## 주요 변경

- `[Extend: ...]` 정식 표식은 저장 원문·부분 복사·검색·수정 기록·내보내기에 그대로 보존하면서 Suno 전체 복사에서만 해당 줄을 제외한다.
- `Intro`, `Verse`, `Pre-Chorus`, `Chorus`, `Hook`, `Bridge`, `Outro`를 PC 우클릭·키보드·모바일의 같은 송폼 메뉴에서 제공한다.
- 메뉴를 연 시점의 CRDT 상대 caret을 실행 시 해석해 선택 본문을 지우지 않고 한 transaction으로 삽입하며, IME 조합·해석 실패 때는 원문을 바꾸지 않는다.

## 검증

PostgreSQL 18 migration 반복과 unit/integration 275건, Chromium PC/mobile 전체 328건 중 292건과 조건부 36 skip을 통과했다. 신규 기능은 Chromium·Firefox·WebKit 5-project에서 17건을 통과했고, P5 GitHub Actions run `34511266182` 전체 verify와 네 개발 image 게시·서명, 동일 SHA 개발 HTTPS, 공개 revision·ZIP export exact Extend 원문 및 collaboration 재시작 뒤 동일 document key·원문 보존을 확인했다.

## 알려진 제한과 운영 위험

- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- 실제 Windows/iOS/Android 물리 입력은 이 후보에서 새로 수행하지 않았으며 자동 브라우저 결과로 대체하지 않는다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.

AI 생성·Suno API, 다사용자 공동 편집과 공개 공유는 1.0.6 범위가 아니다.
