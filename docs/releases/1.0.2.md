# LyricsCloud 1.0.2 — Private Beta 안정화

상태: P1~P5 후보 인수 완료, 사용자가 승인한 정식 릴리스 실행 대상.

## 주요 변경

- 가입 성공 응답이 유실돼도 같은 가입 intent를 멱등 회수해 계정·grant·초대 코드를 중복 처리하지 않는다.
- 브라우저 로컬 저장 실패를 서버 저장 성공으로 표시하지 않고 현재 입력의 exact-copy 복구 동작을 제공한다.
- 미전송 입력이 남아 있으면 화면 이탈과 PWA 강제 갱신을 막고, service worker cache를 build별로 분리한다.
- 로그인·가입 재시도·취소와 desktop/mobile 복구 동선을 명확히 했다.

## 검증

실제 PostgreSQL migration 반복 적용, unit/integration 248건과 beta 가입 전용 4건, Chromium desktop/mobile 267건과 의도적 31 skip, Chromium·Firefox·WebKit release matrix 10건을 통과했다. 네 production image의 fresh DB, DB·collaboration 재시작, durable pending projection, 중복 ACK, revision restore, owner 격리, 암호화 backup/restore와 upgrade/application rollback도 통과했다. P5 전체 CI와 네 개발 image 게시, 동일 SHA 개발 HTTPS 인수까지 완료했다.

## 알려진 제한

- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.
- iOS/Android update PASS 증거에는 상세 기종·OS·브라우저/PWA 모드가 없다.

자동 요약·AI 변환·Suno API, 다사용자 공동 편집과 공개 공유는 1.0.2 범위가 아니다.
