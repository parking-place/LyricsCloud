# LyricsCloud 1.0.10 — Suno 수동 작업공간

상태: P1~P5 후보 인수 뒤 사용자가 승인한 정식 릴리스 실행 대상.

## 주요 변경

- 곡 대시보드에서 사용한 Suno 모델을 미지정·참고 제안·사용자 지정 값으로 기록한다.
- 곡마다 최대 20개의 Suno 작업 링크를 수동 제목·메모와 함께 추가·수정·정렬·제거한다.
- 링크는 보호된 새 탭으로 열고, 제거는 LyricsCloud의 수동 항목만 지우며 Suno 원곡에는 요청을 보내지 않는다.
- 저장 실패·잘못된 URL·오래된 버전·새로 고침 실패를 구분해 표시하고 브라우저 탭 초안을 유지한다.
- 모델과 링크는 곡의 owner에 귀속되고 곡 휴지통/복원·내보내기·서비스 재시작 뒤에도 기존 lifecycle 계약을 따른다.

## 검증

P4에서 실제 PostgreSQL 계약/store/export 7건, Chromium·Firefox·WebKit desktop과 Chromium·WebKit mobile 기능 20건을 통과했다. Actions `34610699744`는 전체 verify, Chromium desktop/mobile 330 PASS·환경 조건부 36 skip, release matrix 10 PASS와 네 dev image 게시·서명을 통과했다. 같은 SHA 개발 환경에서 링크 3개·다른 owner 차단·soft-delete/restore와 web·collaboration·worker 실제 재시작 뒤 데이터 지속성을 확인했다.

## 알려진 제한과 운영 위험

- 자동 제목·썸네일·생성 시간 조회는 제공하지 않는다. 공식·허가된 metadata 경로를 확인하기 전 scraping이나 비공식 API를 사용하지 않는다.
- 실제 Windows/iOS/Android 물리 입력은 이 후보에서 새로 수행하지 않았으며 자동 브라우저 결과로 대체하지 않는다.
- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.
