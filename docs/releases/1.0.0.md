# LyricsCloud 1.0.0

LyricsCloud 1.0.0은 혼자 쓰는 작사 작업 공간의 첫 정식 릴리스다. 곡, 여러 가사 버전, 라임 노트, 프롬프트와 템플릿을 한 계정 안에서 관리하고 PC와 모바일 사이에서 초안을 이어 쓸 수 있다.

## 주요 기능

- CodeMirror 기반 순수 텍스트 가사 편집, 한글 IME 안전 자동 저장, 송폼 탐색·집중 모드·전체/부분 복사
- 같은 계정의 탭·기기 사이 Yjs 동기화, 오프라인 초안 복구, 수정 기록 비교와 비파괴 복원
- 곡·가사·라임·프롬프트의 검색, 연결, 즐겨찾기, 핀, 최근 작업과 빠른 추가
- 사용자 템플릿, 30일 휴지통, 7일 탈퇴 철회와 전체 ZIP 내보내기
- 설치 가능한 온라인 우선 PWA, 미전송 변경을 보호하는 update·logout 흐름
- Google 로그인을 사용하는 비공개 초대형 단일 사용자 작업 공간

## 배포와 검증

- Node.js 24, pnpm 11, PostgreSQL 18, Docker Compose 기반 자체 운영
- web·collaboration·worker·migrate 네 이미지를 digest로 고정하고 nonroot/read-only 경계로 실행
- Chromium·Firefox·WebKit 데스크톱과 Chromium·WebKit 모바일 자동 회귀 통과
- 사용자가 `iOS update PASS, Android update PASS`를 확인했으며 상세 기기·OS 버전은 제공되지 않았다.
- 71개 출시 요구사항, 15개 목업 화면과 8개 추가 제안 source가 모두 추적·검증되었고 미해결 P0/P1은 0건이다.

정식 source SHA, 네 release image digest, CI run과 production smoke 결과는 GitHub Release의 검증 섹션 및 비공개 운영 변경 기록에 고정한다. `v1.0.0`은 annotated tag이며 Docker 이미지는 GitHub Actions OIDC 기반 Sigstore keyless signature, SLSA provenance와 SBOM을 제공한다.

## 설치와 업그레이드

새 자체 운영 환경은 [셀프호스팅 안내](../self-hosting.md)를 따른다. 기존 환경은 [backup·restore·upgrade·rollback runbook](../runbooks/backup-restore-upgrade.md)으로 환경 schema와 migration을 먼저 확인하고, tag가 아닌 승인 digest를 사용한다. destructive down migration은 허용하지 않는다.

## 알려진 제한과 운영 위험

- `RC-091-001`: production build의 Yjs duplicate import 경고를 1.0.1에서 조사한다. 현재 동기화·장문·offline·복원 회귀는 통과했다.
- `RC-100-001`: rate limiter는 승인된 단일 web replica의 메모리 경계다. scale-out 전에 공용 limiter가 필요하다.
- `RC-091-002`: 실제 iOS/Android 결과는 PASS지만 기기·OS·브라우저 상세 버전이 없다.
- `OPS-100-001`: 공식 릴리스 서버의 외부 암호화 backup, 일일 timer, 실제 archive와 복원 훈련은 사용자의 명시적 지시로 1.0.1+까지 유예되었다. 24시간 RPO를 보장하지 않으며 정상 backup 상태로 간주하면 안 된다.

세부 후속 항목은 [1.0.1+ backlog](../operations/1.0.1-backlog.md)에서 관리한다.
