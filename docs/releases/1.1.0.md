# LyricsCloud 1.1.0 — 지정 사용자 읽기 공유

상태: **정식 릴리스 완료**. main·annotated `v1.1.0` tag·exact digest 운영 배포와 GitHub Release를 완료했다.

## 주요 변경

- 가사 편집 화면에서 로그인한 지정 사용자의 공유 코드를 입력해 한 가사에 읽기 권한을 부여하고 즉시 회수할 수 있다.
- reader는 별도 공유 화면에서 제목·본문·상태를 읽기 전용으로 보고, owner 변경과 최소 presence를 실시간으로 받는다.
- 공유 화면의 로그인 return path, PC·모바일 레이아웃, offline·재연결·서비스 재시작 복구를 제공한다.

## 설치와 업그레이드

`v1.1.0`의 네 서비스 이미지를 같은 source SHA의 exact digest로 고정하고 migrate를 먼저 실행한다. 최신 schema는 `1100_selected_lyric_sharing.sql`이다. 애플리케이션 rollback을 먼저 하며 1.0.14 image는 새 공유 UI/API를 사용하지 않는다. DB volume은 삭제하지 않고 schema 복구가 필요하면 격리 restore 절차를 따른다.

## 공유와 보안

지정 사용자 읽기 공유만 지원한다. public link·guest·쓰기 공유는 비활성이다. sharing ID는 계정 선택용 비밀이 아닌 비열거 식별자이며, 앱은 이메일 대신 제한된 표시 이름만 보여 준다. reader는 메모·연결 자료·다른 가사·revision·owner API를 읽거나 가사를 수정·삭제할 수 없다. 권한 회수·만료는 열린 실시간 연결과 이후 API 접근을 함께 차단한다.

## 알려진 제한과 운영 위험

- 실제 OS/물리 기기는 1.1.0 P4/P5에서 새로 실행하지 않았다. Linux에서 Chromium·Firefox·WebKit desktop과 Chromium·WebKit mobile viewport 자동화를 수행했다.
- 공유 코드는 앱 안에서 별도로 전달해야 한다. 이메일 주소 검색·초대 메일·링크를 가진 비로그인 guest 접근은 제공하지 않는다.
- public link read, selected/public write, 공동 cursor와 guest 수명주기는 후속 1.1.1~1.1.4 범위다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련은 사용자 승인 예외로 미구축이다.
