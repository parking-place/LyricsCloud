# LyricsCloud 1.1.7b 릴리스 노트 초안 — 개발 후보

상태: 기능 SHA `acd2bd99876740debf426c401fe7157713f8b854`의 개발 서버 인수 완료. 정식 tag·main 통합·운영 배포는 미승인/미실행이다.

## 변경 사항

- 연결이 끊기거나 저장이 실패할 때 편집 원문과 복구 경로를 더 명확히 보존한다. 가사·프롬프트·공유 작성, 설정·목록의 늦은 응답과 브라우저 업데이트 경쟁을 보정했다.
- 목록/검색/즐겨찾기/복제/삭제·내보내기의 응답 순서·권한·부분 성공 처리를 보강했다. 공유 권한 회수 뒤 입력은 자동 재전송하지 않는다.
- 백업 잠금의 강제 종료 회복, 개발 Cloudflare 경로의 IP 제한, 신규 `1152` 순방향 DB 호환을 추가했다.

## 설치와 업그레이드

제품 `1.1.7b`와 private package `1.1.7`을 구별한다. 기존 DB/볼륨·native 1150 이력·사용자 초안/outbox를 보존하고 `1152_prompt_dictionary_cascade.sql`만 순방향 적용한다. 기존 a/native 포함 웹 image로 되돌릴 때도 DB down/drop은 하지 않으며 쓰기 중단·원문 복구를 먼저 확인한다. 개발 image의 SHA 별칭과 정식 image/tag는 별개다. 실제 운영 설치 절차는 정식 승인 뒤에만 실행한다.

## 알려진 제한과 운영 위험

UI-04/05 템플릿 복제 후 목록·실패 안내와 UI-07 오류 읽기 위치는 미해결 P2로 남는다. 실제 Windows/iOS/Android 기기, OS IME·가상 키보드·AT는 사용자 지시로 미실행이며 자동화 브라우저가 이를 대체하지 않는다. 외부 Google 장애 회복, 운영 backup/timer·릴리스 proxy·실제 PC 앱 rollback도 새 PASS가 아니다. `OPS-100-001` 외부 backup/RPO 예외로 24시간 RPO나 호스트 손실 복구를 보장하지 않는다. 새 원문 손실·거짓 저장·권한 확대가 관측되면 인수와 배포를 중단한다.

지원·보안 보고는 [지원 정책](../support.md)과 [비공개 보안 정책](../../SECURITY.md)을 따른다. 실제 사용자 원문·사진·세션을 공개 이슈에 올리지 않는다. 검증의 출처·미실행은 [최종 추적](../architecture/1.1.7b-FINAL-TRACEABILITY.md)에서 확인한다.
