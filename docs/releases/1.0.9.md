# LyricsCloud 1.0.9 — 라임·프롬프트 사용자정렬

상태: P1~P5 후보 인수 뒤 사용자가 승인한 정식 릴리스 실행 대상.

## 주요 변경

- 라임 노트와 프롬프트 목록을 drag handle이나 보이는 이동 버튼·키보드 명령으로 재배치하고 계정별 순서를 저장한다.
- 목록 보기·검색·필터 중에도 보이는 자료를 기준으로 이동하며 곡 순서, 전역 핀, 보기 설정과 각 자료의 본문을 덮어쓰지 않는다.
- 모바일 long-press copy와 이동 제스처를 분리해 한 동작에서 복사와 이동이 함께 실행되지 않는다.
- 새로고침·재로그인·서비스 재시작 뒤에도 라임·프롬프트 순서를 복원한다.
- 두 탭의 오래된 이동, 응답 유실, 같은 요청 재전송은 CAS와 idempotency로 수렴하며 다른 계정 자료와 anchor는 거부한다.

## 검증

P4에서 실제 PostgreSQL 309건, Chromium desktop/mobile 322건과 조건부 36 skip, Chromium·Firefox·WebKit 5-project 기능 15건을 통과했다. 최종 P5는 전체 CI·네 dev image 게시/서명과 동일 SHA 개발 공개 환경의 desktop/mobile 이동·재진입·서비스 재시작 지속성을 다시 인수한다.

## 알려진 제한과 운영 위험

- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- 실제 Windows/iOS/Android 물리 입력은 이 후보에서 새로 수행하지 않았으며 자동 브라우저 결과로 대체하지 않는다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.
- 1.0.9는 수동 사용자정렬만 제공한다. Suno 모델/링크 metadata는 1.0.10 이후 별도 범위다.
