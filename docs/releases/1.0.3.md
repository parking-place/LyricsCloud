# LyricsCloud 1.0.3 — 프롬프트 표현 모드

상태: P1~P5 후보 인수 완료, 사용자가 승인한 정식 릴리스 실행 대상.

## 주요 변경

- 프롬프트를 태그형 또는 문장형으로 저장하며, 문장형의 구두점·연속 공백·줄바꿈 원문을 그대로 보존한다.
- 표현 전환은 원문과 결과를 미리 확인한 명시적 동작에서만 수행하고, 직후 undo와 수정 기록 비교·복원을 제공한다.
- 문장형을 이해하지 못하는 collaboration client를 capability 검사로 차단해 기존 클라이언트가 원문을 손상하지 못하게 한다.

## 검증

실제 PostgreSQL unit/integration 261건과 `1000_prompt_modes.sql` fresh/repeat migration, production build를 통과했다. Chromium desktop/mobile 전체 306건 중 274건과 조건부 31 skip, 새 기능 Chromium 8건·Firefox 4건·WebKit mobile 4건을 통과했다. P5 전체 CI와 네 개발 image 게시·서명, 동일 SHA 개발 HTTPS 및 collaboration 재시작 뒤 원문 재접속·복제도 통과했다.

## 알려진 제한

- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- ASCII 마침표별 문장 카드와 최종 복사 길이 안내는 1.0.4 범위다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.

자동 요약·AI 변환·Suno API, 다사용자 공동 편집과 공개 공유는 1.0.3 범위가 아니다.
