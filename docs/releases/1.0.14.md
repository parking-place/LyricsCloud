# LyricsCloud 1.0.14 — 자체 호스팅 Noto Sans KR

상태: Phase 5 정식 릴리스 후보. 최종 main/tag·CI·exact digest 운영 배포 결과는 릴리스 실행 뒤 이 문서에 기록한다.

## 주요 변경

- 공식 Noto Sans KR 2.004 Regular를 앱에 함께 배포하고 설정과 가사별 표시에서 선택할 수 있다.
- 선택은 계정 기본값과 가사별 override로 저장되어 새로고침·재진입 뒤에도 유지된다.
- 가사·라임·프롬프트 편집기에 같은 family가 적용되며 저장 원문·복사·cursor·undo·CRDT는 바뀌지 않는다.
- cold font는 한 번만 요청하고 warm/offline은 PWA cache를 사용한다. 로드 실패·차단 시 system sans fallback으로 즉시 표시와 저장을 계속한다.

## 설치와 업그레이드

`v1.0.14`의 네 서비스 이미지를 같은 source SHA의 exact digest로 고정하고 migrate를 먼저 실행한다. 최신 schema는 `1004_web_font_selection.sql`이다. 애플리케이션 rollback을 먼저 하고 필요할 때만 제공된 rollback SQL로 `noto_sans_kr` 선택을 `sans`로 변환한다. DB volume은 삭제하지 않는다.

## 라이선스·지원

Noto Sans KR는 SIL Open Font License 1.1로 배포된다. 앱에는 변경하지 않은 OTF와 OFL 전문이 포함되며 글꼴 파일 자체만 별도 판매하지 않는다. 지원 범위는 Latin, 한글 완성형·자모, Kana와 font에 포함된 Han·기호이며 누락 글리프는 운영체제 system sans가 표시한다. 상세 고지·hash·문제 해결은 [폰트 고지](../third-party-fonts.md)를 따른다.

## 알려진 제한과 운영 위험

- 1.0.14 폰트 전환·늦은 로딩·장문 입력은 Linux Chromium desktop/mobile viewport와 합성 composition으로 검증했다. 실제 Windows 한글 IME·Android/iOS 키보드와 물리 저사양 기기는 새로 실행하지 않았다.
- 1.0.13 세 언어 사전은 공식 provider 계약·표시/캐시/재배포 권리가 없어 제공하지 않는다.
- 공유는 owner/actor·초대/철회·권한/RLS·복구 결정이 승인되지 않아 `OPS-NF-002` NO-GO이며 1.1.0을 시작하지 않는다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련은 사용자 승인 예외로 미구축이다.

## 지원과 보안

폰트 선택은 기존 owner-only 표시 설정과 forced RLS를 유지하고 창작 원문을 외부에 전송하지 않는다. 미해결 제품 P0/P1은 0건이다. 일반 문제와 보안 문제는 각각 [지원 정책](../support.md)과 [비공개 보안 보고](../../SECURITY.md)를 따른다.
