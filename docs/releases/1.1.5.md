# LyricsCloud 1.1.5 — B-1 통합 작업공간과 탐색 셸

상태: **정식 릴리스 완료**. main·annotated tag·정식 image·릴리스 서버 exact-digest 배포와 공개 인수를 완료했다.

## 주요 변경

- desktop의 중복 창작 탭을 현재 영역을 보여 주는 context header로 정리하고, 접힌 rail에 현재 위치와 모든 메뉴 tooltip을 유지한다.
- 모바일 하단 내비를 곡·라임·프롬프트·검색·더보기 다섯 항목으로 정리하고 즐겨찾기·최근·템플릿·휴지통·설정을 focus 복귀가 되는 More 시트에 보존한다.
- 곡·라임·프롬프트·검색·최근·즐겨찾기·곡 작업공간을 B-1 Flat-depth surface와 공통 dark/light token으로 맞춘다.
- shell을 조작해도 CodeMirror·IME·selection·undo·draft/store를 재생성하지 않고 기존 URL·filter·사용자정렬·API·DB를 그대로 유지한다.

## 설치와 업그레이드

`v1.1.5`의 네 서비스 이미지를 같은 source SHA의 exact digest로 고정하고 migrate를 먼저 실행한다. 최신 schema는 `1140_sharing_stability.sql`로 1.1.4와 같다. release는 `LC_UI_VARIANT=b1`을 사용한다. 문제 발생 시 같은 image에서 `LC_UI_VARIANT=classic`으로 즉시 되돌리거나 application-first rollback으로 1.1.4 image를 복원하며 DB volume을 삭제하지 않는다.

## 알려진 제한과 운영 위험

- 실제 Windows/Linux/macOS/Android/iOS 물리 기기, 실제 OS IME·screen reader·200% OS zoom은 이번 버전에서 새로 실행하지 않았다. Linux Chromium·Firefox·WebKit desktop/mobile 자동화는 실제 OS 검증을 대신하지 않는다.
- 모바일 More는 보조 목적지이며 주 작업 다섯 항목은 하단에 유지된다. classic rollback은 구조/시각 전환이며 사용자 데이터·URL·권한을 변환하지 않는다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련은 사용자 승인 예외로 미구축이다.

## 지원과 보안

B-1은 표현·탐색 변경이며 인증, owner/RLS, selected/public capability, guest 제한을 확대하지 않는다. 다른 owner의 자료가 보이거나 shell 전환 중 본문이 사라지거나 저장되지 않았는데 성공으로 표시되면 배포를 중단한다. 취약점은 공개 Issue가 아닌 `SECURITY.md`의 비공개 경로로 보고한다.
