# LyricsCloud 1.0.1 — Private Beta

상태: P10 최종 후보 인수 완료, 승인된 정식 릴리스 실행 중. 정식 tag·image·운영 배포가 끝나기 전에는 발행 완료가 아니다.

## 주요 변경

- Windows Chrome·Edge에서 한글 IME 조합 직후 나가거나 다시 들어와도 마지막 확정 입력을 서버 저장본과 계정별 초안에서 보존한다.
- light/dark 양 테마의 `+ 새 가사`, `연결 관리`, 좁은 화면 제목·버튼·접힌 rail을 복구했다.
- 환경·목적별 HMAC allowlist와 관리자 `LyricsCloud betacode -n`, `ls`, `refresh`를 제공한다.
- 초대 코드·메일 입력 뒤 같은 Google identity가 검증될 때만 코드 소비와 Private Beta grant를 원자 처리한다.
- 주 로고와 favicon/PWA 자산, 신뢰 가능한 version·phase·channel 표시를 적용했다.
- 1.0.1의 10 Phase, 다자리 버전, dev/release image alias 격리와 digest-only 릴리스 계약을 지원한다.

## 검증

P9에서 실제 PostgreSQL integration 250건, desktop/mobile 브라우저 263건, Chromium·Firefox·WebKit release matrix 10건을 통과했다. production image, 암호화 backup/restore, 0.9.0 upgrade/application rollback, secret·취약점·관측·성능 게이트도 통과했다. P10 후보의 전체 CI·네 dev image 발행·동일 SHA 개발 공개 저장/UI/mobile smoke도 PASS다. 최종 main SHA와 정식 digest·운영 smoke는 발행 시 GitHub Release에 기록한다.

## 알려진 제한

- 공식 릴리스 서버의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 `OPS-100-001` 사용자 승인 예외로 미구축이다.
- 단일 web replica의 in-memory rate limiter는 scale-out 전에 공유 limiter로 교체해야 한다.
- iOS/Android update는 PASS지만 상세 기종·OS·브라우저/PWA 모드는 다음 실기기 인수에서 보강한다.

다사용자 공동 편집·공개 공유·AI 생성·미디어 업로드는 1.0.1 범위가 아니다.
