# LyricsCloud 1.1.6 — 편집·자료·가입·공유·복구 B-1 적용

상태: **Phase 5 후보 검증 중**. 정식 main/tag/image/릴리스 서버 변경은 최종 후보 인수 뒤 승인된 release gate에서만 수행한다.

## 주요 변경

- 가사·라임·프롬프트의 CodeMirror 생명주기는 유지하면서 editor shell·저장 상태·자료 panel/mobile sheet를 B-1 Flat-depth와 공통 dark/light token으로 맞춘다.
- 새 가사·라임·프롬프트와 곡 연결 관리에 입력 유지, loading/empty/error/retry, mobile sheet와 focus 복귀를 명시한다.
- beta 가입 오류, 공유 권한 회수와 guest 복구, 탈퇴 재인증 화면을 같은 상태·권한 언어로 정리한다.
- classic/B-1은 같은 copy/export payload, URL·deep link·API·DB·capability·actor/resource local store를 유지한다. 기존 rail과 모바일 더보기 계약도 바꾸지 않는다.

## 설치와 업그레이드

정식 발행 시 `v1.1.6`의 네 서비스 이미지를 같은 source SHA의 exact digest로 고정하고 migrate를 먼저 실행한다. 최신 schema는 `1140_sharing_stability.sql`로 1.1.5와 같다. release는 `LC_UI_VARIANT=b1`을 사용한다. 시각 결함이면 같은 image에서 `LC_UI_VARIANT=classic`을 우선 사용하고, application-first rollback은 1.1.5 exact image를 복원하며 DB volume을 삭제하지 않는다.

## 알려진 제한과 운영 위험

- 실제 Windows/Linux/macOS/Android/iOS 물리 기기, 실제 OS IME·screen reader·200% OS zoom은 이번 버전에서 새로 실행하지 않았다. Linux Chromium·Firefox·WebKit desktop/mobile 자동화는 실제 OS 검증을 대신하지 않는다.
- 합성 viewport/keyboard/focus와 10,000줄 자동 입력은 실제 한글 IME 조합 중간 상태나 모바일 가상 키보드 수명주기 증거가 아니다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련은 사용자 승인 예외로 미구축이다.

## 지원과 보안

B-1은 표현·동선 변경이며 인증, owner/RLS, selected/public capability, guest 제한을 확대하지 않는다. 다른 owner의 자료가 보이거나 편집/테마/패널 전환 중 본문·selection·undo가 사라지거나 저장되지 않았는데 성공으로 표시되면 배포를 중단한다. 취약점은 공개 Issue가 아닌 `SECURITY.md`의 비공개 경로로 보고한다.
