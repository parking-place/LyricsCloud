# PROD-0004 — 이름 있는 가사와 수정 기록

- 상태: Accepted
- 결정 Phase: 0.3.0 Phase 1
- 승인 근거: 사용자 2026-09-05의 0.3.0 Phase 1 실행 지시 및 기존 Sketch §7~8, DEC-07-A 범위

이름 있는 가사는 한 곡 아래 독립 resource ID를 가지며 제목이 같아도 서로 다른 문서다. 복제는 본문·메모·상태를 새 ID로 복사하고 제목 뒤에 ` (복사본)`을 붙인다. 최대 200 Unicode 문자 안에서 접미사를 위한 공간을 확보한다. 원본과 복사본은 이후 독립적으로 바뀌며 핀·즐겨찾기는 새 문서에서 해제한다.

수정 기록은 0.3.1에서 도입하는 불변 복구 snapshot이다. 가사 목록이나 lyric_count에 포함하지 않는다. 현재본을 수정하거나 복원해도 이름 있는 가사를 자동 생성하지 않는다. 복원 전 현재본을 별도 기록으로 보존한 후 과거 내용을 새 최신본으로 적용한다. 5분·중요 작업 전 생성 및 180일/200개 보존은 DEC-07-A를 따른다.

가사별 전체 텍스트 저장은 rowVersion 일치 시에만 허용한다. 오래된 저장은 409로 거부하고 사용자의 미저장 입력을 유지한다. 이 token은 자동 병합이나 revision을 의미하지 않는다. 0.3.1에서 승인된 Yjs 어댑터를 도입할 때 이 현재본을 초기 입력으로 보존한다.

대안인 모든 자동 저장의 독립 가사 생성은 목록을 불필요하게 늘리고, 복구 기록을 가사 버전으로 대신하는 방식은 보존 기간 후 사용자 문서를 잃게 하므로 채택하지 않는다. 영향 작업은 LC-030-P1-01~10, LC-031-P4-01~08이며 독립 ID·복제 원문·집계 제외·비파괴 복원 테스트로 검증한다. 변경 시 기존 가사와 revision의 ID 및 수명 이관이 필요하다.
