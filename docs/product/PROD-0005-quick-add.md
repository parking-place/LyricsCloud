# PROD-0005 — 빠른 아이디어 자료 유형과 새 가사의 부모 곡

- 상태: Accepted
- 결정 Phase: 0.6.0 Phase 4
- 승인 근거: 사용자의 1.0.0까지 단계별 진행 지시, 2026-09-07

## 해결할 질문

모바일에서 즉시 남긴 아이디어를 별도 inbox 자료로 만들지, 기존 자료 중 어디에 저장할지와 전역 빠른 추가에서 새 가사의 부모 곡을 어떻게 정할지 확정한다.

## 검토한 대안

- 독립 `quick_idea` 자료와 inbox를 새로 만든다. 빠른 기록은 단순하지만 새 schema·탐색·삭제·복원·분류 정책이 필요하고 기존 자료와 중복된다.
- 현재 곡의 메모에 자동 추가한다. 입력은 빠르지만 곡이 열려 있지 않은 화면과 독립 표현·프롬프트를 설명하지 못하며 메모를 예고 없이 변경한다.
- 승인된 기존 자료 유형의 최소 초안으로 저장하고 나중에 세부 정보를 보완한다.

## 선택과 이유

- 독립 quick idea 자료 유형은 추가하지 않는다. 전역 빠른 추가는 새 곡·가사·라임 노트·프롬프트의 네 기존 생성 흐름만 제공한다.
- 한 줄 빠른 아이디어는 사용자가 `라임 노트` 또는 `프롬프트`를 명시적으로 고른다. 첫 줄을 임시 제목으로 사용하고, 라임은 원문 본문으로, 프롬프트는 쉼표·줄바꿈 단위 표현으로 저장한다. 제목·태그·곡 연결은 생성 후 기존 편집 화면에서 보완한다.
- 빠른 아이디어는 계정별 IndexedDB에 request ID와 함께 먼저 기록한다. 온라인이면 즉시 생성하고, 오프라인·프로세스 종료·응답 유실 뒤에는 같은 request ID로 재시도한다. 서버의 기존 생성 receipt가 동일 요청을 하나의 자료로 수렴시킨다.
- 새 가사는 항상 owner가 접근 가능한 활성 곡 하나를 부모로 요구한다. 곡·가사 화면에서는 현재 곡을 우선 선택하고, 다른 화면에서는 최근 수정 곡 목록과 검색으로 부모를 고른다.
- 현재 곡이 삭제·전환되었거나 권한이 없으면 자동 대체하지 않는다. 사용자에게 실패를 알리고 다른 곡을 다시 선택하게 한다. 후보가 없으면 먼저 새 곡을 만드는 흐름을 제공한다.
- 취소는 자료를 생성하지 않고 호출 화면으로 돌아간다. 생성 요청 중 연속 탭은 잠그고, 실패 시 입력과 request ID를 유지한다.

## 영향과 검증

- 영향 작업: `LC-060-P4-05`~`LC-060-P4-08`, 공통 `WorkspaceShell`, `/lyrics/new`, 라임·프롬프트 생성 API와 계정별 로컬 초안.
- PC 상단과 모바일 FAB에서 네 생성 흐름을 모두 열 수 있는지 확인한다.
- 현재 곡 우선 선택, 부모 검색, 취소, 빈 후보, 삭제·권한 실패를 검증한다.
- 오프라인 저장 뒤 앱 컨텍스트를 다시 만들고 online event를 발생시켜 동일 request ID가 정확히 한 자료만 만드는지 검증한다.
- 로그아웃 복구 파일과 미전송 초안 판정에 빠른 아이디어가 포함되는지 확인한다.

## 되돌림 비용

독립 inbox가 필요해지면 새 제품 결정과 migration, 목록·검색·삭제·복원 정책이 필요하다. 기존 빠른 아이디어는 이미 라임 또는 프롬프트이므로 자동 재분류하지 않고 사용자가 명시적으로 이동·복제하는 도구를 별도 제공한다.
