# PROD-0003 — 송폼 문법과 구간 복사

- 상태: Accepted
- 결정 Phase: 0.3.0 Phase 1
- 승인 근거: 사용자 2026-09-05의 0.3.0 Phase 1 실행 지시와 0.3.0 Phase 3~4의 명시된 수용 계약

앞뒤 공백을 제외한 한 줄 전체가 비어 있지 않은 `[label]`인 경우에만 송폼이다. label 내부 대괄호는 허용하지 않는다. 표준 영문·번호·Final 변형 및 한글·사용자 label을 원문대로 유지한다. 빈 대괄호, 닫지 않은 대괄호, 본문 중간의 대괄호는 일반 가사다. 제한된 영문 whitelist나 AI 추론 대신 이 문법을 사용해 사용자 송폼을 보존한다.

각 구간은 tag 줄 시작부터 다음 tag 줄 직전까지이며 마지막은 문서 끝까지다. 첫 tag 전의 본문도 전체 복사에서 보존한다. 반복 label은 문서 순서 occurrence와 offset으로 구분한다. UI와 편집기는 하나의 순수 parser를 사용하고 파싱 결과를 별도 DB 원본으로 저장하지 않는다.

구간 복사는 tag와 빈 줄을 포함한 현재 원문의 범위를 사용한다. 복수 선택은 문서 순서로 정렬하고 각 원문 slice를 이어 붙인다. 앞 slice에 줄 끝이 없을 때만 LF 하나로 경계를 구분하며 기존 빈 줄은 제거하지 않는다. CodeMirror 입력에서 CRLF는 LF로 정규화하고 전체·구간 복사는 현재 편집기 문자열을 기준으로 한다. Clipboard 거부 시 같은 문자열을 수동 복사 dialog에 제공한다.

영향 작업: LC-030-P3-01~10, LC-030-P4-01~07. 검증은 Unicode·반복 label·잘못된 대괄호·마지막 구간의 offset 및 문자 단위 복사 비교다. 문법 변경은 저장 원문을 바꾸지 않지만 목차와 복사 범위를 바꾸므로 별도 결정과 회귀 검증을 요구한다.

## 1.0.5 호환 확장

`PROD-NF-002`가 승인한 1.0.5 범위에서는 기존 송폼 한 줄 문법을 유지하면서 대괄호 내부의 첫 `:`만 주 이름과 부태그 경계로 해석한다. 주 이름은 콜론 앞 값을 trim한 문자열이고 반복 occurrence·목차·최근 위치 복원은 이 주 이름을 사용한다. 콜론과 그 뒤 문자열은 추가 콜론·공백을 포함해 원문 범위 그대로 보존하며 편집기 표시만 낮춘다. 콜론 앞이 공백뿐이면 기존에 인식되던 label을 일반 본문으로 강등하지 않고 전체 내부 문자열을 단일 label로 유지한다. DB/API/CRDT/revision/search/export/전체·구간 copy 원문은 바꾸지 않는다.
