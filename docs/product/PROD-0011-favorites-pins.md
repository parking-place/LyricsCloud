# PROD-0011 — 즐겨찾기와 핀의 의미·순서

- 상태: `Accepted`
- 결정 Phase: 0.7.0 Phase 4

## 결정

- 즐겨찾기는 다시 사용할 가능성이 높은 자료의 장기 표식이고, 핀은 지금 집중하는 자료의 짧은 작업 순서다. 두 상태는 서로 독립적이다.
- 곡·가사·라임 노트·프롬프트는 같은 owner 검사와 비노출 404를 사용한다.
- 핀 순서는 자료 유형과 관계없는 owner별 단일 0 기반 순서다. 새 핀은 끝에 붙고 재정렬은 현재 활성 핀 전체를 한 transaction에서 교체한다.
- 일반 목록은 핀과 `pin_order`를 먼저 적용한 뒤 화면의 정렬 기준을 적용한다.
- soft delete는 통합 화면에서 즉시 숨기되 즐겨찾기·핀 값은 보존한다. 복원 후 핀 순서 충돌은 다음 명시적 순서 변경에서 안정적으로 정규화한다.
- 통합 응답은 제목·유형·상태·소속 곡·표시 속성과 시각만 포함하며 본문·메모는 포함하지 않는다.

## 접근성·동시성

- 별·핀은 텍스트 이름과 `aria-pressed` 상태를 제공한다.
- drag는 보조 입력이며 `앞으로`·`뒤로` 버튼과 키보드로 동일한 순서를 바꿀 수 있다.
- toggle과 reorder는 owner별 직렬화하고, 클라이언트도 마지막 사용자 의도를 순서대로 전송한다.
