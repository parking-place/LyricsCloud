# 0.9.1 API·데이터 소유권 감사 행렬

최초 감사 기준일은 2026-09-08이며 1.0.1 공개 가입 경계는 2026-09-10에 추가 감사했다. 모든 private 요청은 세션에서 얻은 내부 `userId`만 신뢰하고 query·path·body의 `ownerId`는 권한 근거로 사용하지 않는다. 존재하는 타인 자료와 존재하지 않는 ID는 모두 같은 404/빈 결과 계약으로 처리한다.

## 부정 행렬 판정

- 읽기: 타인 ID를 상세·검색·최근·저장·연결·revision에 대입해 자료 내용이 반환되지 않는다.
- 쓰기: query/body의 위조 owner는 무시되고 현재 세션 owner에만 쓰거나 404/403으로 실패한다.
- 삭제·복원·purge: 다른 owner 자료는 변경되지 않으며 존재 여부도 누설하지 않는다.
- export: owner별 repeatable-read snapshot과 ZIP이 다른 owner ID·제목·본문을 포함하지 않는다.
- 탈퇴: 요청 직후 기존 session 전부가 폐기되고 7일 철회 전용 session 외 일반 API는 401이다.

전체 자동 회귀에서 미해결 교차-owner 노출은 0건이다.
