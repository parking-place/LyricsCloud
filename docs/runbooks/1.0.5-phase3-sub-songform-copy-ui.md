## 사용자 변화

- `[Verse: whisper]`는 본문에서 `Verse`를 주 강조로, `: whisper`를 낮은 강조로 표시한다. 목차도 주 이름으로 이동·반복 번호를 계산하고 suffix는 보조 정보로만 보여준다.
- 전체 복사 버튼 주변에서 최종 payload 길이를 확인할 수 있다. 3,001자부터 저장이나 복사를 막지 않는 안내를 자동 copy toast와 clipboard 실패 수동 dialog에 함께 표시한다.
- PC·모바일·단축키·저장 오류의 현재 입력 복사는 모두 같은 LF payload와 Unicode code point 판정을 쓴다. 선택 구간 복사는 원문 suffix를 그대로 보존한다.
