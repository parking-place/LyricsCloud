## 범위

- `LC-080-P5-01`~`LC-080-P5-09`
- DEC-13-A의 UTF-8 TXT/Markdown + JSON 전체 내보내기
- DEC-07-A의 정확한 5분 snapshot과 180일/200개 보존 경계
- Phase 1~4 템플릿·설정·휴지통·탈퇴 회귀

구현 계약은 [전체 내보내기 계약](../architecture/0.8.0-EXPORT-CONTRACT.md), 전체 버전 연결은 [0.8.0 작업 추적표](../architecture/0.8.0-TRACEABILITY.md)에 기록한다.

## 구현 검증 항목

- 한 `REPEATABLE READ READ ONLY` snapshot에서 계정 메타데이터를 owner 조건으로 읽고, 창작 자료는 강제 RLS 역할로 50행씩 cursor 처리한다.
- ZIP과 본문 전체를 서버 메모리·디스크에 모으지 않고 chunk 전송하며 완료는 commit, 취소·오류는 rollback과 연결 반환으로 끝낸다.
- 특수문자·제어문자·Windows 예약 이름·같은 제목·한글 파일명을 안전한 고유 UTF-8 경로로 변환한다.
- JSON validator가 schema version, section과 resource·tag·dictionary·template 관계 대상을 검사한다.
- PC·360px에서 템플릿 → 설정 내보내기 → 곡 휴지통·복원 → 100k 근접 가사 ZIP 다운로드를 실행한다.
- 사용자 A/B 각 다운로드에 자기 자료만 있고 상대 owner ID·자료가 없는지 확인한다.
- 탈퇴 확인 dialog에서 실제 전체 ZIP 다운로드와 내보내기 완료/건너뜀 확인을 함께 제공한다.
- revision integration에서 5분 직전/정각과 180일 직전/정각/직후, 200/201개 경계를 고정 시계로 검사한다.

### 원격 인수

기능 commit의 원격 CI·Docker Hub tag/digest, 동일 SHA 개발 배포와 공개 export smoke를 진행한다. 완료 문서 commit도 같은 순서로 재검증한 뒤 최종 SHA와 수치를 이 문서에 기록한다. 릴리스 서버·`main`·`Release`·`latest`는 사용자의 현재 명시적 지시가 없으므로 변경하지 않는다.
