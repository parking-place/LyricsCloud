## 계약

- `user_profiles.owner_id`는 내부 사용자 UUID의 PK·FK이며 사용자 삭제 시 cascade한다.
- 모든 사용자 query는 `SET LOCAL ROLE lyricscloud_app`과 transaction-local `app.user_id`를 사용한다.
- profile API는 session의 내부 user ID만 사용하고 입력 `owner_id`를 저장하지 않는다.
- 미인증은 `AUTH_REQUIRED`, 만료는 `AUTH_SESSION_EXPIRED`, 미소유·미존재 자료는 동일한 `NOT_FOUND`를 사용한다.
- 브라우저 저장소는 `lc:<internal-user-id>:` namespace로 분리하며 로그아웃·계정 변경 때 이전 namespace를 제거한다.
