## 확인한 경계

- 자료·owner 템플릿의 `purge_at`은 `deleted_at + 30 days`가 아니면 DB 제약이 거부한다.
- 곡 복원은 같은 `deletion_batch_id`의 가사만 되돌리고, 독립 삭제 가사는 부모 복원 또는 활성 곡 이동을 명시해야 한다.
- 다중 복원·완전 삭제는 모든 row를 잠근 뒤 한 transaction에서 처리하며 제목 확인이나 owner가 다르면 부분 적용 없이 실패한다.
- 직접 table delete 권한은 회수하고 현재 owner의 휴지통 행만 hard-delete 함수로 제거한다.
- 탈퇴는 10분 이내 생성된 현재 세션만 요청할 수 있고 즉시 모든 기존 세션과 일반 자료 API를 차단한다.
- 탈퇴 후 Google 재인증 세션은 철회 화면만 열 수 있고 `철회` 확인 뒤에만 일반 접근이 돌아온다.
- 30일·7일 경계 직전/정각/직후와 반복 purge를 고정 시계로 검증했고 다른 owner의 자료를 보존했다.
- 브라우저 계정 prefix local/session storage, IndexedDB와 개인 Cache Storage를 탈퇴 시 정리한다.
- live DB 완전 삭제와 인프라 백업 보존 가능성을 사용자 문구에서 구분한다.
