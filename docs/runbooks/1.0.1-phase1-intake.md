## IME 재현 행렬

사용자 보고 원문은 `바라봐→바라보`, `마냥→마냐`, `마땅한→마ㄸㅎ`이다. Windows Microsoft 한국어 IME에서 관찰됐다는 실제 보고는 보존하지만 OS·브라우저·IME 버전과 최초 손실 계층은 아직 기록되지 않았다.

| 입력 위치 | 새/기존 | 단일/다중 탭 | online/offline | 화면·로컬 초안·CRDT·projection·재열기·복사 | 상태 |
|---|---|---|---|---|---|
| 라임 본문 | 둘 다 | 둘 다 | 둘 다 | 세 관찰 문장 문자 단위 대조 | 실제 Windows 재현 대기 |
| 가사 본문 | 둘 다 | 둘 다 | 둘 다 | 위와 같음 | 실제 Windows 재현 대기 |
| 프롬프트 제목·태그 | 둘 다 | 둘 다 | 둘 다 | UI·저장·재열기·복사 | 실제 Windows 재현 대기 |
| 제목·메모 | 둘 다 | 둘 다 | 둘 다 | UI·저장·재열기 | 실제 Windows 재현 대기 |

합성 composition과 Playwright `fill`/붙여넣기는 실제 Windows PASS로 기록하지 않는다. 현재 본문 경로는 CodeMirror composition change를 모아 확정 transaction으로 전달하고, CRDT remote update를 조합 종료까지 보류한다. 제목·메모는 React composing ref로 autosave를 보류한다. 이 정적 구조만으로 보고된 손실 원인을 확정하지 않는다.

## P2 인계 계약

권한 원본은 환경별 HMAC seed와 PostgreSQL admission grant로 분리한다. 신규 가입은 code+claimed email intent를 만든 뒤 검증된 Google identity와 메일이 일치할 때만 code 소비·grant·receipt를 한 transaction으로 commit한다. CLI의 code 원문 복구 AEAD key는 웹 런타임에 주지 않는다. 활성 코드 100개, 기본 24시간, principal별 5회/24시간, 환경 전체 1,000회/24시간을 초기값으로 사용한다.

P1은 실제 Windows 행렬과 인증 후 공개 UI 재현이 남아 있어 완료로 표시하지 않는다. 해당 증거 없이는 P2 완료 또는 P10 release 근거로 승격하지 않는다.
