## IME 재현 행렬

사용자 보고 원문은 `바라봐→바라보`, `마냥→마냐`, `마땅한→마ㄸㅎ`이다. P1 확인 요청 뒤 사용자가 실제 입력과 재진입 결과 화면을 다시 제출해 세 문자열의 durable 저장 손실을 재확인했다. 요청한 Windows Microsoft 한국어 IME에서 수행한 결과로 인수하며, 정확한 OS·브라우저·IME 세부 버전은 제출되지 않아 P5 최종 PASS 환경 기록에 다시 포함한다.

| 입력 위치 | 새/기존 | 단일/다중 탭 | online/offline | 화면·로컬 초안·CRDT·projection·재열기·복사 | 상태 |
|---|---|---|---|---|---|
| 라임 본문 | 둘 다 | 둘 다 | 둘 다 | 세 관찰 문장 문자 단위 대조 | 사용자 재현 확인; 전체 조합은 P5 회귀 |
| 가사 본문 | 새 가사 재진입 | 단일 탭 | online | 입력 직후 화면과 재진입 durable 원본 불일치 | 사용자 재현 확인; 전체 조합은 P5 회귀 |
| 프롬프트 제목·태그 | 둘 다 | 둘 다 | 둘 다 | UI·저장·재열기·복사 | CodeMirror와 별도 React 입력 경로; P5 실제 회귀 |
| 제목·메모 | 둘 다 | 둘 다 | 둘 다 | UI·저장·재열기 | composing ref로 metadata autosave 보류; P5 실제 회귀 |
| 검색·태그·템플릿 | 해당 상태 | 해당 상태 | online 중심 | 입력·결과·적용 후 원문 | 독립 React/form 경로; P5 실제 회귀 |

합성 composition과 Playwright `fill`/붙여넣기는 실제 Windows PASS로 기록하지 않는다. 현재 본문 경로는 CodeMirror composition change를 모아 확정 transaction으로 전달하고, CRDT remote update를 조합 종료까지 보류한다. 다만 `compositionend`의 확정 transaction을 `setTimeout(0)`으로 미룬 뒤 `destroy()`에서 해당 타이머를 취소한다. 화면 이탈·blur와 조합 종료가 겹치면 화면에는 보인 최종 CodeMirror 문자열이 CRDT/outbox에 전달되기 전에 사라지는 최초 손실 경계가 된다. P5에서는 종료 직전 authoritative editor value의 최소 변경을 동기 확정하고, remote queue 해제와 leave/checkpoint 순서를 회귀한다. 제목·메모는 React composing ref로 autosave를 보류하며 다른 입력 경로는 P5 실제 행렬에서 별도 확인한다.

## P2 인계 계약

권한 원본은 환경별 HMAC seed와 PostgreSQL admission grant로 분리한다. 신규 가입은 code+claimed email intent를 만든 뒤 검증된 Google identity와 메일이 일치할 때만 code 소비·grant·receipt를 한 transaction으로 commit한다. CLI의 code 원문 복구 AEAD key는 웹 런타임에 주지 않는다. 활성 코드 100개, 기본 24시간, principal별 5회/24시간, 환경 전체 1,000회/24시간을 초기값으로 사용한다.

P1은 사용자 재현, 최초 손실 경계, 테마 selector 누락과 P2 계약을 확정했다. Windows 환경의 세부 버전과 전체 입력 행렬 PASS는 수정이 들어가는 P5의 최종 실제 기기 인수로 넘기며 미리 성공으로 기록하지 않는다. 버튼·테마 수정과 양 테마 PASS는 P6에서 닫는다.
