- `LC-090-P4-01`~`LC-090-P4-09`

## 구현 결과

- 15개 화면에 하나의 주 제목과 명명된 `main` landmark를 보장하고 편집 화면의 모바일 숨김 레이블을 보조 기술에는 유지했다.
- 밝음·어두움 공통 의미 색상과 빈 화면·위험 영역·프롬프트 토큰 대비를 보정했다.
- `StatePanel`을 도입해 빈 화면과 오류를 종류·제목·설명·다음 행동으로 구분했다.
- 비네이티브 dialog의 키보드 경계를 공통화해 최상위 modal의 Tab 순환, Escape, 처리 중 닫기 차단, 호출 지점 초점 복원을 일관되게 적용했다.
- 저장 실패 후 재시도 시 가사 본문뿐 아니라 편집 cursor 위치도 그대로 남는 회귀 검사를 추가했다.
