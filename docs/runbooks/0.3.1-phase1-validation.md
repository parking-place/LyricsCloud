# 0.3.1 Phase 1 검증

2026-09-05에 합성 문서와 격리 PostgreSQL만 사용했다. Yjs 13.6.32의 stable update API를 editor adapter 뒤에 두고 [동일 owner CRDT 계약](../architecture/0.3.1-CRDT-SYNC-CONTRACT.md)을 고정했다.

- opaque document key와 resource/owner mapping, UUID update ID, 1 MiB update·400,000 byte 본문 제한을 정의했다.
- 다른 owner, 미인증·만료 session, 삭제 문서는 모두 `SYNC_DOCUMENT_UNAVAILABLE`로 거부한다.
- 본문은 `Y.Text("body")`, 제목과 나머지 metadata는 ADR-0004의 관계형 CAS 명령으로 유지하며 projector가 둘을 결정적으로 결합한다.
- 두 client의 반대 순서 update와 3회 중복 전달이 같은 본문으로 수렴하고, snapshot+후속 delta로 한글·emoji·LF 본문을 복구함을 검사했다.
- `pnpm check`, 24개 파일 90개 unit/DB test, production standalone build, secret scan을 통과했다. 전체 PC/mobile E2E 74개 중 버전 전환으로 드러난 baseline 기대값만 보정했고 나머지 72개가 통과한 뒤 baseline 2개를 재실행해 통과했다.
- schema와 사용자 화면 동작은 바뀌지 않는다. Phase 2는 이 문서 key를 owner와 함께 IndexedDB compound key로 사용한다.
