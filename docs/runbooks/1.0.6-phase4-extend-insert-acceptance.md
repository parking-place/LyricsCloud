# 1.0.6 Phase 4 Extend·송폼 삽입 교차 인수

## 수용 결과

- `[Extend: 3:00:24]` 뒤 두 줄을 Suno 전체 복사하면 Extend 표식 한 줄만 제외되고 두 가사 줄은 정확히 남는다. 저장 원문·부분 복사·수정 기록·계정 내보내기는 표식과 시간 문자열을 그대로 보존한다.
- 메뉴를 연 시점의 CRDT 상대 caret 앞에 다른 탭이 접두어를 추가해도 선택한 송폼은 원래 논리 위치에 한 번만 들어가며 한 번의 undo로 삽입만 취소된다.
- Chromium desktop 합성 조합 중 메뉴 요청은 원문을 바꾸지 않고 안내하며, Escape는 메뉴만 닫고 편집기 focus를 돌려준다.
- 다른 계정, offline/재접속, 저장 후 재진입, 100,000자 경계와 공개 개발 collaboration 재시작 뒤에도 원문·권한·document key를 유지한다.
