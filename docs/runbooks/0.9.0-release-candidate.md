## 지원 기준

LyricsCloud 0.9.0은 Next.js 16의 공식 무설정 최소 브라우저인 Chrome 111+, Edge 111+, Firefox 111+, Safari 16.4+를 하한으로 삼는다. 기준 출처는 [Next.js Supported Browsers](https://nextjs.org/docs/architecture/supported-browsers)다. 설치형 PWA와 실제 모바일 인수 범위는 보안 업데이트를 받는 iOS/iPadOS 16.4+ Safari와 Android 12+ Chrome 111+다.

| 대상 | 최소 지원 | 자동 출시 후보 증거 | 실제 기기 증거 |
|---|---|---|---|
| Chrome / Edge desktop | Chromium 계열 111+, Windows 11 또는 지원 중인 macOS | Playwright Chromium 151.0.7922.34, 1440×1000 통과 | 데스크톱 Chromium 공개 smoke 통과 |
| Firefox desktop | Firefox 111+, Windows 11 또는 지원 중인 macOS | Playwright Firefox 153.0, 1440×1000 통과 | 자동 엔진 기준 |
| Safari desktop | Safari 16.4+, 지원 중인 macOS | Playwright WebKit 26.5, 1440×1000 통과 | 자동 엔진 기준; Playwright WebKit은 Safari 자체가 아님 |
| iPhone / iPad | iOS/iPadOS 16.4+ Safari, 브라우저 탭과 홈 화면 설치본 | WebKit 26.5, 390×844 touch 통과 | `IOS_PHYSICAL` 행에 기종·OS·Safari·설치 방식 기록 필요 |
| Android | Android 12+ Chrome 111+, 브라우저 탭과 설치본 | Chromium 151.0.7922.34, 390×844 touch 통과 | `ANDROID_PHYSICAL` 행에 기종·OS·Chrome·설치 방식 기록 필요 |

Playwright의 Chromium·Firefox·WebKit은 브라우저 엔진 회귀용이며 실제 Safari/모바일 기기를 대신하지 않는다. 엔진 의미와 한계는 [Playwright Browsers](https://playwright.dev/docs/browsers)를 따른다.

## 실제 기기 실행 절차

1. 공개 개발 주소를 일반 브라우저 탭에서 열고 허용된 Google 계정으로 로그인한다. 실제 창작물 대신 제목에 `0.9 기기 인수`를 붙인 합성 곡·가사만 만든다.
2. 홈 화면에 설치한 뒤 설치본에서 합성 곡·가사·라임·프롬프트를 열고 OS 한글 IME로 `한글 조합 입력 확인`을 입력한다. 전체/송폼 복사 후 다른 앱에 붙여넣고 앱으로 돌아와 본문·cursor가 유지되는지 확인한다.
3. 편집 화면을 연 채 비행기 모드로 전환하고 `오프라인 종료 복구`를 추가한다. 앱을 완전히 종료한 뒤 네트워크가 없는 상태로 다시 열어 문구와 입력을 확인하고, 연결 복구 후 `방금 저장됨`과 다른 브라우저 탭의 동일 본문을 확인한다.
4. 미전송 입력이 있는 동안 새 service worker가 발견되면 `업데이트 적용`이 비활성인지 확인한다. 재연결·저장 뒤 적용하고 같은 자료가 유지되는지 확인한다.
5. Clipboard 권한을 거부하거나 사용할 수 없는 상태에서 복사를 실행해 실패 이유와 전체 선택된 수동 복사 원문을 확인한다. Android는 뒤로 가기와 세로/가로 회전 뒤에도 필수 버튼과 초안이 남는지 확인한다.
6. 로그아웃 전 미전송 입력 보호 안내를 확인하고, 저장 후 로그아웃한다. 설치본과 일반 탭 모두 보호 route가 로그인으로 이동하며 이전 계정의 제목·본문·최근 위치가 보이지 않는지 확인한다.
