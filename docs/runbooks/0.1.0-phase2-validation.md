## 계약

- `/api/auth/login`은 state, nonce, PKCE verifier를 만들고 거래 해시를 DB에, 암호화된 거래 자료를 10분 HttpOnly·SameSite=Lax 쿠키에 저장한다.
- `/api/auth/callback`은 거래를 원자적으로 한 번만 소비하고, 검증된 `issuer + sub`를 내부 UUID에 연결한 뒤 opaque 세션 원문의 SHA-256 해시만 저장한다.
- 세션은 30일 idle·90일 absolute 제한이며 만료 7일 전부터 idle 만료를 갱신한다. HTTPS 환경에서는 `__Host-` 이름과 Secure를 적용한다.
- `/api/auth/logout`은 같은 origin POST만 받고 서버 세션을 폐기하며 쿠키 삭제와 `Clear-Site-Data` 신호를 반환한다.
- 로그인 후 위치는 단일 `/`로 시작하는 내부 경로만 허용한다.

## 실제 Google 확인

자동 검증은 로컬 합성 OIDC 공급자로 protocol과 실패 경계를 검사했다. 이후 로컬 `.env`에만 보관한 실제 Google Cloud OAuth client와 허용 계정으로 사용자가 브라우저 로그인 성공을 확인했다. 비밀 값·이메일·provider token·session 원문은 검증 출력이나 저장소에 포함하지 않았다. 브라우저 재시작·재로그인·로그아웃을 포함한 최종 사용자 흐름은 Phase 5에서도 다시 확인한다.
