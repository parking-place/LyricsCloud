# 1.0.14 Phase 1 — 웹폰트 계약

## 채택

- 자산: 공식 Noto Sans KR 2.004 `NotoSansKR-Regular.otf` 한 파일
- 권리: SIL Open Font License 1.1 원문을 자산과 함께 배포
- provenance: ZIP `ac7eeb4e…1747b612`, OTF `69975a0a…e0148d68`, LICENSE `6a73f954…3efe2bf2`
- fallback: 현재 system sans stack 유지, `font-display: swap`
- 범위: Latin, 한글 완성형·자모, Kana, Korean subset에 포함된 Han·기호. 누락 글리프는 system fallback

## 예산

| 항목 | P1 기준/상한 |
|---|---:|
| 현재 public 파일 합계 | 4,702B |
| font 원본 | 4,644,748B |
| 선택 시 cold 요청 | 1건, 4.7MB 이하 |
| warm/offline 추가 네트워크 | 0건 |
| 문서/제어 JS gzip 증가 | 20KB 이하 |

외부 CDN은 사용하지 않는다. 서브셋 재생성이나 다른 weight 추가는 이 버전 범위가 아니다. 폰트 실패는 글자를 숨기거나 저장을 막지 않으며 원문·copy·selection·undo·IME를 바꾸지 않는다.

공식 근거와 rollback은 [ADR-NF-007](../adr/ADR-NF-007-web-fonts.md), 사용자 동작은 [PROD-NF-008](../product/PROD-NF-008-web-fonts.md)을 따른다.
