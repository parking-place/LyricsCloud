## 구현과 상태 연속성

곡·라임 노트·프롬프트 목록에 동일한 목록/작게/중간/크게 선택기를 연결했다. 선택기는 현재 상태를 `aria-pressed`로 알리고 저장 중에는 조작을 잠근다. 저장은 낙관적으로 반영하되 실패하면 직전 값으로 되돌리고, stale 409는 서버 최신값을 다시 읽어 충돌을 알린다.

보기 전환은 기존 목록 배열과 item key를 그대로 사용하므로 검색 query, 필터, 정렬, 추가 로드한 항목과 URL을 재생성하지 않는다. 작은 밀도는 보조 미리보기 우선순위만 낮추며 제목·액션·수정일은 유지한다. 320px에서도 각 grid 최소 폭을 컨테이너 이하로 제한하고 긴 한글 제목을 줄바꿈한다.
