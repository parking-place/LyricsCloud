# 1.0.3 Phase 3 프롬프트 모드 UI 인수

## 구현 결과

- 신규·편집·템플릿 화면에 태그형/문장형 선택을 제공하고 목록 카드에는 현재 mode를 표시한다.
- 문장형 textarea는 쉼표·마침표·공백·줄바꿈과 IME 조합 중 값을 raw 그대로 로컬 초안과 서버에 저장한다.
- 내용이 없는 반대 표현으로 전환할 때만 원문과 변환 미리보기·확인을 보여준다. 확인 전 checkpoint를 만들고 완료 직후 undo를 제공한다.
- mode 전환과 두 표현 교체는 하나의 Yjs transaction이며, 이미 저장된 반대 표현으로 보기를 바꾸는 동작은 어느 원문도 변환하지 않는다.
- 목록·가사 자료 패널·전체 복사는 mode별 공통 `plainText` 결과를 사용한다. 템플릿은 같은 mode끼리만 뒤에 추가한다.
- revision v2의 mode·문장 원문을 UI가 읽지 못하던 회귀를 발견해 v1 태그 기록과 v2 태그/문장 기록을 모두 표시·복원하도록 고쳤다.
