# 1.0.4 Phase 4 프롬프트 표시·복사 교차 인수

## 수용 결과

- `a.. b.`·소수·URL·미완성·CRLF의 표시 span을 연결하면 API raw와 같다.
- 999·1000자는 경고하지 않고 1001자만 안내하며 세 payload 모두 복사를 막지 않는다.
- emoji·분해 한글·공백·줄바꿈을 포함한 최종 payload의 Unicode code point 수를 사용한다.
- 목록 빠른 복사·편집기·가사 자료 패널·clipboard 실패 수동 대안이 같은 payload와 경고를 사용한다.
- 다른 계정 접근은 차단되고 offline 초안·두 탭·한국어 조합 직후 이탈·재접속에서 기존 저장 계약을 유지한다.

## 자동·실제 환경 증거

- 구현·검증 후보: `dd638e70051acd74486b4056d66503caffe26311`
- Node 24.20.0, pnpm 11.25.0, 깨끗한 PostgreSQL 18: migration 2회와 unit/integration 263 PASS, 기존 별도 beta signup 4 skip.
- Chromium PC/mobile 전체: 310건 중 279 PASS, 환경 조건에 따른 기존 31 skip.
- 새 기능 5-project 행렬: Chromium desktop/mobile, Firefox desktop, WebKit desktop/mobile 10 PASS.
- `pnpm check`, production `pnpm build` PASS.

첫 DB 실행은 이전 E2E가 남긴 격리 DB의 pending projection 때문에 기대 1건이 2건으로 집계됐다. 작업 전용 임시 DB를 새로 만들고 같은 전체 검사를 통과해 제품 결함과 구분했다. 첫 5-project 실행은 테스트가 프로젝트명 `mobile`만 인식해 `chromium-mobile`·`webkit-mobile` 패널을 잘못 찾았다. `endsWith("mobile")`로 최소 수정한 뒤 같은 10건을 재실행해 모두 통과했다.

실제 Windows/iOS/Android 물리 입력은 이번 Phase에서 새로 수행하지 않았으며 자동 브라우저 결과로 대체했다고 표시하지 않는다.
