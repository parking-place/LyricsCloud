# 0.9.0 Phase 1 UI 감사 기준선 검증 기록

## 범위

- `LC-090-P1-01`~`LC-090-P1-08`
- 목업 01~15와 구현 라우트·컴포넌트·기획 절의 일대일 추적
- PC·좁은 PC·태블릿·모바일의 합성 데이터 시각 기준선
- 화면 상태, 공통 셸, 디자인 토큰과 접근성 차이의 P0~P3 분류

감사 결과와 Phase 2 이후 인계 항목은 [0.9.0 UI 감사 보고서](../architecture/0.9.0-UI-AUDIT.md)에 기록한다.

## 구현 검증 항목

- `UI-01`~`UI-15`가 목업 디렉터리 15개와 각각 하나의 실제 라우트로 연결된다.
- 각 화면은 정상·로딩·빈 상태·오류·저장·오프라인·권한 없음 상태의 보유 여부와 강제 전환 경로를 기록한다.
- 목업 README의 추가 제안 7개 원문 행과 중복 제거한 5개 요구를 별도로 추적한다.
- 1440×1000, 1024×768, 768×1024, 390×844의 네 뷰포트에서 동일한 격리 합성 계정으로 15개 화면을 캡처한다.
- 캡처에는 실제 계정이나 창작 자료를 사용하지 않으며 고정 locale·timezone·color scheme·reduced motion을 적용한다.
- 공통 상단바, 좌측 메뉴, 편집기 우측 패널과 모바일 내비게이션의 전환 경계를 감사한다.
- 색상·간격·타이포그래피·모서리·그림자·포커스 토큰을 조사하고 기능·접근성·시각 차이를 P0~P3로 분리한다.
- CI가 감사 문서 행 수, 목업 디렉터리, 캡처 파일 수·이름·PNG signature를 자동 검증한다.
