# LyricsCloud 1.1.6 Phase 1 편집·복구 화면 계약

## 기준과 범위

- 계획 source: 1.1.5 정식 릴리스 기록 main `98c2a29566b6d8382f19ddbc44560a28fcaaebf2`; 실제 제품/운영 source는 annotated `v1.1.5`의 `17fb4a9377584c477220092ed91317182f112c8b`다.
- 승인 입력: B-1 통합 workspace+Flat-depth, 기존 기능 보존, `LC_UI_VARIANT=classic` 즉시 시각 rollback.
- P1은 문서-only 계약 단계다. runtime `VERSION`·package·image·DB·API·운영 서버를 바꾸거나 1.1.6 제품 완료를 주장하지 않는다.
- 포함: 가사·라임·프롬프트 편집기, 자료 패널, 가입/beta 오류, 공유·권한 회수, 탈퇴·초안/미전송 복구 화면의 표현·배치·focus 계약.

## 상태와 생명주기 계약

1. B-1/classic, theme, responsive CSS, panel open/close는 기존 editor component의 state만 바꾸며 editor mount effect의 identity 입력에 추가하지 않는다.
2. `EditorView` 생성·destroy는 resource ID 교체 또는 component 실제 unmount에만 대응한다. 단순 시각 전환 중 `finishComposition()`이나 `destroy()`를 호출하지 않는다.
3. DOM 이동이 필요하면 editor parent를 조건부 교체하지 않고 한 고정 mount 안에서 CSS grid/order를 바꾼다. portal에는 editor 자체가 아닌 menu/dialog/sheet만 둔다.
4. 새 observer/listener/timer가 필요하면 effect cleanup과 단일 등록 회귀를 먼저 추가한다. `visualViewport`는 선택 사항이며 없을 때 `100dvh`/safe-area fallback을 유지한다.
5. 10,000줄 성능 입력은 합성 텍스트로 측정한다. P2는 동일 Chromium 환경의 panel/theme/resize 전후 입력·heap/DOM 기준을 기록하고, P4는 지원 browser matrix에서 결과 동등성을 판정한다.

- P2 단위/계약: `tests/new-feature/1.1.6.contract.test.ts`를 실제 Vitest include에 등록해 editor mount key·상태 의미·copy payload·listener cleanup·B-1/classic selector를 실패부터 고정한다.
- P2 구현: `lyric-editor.tsx`, `rhyme-editor.tsx`, `prompt-editor.tsx`, `lyric-resource-panel.tsx`, 공통 UI/CSS. server API·domain schema·migration은 변경하지 않는다.
- P3 사용자 흐름: `tests/e2e/new-feature-1.1.6.spec.ts`에서 PC/mobile×dark/light의 편집·자료·가입/공유/복구/탈퇴 상태와 focus를 검사한다. 스크린샷은 합성 계정/자료만 사용한다.
- P4 회귀: 실제 PostgreSQL, Chromium/Firefox/WebKit desktop과 Chromium/WebKit mobile, offline/reconnect/revoke/restart, 10,000줄·200% browser zoom을 분리 기록한다.

## 호환·중단·rollback

- API·DB·migration·URL·copy payload·권한·local store key는 1.1.5와 동일하다. 변경 필요성이 발견되면 P2를 중단하고 별도 계약/실패/rollback 승인을 먼저 기록한다.
- editor DOM 교체, IME/selection/undo/scroll/outbox 유실, 거짓 저장 완료, recovery 원문/다른 actor 노출, W⊆R 위반, modal 탈출·필수 버튼 불능은 즉시 중단 조건이다.
- 시각/배치 결함은 같은 source에서 `LC_UI_VARIANT=classic`으로 되돌린다. 자료/권한 이상은 1.1.5 exact image application-first rollback을 사용하며 DB volume과 1140 schema를 삭제하지 않는다.
- 실제 Windows/Linux/macOS/Android/iOS 물리 기기, 실제 OS IME·NVDA/VoiceOver/TalkBack·OS 200% zoom은 P1에서 미실행이다. Linux browser 자동화나 viewport는 이를 PASS로 대체하지 않는다.
- `OPS-100-001` 외부 암호화 backup 예외는 유지한다.

## P1 판정

현행 source와 회귀를 읽어 editor/store/copy/security 생명주기와 P2~P5 담당을 고정했다. 사용자 승인 B-1의 의미를 새로 넓히지 않으며 P2가 위 실패 테스트를 먼저 만들 수 있는 입력이 준비됐다. P1은 문서-only로 완료하고 앱 CI·image·개발/릴리스 서버 배포는 수행하지 않는다.
