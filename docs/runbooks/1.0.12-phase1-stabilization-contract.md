## 확인한 병목과 측정

세 목록은 각 item마다 전체 배열을 `filter`하고 결과를 `findIndex`해 O(n²)이다. 같은 입력·Node 20 프로세스에서 기존과 한 번의 선형 precompute를 각각 12회 실행했다.

| item 수 | 기존 median / p95 | 선형 후보 median / p95 | p95 변화 | 결과 |
|---:|---:|---:|---:|---|
| 2,500 | 25.90 / 46.18 ms | 0.26 / 0.68 ms | 68.1x | exact-equivalent |
| 10,000 | 450.40 / 482.97 ms | 0.85 / 1.90 ms | 253.8x | exact-equivalent |

이는 순수 계산 microbenchmark이며 브라우저 render·메모리·실기기 성능을 대신하지 않는다. P2는 결과 동등성과 선형성 실패 시험을 먼저 등록하고 공통 함수를 구현한다.

## 수용·실패 입력

- 빈 배열, pinned only, unpinned only, 섞인 배열에서 각 ID의 group position/size가 기존 정의와 같아야 한다.
- 중복 ID는 서버 계약 위반이므로 명시적으로 거부해 잘못된 이동 target을 만들지 않는다.
- 곡·라임·프롬프트의 카드 순서, 첫/이전/다음/끝 버튼 활성화와 drag target은 변경되지 않아야 한다.
- 저장·복사·Suno 링크·삭제/복원·PWA/계정 전환은 기존 수직 회귀로 검증한다.
- 공유 ADR·실제 다중 사용자·운영 backup 인수가 미완료이므로 `AC-1.0.12-04`에 따라 1.1.0을 자동 시작하지 않는다.

되돌림은 공통 utility 소비를 제거하고 기존 inline 계산으로 복귀하는 코드-only 변경이다. schema/data rollback은 없다.
