# 1.0.14 Phase 3 — 폰트 선택·편집 적용

## 구현 계약

- 계정 기본값과 가사별 override의 `writing_font`에 `noto_sans_kr`를 추가했다. `1004_web_font_selection.sql`은 기존 행을 바꾸지 않고 두 check constraint만 확장한다.
- 설정과 가사별 설정은 동일한 네 옵션과 한글·영어·일어·Han·기호 미리보기를 사용한다. 저장은 기존 owner RLS·CAS를 그대로 거치며 새로고침과 다른 기기에서 서버 값을 다시 읽는다.
- 가사·라임·프롬프트 본문은 하나의 font-family/fallback 매핑을 소비한다. 폰트 전환은 CSS 변수만 바꾸고 CodeMirror·textarea·동기화 객체를 다시 만들지 않으므로 cursor·selection·undo·scroll·IME와 원문/copy 경계가 유지된다.
- 라임·프롬프트의 새 문서 화면도 같은 계정 기본값을 받는다. compact prompt tag UI는 family만 적용해 320px·200% 확대에서 제어부 overflow를 만들지 않는다.

## rollback

애플리케이션을 먼저 이전 버전으로 되돌린 뒤 `1004_web_font_selection.sql` rollback을 적용한다. rollback은 새 값을 `sans`로 명시 변환한 후 기존 세 값 constraint를 복원하며 다른 표시 설정과 창작 원문은 보존한다.
