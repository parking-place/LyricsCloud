## 구현 계약

- 첫 ASCII 콜론 앞의 trim된 주 이름을 탐색·occurrence에 사용하고, 콜론부터 닫는 대괄호 직전까지의 suffix와 절대 범위를 lossless projection으로 제공한다.
- 주 이름이 공백뿐인 기존 label과 잘못된 괄호 처리는 이전 인식 규칙을 유지한다.
- suffix-only 편집은 같은 offset의 section id와 주 이름 occurrence를 바꾸지 않는다. parser/index는 읽기 전용 projection이며 editor transaction·composition·undo·CRDT 원문을 만들거나 바꾸지 않는다.
- 전체 가사 copy builder는 기존 CRLF/CR→LF 직렬화 뒤 최종 문자열의 Unicode code point를 세고 3,001부터 경고 상태를 반환한다. 구간 복사는 원문 suffix를 그대로 유지하며 경고 대상이 아니다.
