# 1.0.2 Phase 4 실패·권한·복구 교차 회귀

## 수용 사례

| 수용 ID | 자동/실제 경계 | 결과 |
|---|---|---|
| `AC-1.0.2-01` | PostgreSQL 18 실제 transaction + 합성 beta identity | 응답 유실 뒤 새 intent 재시도가 기존 active grant를 반환했다. code consumption·receipt·grant·completed intent가 각 1개여서 중복이 없었다. |
| `AC-1.0.2-02` | desktop/mobile Chromium + 실제 IndexedDB | 로컬 queue 쓰기 실패 때 서버 `방금 저장됨`이 표시되지 않았고 화면 원문·pending 이탈 guard·exact-copy·재시도가 유지됐다. |
| `AC-1.0.2-03` | service worker 허용 Chromium context | 이전 worker를 연 상태에서 새 worker를 설치해도 메모리 입력·IME·미전송 outbox가 있으면 적용 버튼이 비활성이고 즉시 reload하지 않았다. 저장 뒤 사용자 적용에서만 reload했다. |
| `AC-1.0.2-04` | P1~P4 diff·회귀 검토 | 실제 결함 경계인 이탈 guard·build별 worker·복구 동선만 수정했다. 수치 채우기 기능·schema·API·wire 변경은 만들지 않았다. |

## 실행 결과

| 환경·명령 | 결과 |
|---|---|
| PostgreSQL 18 disposable, `pnpm migrate` 2회 | fresh 상태 유지와 repeat/no-op PASS; 최대 schema `0901_beta_signup.sql`, 추가 migration 없음 |
| Node 24.20, `AUTH_DATABASE_INTEGRATION=true pnpm test` | 64 files 248 PASS, beta 전용 4건은 전용 opt-in이 없어 의도적 skip |
| 같은 DB, `pnpm test:beta-signup:0901` | 4 PASS; 응답 유실 재시도 포함 |
| 같은 DB, `pnpm test:beta-admin:0900` | issue/list/refresh/concurrency/output failure recovery PASS |
| Playwright 1.62.1 Chromium desktop/mobile, 전체 `tests/e2e` | 267 PASS, 31 의도적 skip; 계정 A/B, 초대, 오프라인, 재접속, PWA, 저장·복구 포함 |
| Chromium/Firefox/WebKit desktop + Chromium/WebKit mobile release matrix | 10 PASS; 15화면 이동과 약 10,000줄 한글 입력·수동 복사 |

첫 DB 명령은 `NODE_ENV` 누락으로 config 검증에서 migration 전 중단됐다. `NODE_ENV=test`를 명시해 같은 격리 DB에서 성공했으며 실패 시도를 PASS에 포함하지 않았다. 첫 전체 E2E는 새 P3 문구의 옛 기대값 한 곳, 두 번째는 p4 runtime에 남은 p2 기대값 두 곳을 발견해 각각 중단했다. 제품 동작을 완화하지 않고 테스트를 새 공개 계약과 실제 health metadata에 맞춘 뒤 targeted 2+4 PASS와 전체 suite PASS를 다시 확인했다.

## 교차 경계와 미실행

- 다른 owner의 path/query/body 변조, 계정 변경 시 이전 owner local data 제거, 세션 만료 뒤 같은 owner outbox 재개를 포함했다.
- 오프라인 탭 종료·재진입, ACK 유실 동일 update 재전송, 3 replica 수렴, projection 지연, 저장 실패·Clipboard 거부를 포함했다.
- 자동 브라우저와 합성 IME event는 실제 OS IME가 아니다. P4에서 물리 Windows/iOS/Android를 새로 실행하지 않았고 1.0.1 인수는 과거 증거로만 남긴다.
- 운영/릴리스 DB와 릴리스 서버는 사용하지 않았다. 외부 backup 미구축 예외 `OPS-100-001`은 이번 UI·회귀 patch로 닫지 않는다.
- production image의 DB·collaboration restart와 동일 SHA 개발 공개 인수는 후보 commit 확정 뒤 이 문서에 연결한다.
