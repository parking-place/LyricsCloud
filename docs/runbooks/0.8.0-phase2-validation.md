## 확인한 동작과 실패 경계

- 서버에서 계정 테마를 읽고 inline 초기화로 첫 paint 전에 적용하며 `system`일 때만 운영체제 색상 변경을 따른다.
- 다른 기기 저장은 다음 화면 진입 때 갱신되고, 가사별 재정의가 있으면 이후 계정 변경보다 계속 우선한다.
- 설정 화면은 미리보기·저장·취소·제품 기본값을 분리하고, 저장 실패 시 로컬 미리보기와 서버 값이 다름을 알린다.
- 모바일 설정 시트와 가사별 modal/sheet는 Escape·Tab trap·opener focus 복원을 제공하고, 저장·취소·초기화 뒤 편집 위치를 유지한다.
- light/dark 핵심 텍스트·버튼·상태·focus 대비를 자동 검사했고 외부 font 요청이 없음을 확인했다.
- 다른 owner의 가사 설정은 공통 404이며, 범위 밖 숫자·외부 font 문자열은 400, 오래된 row version은 409로 거부된다.
