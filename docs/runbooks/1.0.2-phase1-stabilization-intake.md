## 고정 인터페이스와 호환성

- beta signup의 외부 API, code 형식, grant/receipt schema는 바꾸지 않는다. 동일 principal이 응답 유실 뒤 새 signup intent를 시작하면 기존 active grant를 반환하고 consumed code를 다시 소비하지 않는 기존 의미를 테스트로 고정한다.
- editor의 IndexedDB schema, Yjs wire payload, 서버 ACK 형식은 바꾸지 않는다. DOM `data-pending-input`은 저장 전 메모리 상태를 PWA/이탈 guard에 알리는 내부 UI 계약으로만 추가한다.
- `/sw.js`는 같은 origin의 공개 `BUILD_ID`를 query로 받아 registration과 cache namespace를 build별로 분리한다. 인증 정보나 사용자 자료는 URL/cache에 넣지 않는다. 구버전 worker는 기존 cache를 계속 사용할 수 있고 새 worker 활성화 시 이전 `lyricscloud-shell-*` cache만 정리한다.
- rollback은 application-first다. 새 schema/migration이 없으므로 v1.0.1 image로 되돌릴 수 있으며 DB와 사용자 volume은 변경하지 않는다.
