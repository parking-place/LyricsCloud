# Operational runbooks

재현 가능한 명령, 예상 출력, 실패 시 중단 기준, 복구·롤백 방법을 포함합니다.

1. 개발 환경 시작·종료
2. migration 적용·복구
3. 배포·rollback
4. 백업 생성·검증·별도 환경 복원
5. 탈퇴·휴지통 purge 작업 확인
6. CRDT 동기화 장애와 평문 투영 재구성
7. 비밀 회전과 보안 사고 대응

실제 명령은 관련 구성이 구현되고 검증된 버전에서만 추가합니다.
