# 1.1.3 Phase 3 — 공개 게스트 작성 사용자 흐름

## 구현

- 소유자는 공개 링크 관리 화면에서 읽기와 `읽기 + 비로그인 작성`을 비교하고, 실제 노출·수정·브라우저 보관 위험을 확인한 뒤에만 공개 쓰기를 켠다. 읽기 selected와 쓰기 public-link 같은 불가능한 조합은 서버와 UI가 함께 거부한다.
- 게스트는 링크가 허용한 가사 본문만 CodeMirror에서 편집한다. 계정·workspace·자료 목록·메모·연결 자료·revision·ACL·metadata·삭제 권한은 얻지 않는다. 탭마다 별도 서버 guest session과 표시 이름을 사용하며 현재 guest끼리의 인증된 presence만 본다.
- 본문 update는 link·guest session·permission/write epoch·durable update ID에 결합한다. ACK 전 outbox는 로컬에 보존하되, 제한·중지·회수로 거부되면 서버 확인본으로 즉시 돌아가고 본인 입력만 별도 복구함에서 복사·다운로드할 수 있다. 재허용이나 재연결은 거부 입력을 자동 적용하지 않는다.

## 자동 검증

- Chromium desktop/mobile 전용 P3 제품 흐름과 기존 1.1.1 public-read·1.1.2 selected-writer 관련 회귀가 PASS했다.
