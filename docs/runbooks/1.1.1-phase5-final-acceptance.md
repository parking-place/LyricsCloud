## 완료 증거

P4 제품 후보 `b920049f5b00bbe44809d1d96bec0f5fd7650c4c`는 Actions push `34697600730`과 PR `34697608114`, 실제 PostgreSQL 권한/복구 통합, 5-browser 공개 링크 행렬, 동일 SHA 개발 서버의 collaboration 실제 재시작·offline/reconnect·회수를 통과했다.

P5 최종 제품 후보 `f0131543bbf24d58ed738145e97e7ce1ab006f63`은 Actions push `34701755594`와 PR `34701763143`의 전체 검증을 통과했다. push 실행의 네 dev image 게시·서명, 26개 migration·환경·license·release manifest 봉인, 전체 브라우저·selected-read·public-link 5-browser·release candidate 행렬이 PASS했다.

같은 SHA를 개발 서버 `1.1.1/dev/p5`, schema `1110_public_lyric_read_links.sql`로 배포해 네 서비스 healthy를 확인했다. 공개 smoke는 collaboration 실제 재시작·공개 projection 유지·회수·private API 차단과 owner 확인·일회 링크·fragment 제거·mobile 비로그인 읽기·live update·열린 탭 회수·빈 가사 최초 공개를 통과했고 합성 fixture를 제거했다. 미해결 제품 P0/P1, raw capability 노출, 승인 밖 private 접근, 공개 write, 회수 뒤 데이터 전달, 원문 유실은 0건이므로 승인된 정식 릴리스 gate를 연다.

실제 OS/물리 기기는 P5에서 새로 실행하지 않는다. 자동화 결과를 실기기 증거로 기록하지 않으며 `OPS-100-001` backup 예외도 열린 상태로 정식 릴리스 판단에 명시한다.
