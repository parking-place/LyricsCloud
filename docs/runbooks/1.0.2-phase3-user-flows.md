# 1.0.2 Phase 3 PC·모바일 사용자 흐름 인수

## 사용자 변화

- 가사·라임의 metadata 저장 실패에는 `서버에 저장하지 못했습니다` 상태와 `현재 입력 복사`를 함께 표시한다. IndexedDB/서버 동기화 실패 문구는 이 기기 임시 초안과 서버 저장을 같은 의미로 말하지 않는다.
- 초대 가입 preflight가 실패해도 코드와 이메일을 유지한다. 사용자는 같은 입력으로 재시도하거나 기존 사용자 로그인으로 이동하거나 입력을 지우고 취소할 수 있다.
- 브라우저 직접 이탈 경고와 PWA update 보류는 P2의 synchronous pending marker를 그대로 소비한다.
- 사용자 스스로 할 수 있는 복사·재시도와 운영자만 할 수 있는 권한·배포 복구를 [사용자 입력 복구](./1.0.2-user-recovery.md)에 분리했다.

## 미실행·경계

- P3에서 물리 Windows/iOS/Android를 다시 실행하지 않았다. 자동 브라우저는 합성 IME event와 Chromium PC/mobile이며 실제 1.0.1 물리 기기 결과를 새 실행으로 계산하지 않는다.
- schema/API/Yjs wire/IndexedDB schema 변경은 없다. 추가 migration과 권한 확장은 없다.
- 전체 회귀·서버 재시작·오래 열린 PWA 교차 검증은 P4, 필수 원격 CI는 P5 최종 후보의 책임이다.
- main·정식 Release·릴리스 서버는 변경하지 않는다.
