# 1.0.4 Phase 2 prompt copy 기반 인수

## 구현

- 구현 후보: `0d17b4a920180167811fbf36529ed9d93b2e248e`
- `splitPromptSentenceDisplay`는 U+002E까지를 span으로 만들고 마지막 미완성 구간을 보존한다. 반환 offset은 raw의 UTF-16 slice 경계이며 span 연결은 항상 raw와 같다.
- `buildPromptCopyPayload`는 최종 문자열을 바꾸지 않고 Unicode code point 수와 `> 1000` 안내 상태를 한 번 계산한다.
- 두 함수는 저장·API·CRDT와 분리된 순수 projection이라 mode/remote snapshot 변경 때 새 입력 전체로 재계산할 수 있고 composition 저장을 일으키지 않는다.
- schema·migration·권한 모델은 변경하지 않았다.

## 인계

P3는 목록·길게 누르기·편집기·가사 자료 패널의 실제 최종 문자열을 이 builder에 넣고 동일 경고를 표시한다. clipboard 실패 fallback에도 builder의 같은 payload를 사용한다. 경고는 복사·저장·입력을 차단하지 않는다. 실제 브라우저·권한·offline·재시작은 P3/P4 범위다.
