# 1.0.4 Phase 3 prompt copy UI 인수

## 구현

- 구현 후보: `f8b5fb67cd3fefdabfb6e0b6874002b2db78976d`
- 문장형 프롬프트의 목록과 편집기는 P2의 lossless span을 렌더링하며 원문·선택·저장 값은 바꾸지 않는다.
- 목록 빠른 복사·길게 누르기, 편집기, 가사 자료 패널과 clipboard 실패 수동 대안은 모두 같은 최종 payload·Unicode code point 수·`> 1000` 경고를 사용한다.
- 경고는 안내 전용이며 1,001자 이상도 입력·저장·복사할 수 있다.
- schema·migration·권한 모델은 변경하지 않았다.

## 검증

Node 24와 Playwright 1.62.1 Docker, 격리 PostgreSQL 18을 사용했다.

| 검사 | 결과 |
|---|---|
| `pnpm check` | PASS |

| prompt-copy unit | 17 PASS |
| `new-feature-1.0.4.spec.ts` Chromium desktop/mobile | 4 PASS, 7.6s |
| `a.. b.`·소수·URL·미완성·CRLF span | DOM span 연결과 API 원문 일치 PASS |
| 1,001자 자동 clipboard·수동 fallback·자료 패널 | 동일 payload·비차단 warning PASS |

HTML textarea/DOM은 CRLF를 LF로 정규화해 표시하므로 화면 assertion은 LF를 사용했다. API 응답과 자동 clipboard assertion은 원본 CRLF를 그대로 비교해 저장 또는 copy payload 손실을 숨기지 않았다.
