# 1.0.9 Phase 3 라임·프롬프트 정렬 UI 검증

## 구현 범위

- 라임 노트와 프롬프트의 모든 목록 보기에 `사용자 정렬`과 카드별 드래그 핸들, 맨 앞/앞/뒤/맨 뒤 버튼을 제공한다.
- 이동은 같은 핀 그룹의 현재 표시 카드로 anchor 명령을 만들고, 성공하면 URL을 `sort=manual`로 전환한다.
- 저장 실패는 원래 순서로 복원하고 같은 request ID의 명시적 재시도를 제공한다. `409`는 최신 서버 순서를 다시 읽는다.
- 프롬프트의 650ms 길게 눌러 복사는 카드 본문에서만 시작한다. 이동 핸들은 별도 버튼이고, 포인터 이동 및 drag 시작은 복사 타이머를 취소한다.

- Node 24 web typecheck: PASS
- production web build: PASS

## 경계와 인계

기존 원문 편집·IME·undo·copy payload는 변경하지 않는다. 물리 Windows/iOS/Android 입력은 이번 자동 브라우저 증거로 대체하지 않으며 P4/P5의 실제 지원 환경 인수 상태에 정확히 기록한다. 추가 schema는 없고 application-first rollback은 새 정렬 선택과 route를 숨긴 뒤 `1002` 데이터를 보존한다.
