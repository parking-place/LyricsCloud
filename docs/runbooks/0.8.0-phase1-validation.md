## 확인한 경계

- 기본 템플릿 본문 수정·삭제 불가, 즐겨찾기와 최근 사용은 사용자별 분리
- 다른 owner 템플릿 조회·수정·적용 공통 404
- 다른 유형 적용과 삭제된/다른 owner 부모 곡은 resource 생성 전 원자 거부
- 적용 뒤 템플릿을 수정해도 이미 만든 가사·프롬프트의 원문과 토큰 순서 불변
- HTML처럼 보이는 사용자 문자열을 DOM으로 만들지 않고 텍스트로 표시
- 360px에서 유형·출처·정렬, 수평 카드 선택, 미리보기·적용·취소 흐름과 문서 가로 overflow 없음
