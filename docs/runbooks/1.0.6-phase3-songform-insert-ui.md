## 사용자 흐름

- 편집 가능한 CodeMirror에서 우클릭하면 브라우저 기본 메뉴를 막지 않으면서 앱 송폼 메뉴를 준비한다. 메뉴키와 `Shift+F10`, 모바일의 `＋ 송폼 삽입`도 같은 목록과 삽입 명령을 사용한다.
- 메뉴를 열 때 선택 head를 Yjs 상대 위치로 보존한다. 원격 prefix 뒤에도 안전한 현재 위치로 해석하며, 기존 선택 본문은 지우지 않고 송폼 한 줄만 한 transaction으로 삽입한다.
- `Escape`, 닫기, 삽입과 원문 copy 뒤에는 편집기 focus를 복원한다. IME 조합 중, 상대 위치 해석 실패, 본문 100,000자 초과는 안내 후 원문을 바꾸지 않는다.
- `Suno용 복사`는 Extend 작업 메모를 제외함을 명시하고, 메뉴에서 `Extend 포함 원문 복사`를 별도로 제공한다. 저장 CRDT·revision·export는 그대로다.
- 메뉴와 모바일 dock은 공통 theme token을 사용한다. 390×844 라이트 모바일에서도 viewport를 넘지 않는다.
