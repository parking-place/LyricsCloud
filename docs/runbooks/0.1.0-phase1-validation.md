## 계약

- 공개 API 오류는 안정된 `code`와 불투명 `requestId`만 반환한다.
- liveness는 프로세스, readiness는 DB 연결과 schema 적용을 검사한다.
- 개발 DB와 테스트 DB는 서로 다른 PostgreSQL service·database·storage를 사용한다.
- CI는 별도 `lyricscloud_test` DB에서 migration을 두 번 실행한 후 정적 검사, 단위 테스트, 운영 build를 같은 lockfile로 수행한다.
- 실제 OAuth 값과 인증 기능은 Phase 2에서만 소비한다.
