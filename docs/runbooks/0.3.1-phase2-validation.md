# 0.3.1 Phase 2 검증

2026-09-05에 owner·resource를 SHA-256 opaque key로 분리한 Yjs IndexedDB 저장소와 BroadcastChannel 탭 병합을 편집기에 연결했다. 확정 CodeMirror transaction만 Y.Text에 기록하며 원격 transaction은 재송신하지 않는다. `navigator.locks`로 최초 seed를 직렬화하고, 온라인·오프라인·로컬 임시 저장 상태를 실제 영속 수준대로 표시한다. 로그아웃은 해당 owner hash prefix의 IndexedDB만 제거한다.

- `pnpm check`, 24개 파일 90개 unit/DB test, production build 통과.
- Chromium PC/mobile 전체 E2E 76개 통과.
- 같은 owner 두 탭의 한글 본문 수렴, network offline 편집, 탭 종료 후 IndexedDB 복구, online 복귀 뒤 PostgreSQL 현재본 반영을 검증했다.
- 0.9.0 service worker 전에는 네트워크 없는 cold start를 지원한다고 표시하지 않는다.
