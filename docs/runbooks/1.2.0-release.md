# 1.2.0 정식 릴리스 경로 — 현재 미승인

이 문서는 1.2.0 정식 배포를 승인하지 않는다. P5 개발 인수와 별도로 사용자의 대상·시점·rollback 승인, `main` 통합, 승인 SHA의 annotated `v1.2.0`, 정식 CI `publish=true`·`release=true`, 네 서비스 signed image의 exact digest·provenance 확인이 모두 필요하다. `Release-latest` 이동과 릴리스 서버 변경은 승인 전 금지한다.

승인 후에도 [개발 배포 절차](development-deploy.md)의 read-only preflight, 운영 DB/volume/secret 분리, schema `1152_prompt_dictionary_cascade.sql`과 migration checksum·기존 자료/브라우저 초안/PWA build를 먼저 고정한다. `OPS-100-001` 외부 backup/24시간 RPO 예외를 운영자에게 다시 알리고 host-loss 복구를 보장한다고 쓰지 않는다. 기존 a나 1.1.7b exact image 또는 `LC_UI_VARIANT=b1`/`classic`의 application-first rollback은 환경·schema 호환을 확인한 뒤 사용한다. rollback에서 DB down/drop이나 사용자 원문/초안 삭제는 금지한다.

정식 tag CI·운영 health/live/ready·공개 작성/권한/복구·재시작·rollback smoke는 실제 승인된 SHA와 digest로 별도 수행한다. 현재 P5 CI/개발 공개 증거가 생기더라도 정식 tag/운영 결과로 소급하지 않는다. 물리 기기·OS IME·AT, 릴리스 proxy와 운영 backup/timer는 미실행 상태로 넘긴다.
