## 구현과 상태 연속성

곡 목록에 텍스트 선택과 분리된 drag handle, 맨 앞·앞·뒤·맨 뒤 버튼, `Home`/`End`/방향키 대안을 연결했다. 이동은 현재 보이는 같은 pin group 이웃을 anchor로 전송하며 성공 시 URL과 목록을 사용자정렬로 전환한다. 저장 중 중복 조작을 잠그고, 네트워크 실패는 원래 순서로 복원한 뒤 같은 request ID 재시도를 제공하며 stale 409는 서버 최신 순서를 다시 읽어 수렴한다.

필터된 목록 밖의 곡과 pin group을 전체 배열로 덮어쓰지 않는다. 연속 선두 이동 공개 smoke에서 DB 순서는 바뀌었지만 응답이 `changed: false`였던 결함을 재현했다. SQL의 `sort_rank::text` 출력 별칭을 `ORDER BY sort_rank`가 선택해 sparse numeric rank를 문자열로 정렬한 것이 원인이었으며, 실제 numeric column을 명시하고 같은 DB 회귀를 추가했다.
