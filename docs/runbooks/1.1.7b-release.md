# 1.1.7b 정식 릴리스 경로 — 아직 미승인

이 문서는 정식 배포를 승인하지 않는다. P5 개발 인수와 별개로 사용자 승인, `main` 통합, annotated `v1.1.7b` exact SHA, 정식 CI `publish=true`·`release=true`, 네 signed image exact digest/provenance 검증이 모두 필요하다. 과거 a의 release branch 예외나 dev 후보의 서명은 정식 발행 권한이 아니다. `Release-latest` 이동은 별도 승인 전 금지한다.

승인 후에도 [개발 배포 runbook](development-deploy.md)의 read-only preflight와 환경별 DB/볼륨/secret 분리를 먼저 확인한다. native 1150 이력과 기존 사용자 초안/outbox를 보존하고 `1152`를 순방향 적용한다. 운영 백업 상태와 `OPS-100-001` 예외를 명시하며 24시간 RPO를 약속하지 않는다. application-first rollback은 이전 a 또는 native 포함 PC image의 검증된 exact digest를 환경별로 구분해 사용하고 DB down/drop·원문 삭제를 금지한다. 실제 rollback 절차와 공개 smoke는 승인된 대상의 SHA·DB·PWA build를 다시 고정한 뒤 수행한다.

현재 완료된 것은 개발 후보 CI·서명 image·동일 SHA 개발 공개 인수까지이며 정식 tag CI·운영 smoke는 미실행이다. 물리 기기/OS IME/AT와 릴리스 proxy·운영 backup/timer도 미실행으로 인계한다.
