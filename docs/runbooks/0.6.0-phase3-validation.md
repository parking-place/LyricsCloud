# 0.6.0 Phase 3 가사 편집 자료 패널 검증

## 구현 결과

- 다른 곡·현재 곡의 다른 가사·라임·프롬프트를 하나의 owner 전용 결과 계약과 `/api/lyrics/:lyricId/resources` 조회 경계로 제공한다.
- 다른 가사는 제목·상태·본문 preview·수정 시각·현재 가사를 구분하고, 라임·프롬프트는 현재 곡 연결 자료와 전체 라이브러리를 전환하며 제목·본문 또는 토큰을 검색한다.
- 같은 화면 전환 전에 대상 생존 여부와 현재 CRDT 초안 저장을 확인한다. 새 창 열기는 현재 편집 상태를 유지하고, stale 삭제 항목은 즉시 `삭제됨`으로 잠근다.
- PC 패널은 접기·펼치기, 240~400px 너비, 마지막 탭·검색어를 컴포넌트 생명주기 동안 유지하며 focus mode에서도 상태를 보존한다.
- 모바일은 같은 컴포넌트를 bottom sheet로 사용하고 제목·닫기·handle, `dvh` 높이, sheet 내부 스크롤과 편집기 focus 복원을 제공한다.
- 탭별 loading, 연결 0건, 검색 결과 0건, 실패·재시도와 삭제 상태를 구분하고 화살표·Home·End roving tab 및 dialog/complementary 의미를 제공한다.
