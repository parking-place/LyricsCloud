## 발견 결함과 최소 수정

첫 5-browser 회귀에서 reader가 owner 전용 grant 목록 API를 호출하면 자신의 grant 한 건을 200으로 읽을 수 있었다. `ownsActiveLyric`이 RLS로 읽을 수 있는 자료를 소유 자료로 오인한 것이 원인이었다. owner 판정을 `owner_id=app_current_user_id()`로 고정하고, reader의 목록·회수 호출이 모두 비열거 404가 되는 실제 PostgreSQL 회귀를 추가했다. 테스트나 assertion을 삭제·완화하지 않았으며 같은 5-browser 검사를 다시 5/5 PASS했다.

- `AC-1.1.0-01`: reader A는 지정 가사의 제목·본문·상태와 최소 presence만 읽었다. 메모·연결 자료·revision·다른 가사는 노출되지 않았다.

- `AC-1.1.0-03`: reader를 offline으로 만든 동안 owner 변경은 전달되지 않았고, 권한 회수 뒤 online 재접속은 일반화된 종료 화면과 API 404로 끝났다.
