# 0.6.0 Phase 4 커서 삽입·전역 빠른 추가 검증

## 구현 결과

- panel을 열 때 현재 가사의 Yjs 상대 cursor·selection을 캡처하고 삽입 직전 최신 CRDT 문서에서 다시 해석한다.
- 라임 전체 또는 선택 표현을 request ID가 붙은 하나의 CodeMirror transaction으로 삽입해 한 번의 undo와 editor focus 복원을 보장한다.
- 서버가 source snapshot·target document key·상대 위치·owner를 검증하며 source 변경, target 변경·삭제·전환, 권한 실패와 IME 조합 중 요청에서는 삽입하지 않고 정확한 수동 복사 대안을 제공한다.
- 가사·송폼 구간·라임·프롬프트가 공통 clipboard 성공·실패 feedback과 읽기 전용 수동 복사 dialog를 사용한다.
- PC 상단과 모바일 중앙 FAB에서 곡·가사·라임·프롬프트 네 생성 흐름에 접근하고, 새 가사는 현재 곡 우선 또는 owner 활성 곡 검색·선택을 요구한다.
- `PROD-0005`에 독립 quick idea 유형을 만들지 않는 결정을 승인하고 라임·프롬프트 최소 입력을 계정별 IndexedDB와 안정적인 request ID로 저장·재시도한다.
