# 1.0.1 Phase 6 — 공개 UI 버튼·테마·겹침 인수 기록

## 원인과 수정 경계

곡 대시보드의 `＋ 새 가사`, `연결 관리`, 메모 저장과 연결 적용은 `primary-button` 클래스를 사용했지만 공통 stylesheet에는 링크용 `primary-link`만 정의되어 있었다. 브라우저 기본 button 배경과 글자색이 LyricsCloud의 light/dark 토큰을 우회해 두 테마 모두에서 회색 기본 버튼처럼 보였다. 이벤트·CSP·portal을 완화하지 않고 `primary-button`을 기존 primary action 토큰에 합쳤으며 light theme 전용 hover 토큰을 추가했다.

모바일의 가사 heading은 제목과 두 action을 한 줄에 강제하지 않고 action 행을 별도로 감싼다. `연결 관리`는 44px 이상 동작 영역을 유지하고 360px 이하에서는 panel 폭 전체를 사용한다. 접힌 PC rail의 문자 아이콘과 로그아웃 아이콘은 고정된 정사각형 상자, line-height, overflow와 shrink 규칙을 공유한다.
