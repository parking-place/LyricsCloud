# 1.1.7 P3 플랫폼 상호작용 인수

## 범위와 제품 매핑

- 곡 목록의 필터·정렬 URL을 대시보드와 가사 편집기까지 전달하고, 편집기→대시보드→목록 복귀 때 정확히 같은 URL을 복원한다.
- 공유 dialog는 열었던 `공유` 버튼으로 Escape/닫기 뒤 focus를 돌려보내며 기존 focus trap을 유지한다.
- Suno 작업 링크는 새 탭으로 열고 `noopener noreferrer`를 유지한다.
- desktop 접힌 rail은 각 아이콘에 접근성 이름과 40px 이상 target을 유지하고 hover와 keyboard focus 모두에 보이는 tooltip을 제공한다.
- mobile은 기존 bottom navigation과 `더보기` sheet를 사용하며 Escape 뒤 `더보기` trigger로 focus를 복원한다.
- 곡·라임·프롬프트 순서 이동의 drag handle에는 방향키와 맨 앞/앞/뒤/맨 뒤 버튼이 있고, prompt token에는 방향키와 보이는 앞/뒤 버튼, 가사 context menu에는 mobile의 `＋ 송폼 삽입` 버튼이 이미 있어 같은 기능의 비-pointer 대안을 유지한다.

API·DB schema·권한·본문 저장·copy/export 형식은 변경하지 않는다.

## 확정 목업과 다른 점

`new_Mock-up`은 플랫폼 badge와 Windows/Linux/macOS 창 장식을 검토용 정적 prototype으로 표시한다. 제품은 browser workspace이므로 이를 native shell처럼 추가하지 않고 기존 URL·focus·responsive navigation을 실제 동작 기준으로 유지한다. desktop rail 축소 tooltip은 목업 계약에 있었지만 제품에는 native `title`만 남아 focus 시 시각 라벨이 없었으므로 이번 Phase에서 semantic token 기반 tooltip으로 보완했다.

iOS safe-area·keyboard inset, Android system/predictive back, desktop OS별 native focus·IME·창 lifecycle은 실제 SDK/기기에서 확인하지 않았다. Chromium mobile은 Android browser 대리, WebKit mobile은 iOS browser 대리일 뿐 native PASS가 아니다.

## 로컬 후보 검증

기준 source는 P3 시작 `1e6f9fb3431c3aefce9378880280b8cad4116f74`, runtime은 `1.1.7/dev/p3`다.

| 검증 | 환경 | 결과 |
|---|---|---|
| 실패 우선 계약 | Node 24.20.0, Vitest | rail 접근성 이름·focus tooltip 구현 전 1 FAIL/기존 대안 4 PASS |
| 계약·단위 | Node 24.20.0, Vitest | 264 PASS, DB 환경 필요 115 skip |
| 정적 검사 | Node 24.20.0 | architecture boundary, 전체 workspace typecheck PASS |
| production build | Node 24.20.0, Next.js 16.3.4 | PASS |
| 1.1.7 P2+P3 흐름 | 격리 PostgreSQL, Chromium desktop/mobile | 4 PASS |
| P3 교차 browser | 같은 DB, Chromium/Firefox/WebKit desktop + Chromium/WebKit mobile | 최종 5 PASS |

Firefox는 `getComputedStyle(..., "::after").content`를 렌더된 문자열 대신 `attr(title)`로 반환한다. 제품 결함이 아니므로 실제 `title="곡"`, 접근성 이름, `visibility: visible`, `opacity: 1`을 분리 검증했다. mobile client navigation의 간헐적 완료 시점은 목적 URL까지 poll하도록 보정했으며 제품 대기 시간이나 저장 계약은 변경하지 않았다.

## 원격·공개 인수 gate

- 후보 SHA의 push/PR 필수 CI와 네 signed dev image가 모두 PASS해야 한다.
- 네 image의 SHA·`dev-1.1.7-p3`·`Dev`·`Dev-latest` tag가 서비스별 같은 digest인지 확인한다.
- 정확히 같은 후보 SHA를 개발 서버에 배포하고 공개 desktop/mobile에서 목록 URL 복귀, 공유 focus, Suno 새 탭, rail/mobile navigation, build metadata와 overflow를 다시 확인한다.
- 실제 Android/iOS 앱·물리 기기·OS IME/AT/zoom은 미실행으로 유지한다.

## 중단·되돌림

- 원래 목록 query, 가사 원문, 공유 권한 또는 미전송 상태가 바뀌면 배포를 중단한다.
- 개발 서버 rollback은 직전 exact P2 image/SHA로 되돌리며 migration 추가가 없어 schema 역변경은 하지 않는다.
- 릴리스 서버는 P3에서 변경하지 않는다.
