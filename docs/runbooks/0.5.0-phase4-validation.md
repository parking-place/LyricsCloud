명확한 handle의 mouse drag와 touch pointer drag, 방향키와 앞으로·뒤로 버튼이 같은 occurrence sequence를 만들고 첫·끝 이동이 비활성화됨을 확인했다. 이동 뒤 같은 occurrence에 focus가 복원되고 새 1-based 위치가 live region에 안내된다. 두 브라우저가 같은 토큰을 동시에 이동·삭제해도 화면·Yjs projection·PostgreSQL 평문이 수렴하며 occurrence가 복제되지 않는다.
