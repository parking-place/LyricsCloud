# 1.0.14 Phase 2 — 폰트 자산·로딩 후보

## 구현

- 공식 Noto Sans KR 2.004 Regular OTF와 OFL 1.1 원문을 SHA-256 앞 8자가 포함된 `/fonts/` 경로에 번들했다.
- `@font-face`는 `font-display: swap`과 기존 system sans fallback을 사용한다. 선택 UI가 아직 font family를 소비하지 않으므로 P2에서는 자산 요청이 자동 발생하지 않는다.
- font 경로는 1년 immutable 응답이며 서비스워커는 같은 origin의 hash OTF/WOFF2만 shell cache에 저장한다. API·HTML·사용자 창작물은 cache 대상이 아니다.
- runtime/package/build metadata를 1.0.14로 올렸고 production runtime은 다른 APP_VERSION을 거부한다.

## 로컬 후보 검증

- Node 24.20.0, pnpm 11.25.0
- font asset/OFL 해시 2건 PASS
- architecture boundary·전체 TypeScript·production web build PASS
- 실제 PostgreSQL 18 + Chromium PWA 2건 PASS: immutable font 응답, shell cache 저장, offline fetch, private cache 비노출, logout 정리

전체 CI와 동일 SHA 개발 HTTPS 인수 전에는 P2 완료로 보지 않는다. P3는 기존 display settings 계약에 신규 값·migration·설정/편집 UI를 연결한다.
