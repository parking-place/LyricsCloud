# 0.4.0 Phase 3 검증

## 구현 결과

- `/rhymes/new`는 제목·자유 본문을 계정별 IndexedDB에 즉시 보존하고, 유효한 제목이 생기면 900ms debounce와 최대 5초 경계로 멱등 생성한다. 오프라인 종료·재접속, 실패 재시도와 명시적 초안 폐기를 구분한다.
- `/rhymes/:id`는 관계형 제목·표시 메타데이터와 Yjs CRDT 본문을 독립된 직렬 저장 경로로 처리한다. 다른 탭의 본문 projection이나 태그 변경으로 row version이 전진해도 같은 메타데이터 필드를 덮어쓰지 않고 안전하게 rebase한다.
- 태그 정규화·추가·삭제, 핀·즐겨찾기·색상과 로컬 저장·서버 동기화·projection·실패 상태를 PC와 모바일에서 이름으로 표시한다.
- 수정 기록 목록·본문 비교·복원 직전 checkpoint·비파괴 복원과 전체 본문 복사, Clipboard 실패 수동 복사 대안을 제공한다.
- 삭제는 현재 제목을 포함한 modal/sheet에서 다시 확인하며 soft delete 후 목록으로 돌아간다. 모바일 하단 행동은 문서 흐름에 sticky로 배치해 작은 viewport와 시스템 텍스트 선택을 가리지 않는다.

## Phase 4 인계

- Phase 3의 태그 UI는 자유 입력·추가·삭제의 기본 경로다. Phase 4는 목록 필터 왕복과 태그 후보 상태를 완성하고 곡 검색·N:M 연결·해제를 추가한다.
- 전체 복사는 현재 CRDT 본문의 정확한 문자열과 수동 대안을 제공한다. Phase 4는 CodeMirror selection을 같은 규칙으로 복사하고 빈·오래된 selection 상태를 분리한다.
- 실제 가사 cursor 삽입은 0.6.0 범위다. Phase 4에서는 owner가 같은 열린 target, CRDT 상대 위치와 순수 텍스트 payload 계약만 제공한다.
