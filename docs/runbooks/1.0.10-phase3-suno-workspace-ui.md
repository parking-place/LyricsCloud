# 1.0.10 Phase 3 Suno 수동 작업공간 UI 검증

## 구현 범위

- 곡 대시보드의 첫 번째 보조 패널에서 모델 미지정, P1의 참고 제안, 최대 64 code point 사용자 지정 값을 저장한다.
- 곡당 최대 20개의 Suno 링크를 URL·수동 제목·메모와 함께 추가·수정·위/아래 이동·제거한다.
- 링크는 새 탭으로 열되 `noopener noreferrer`를 적용한다. 제거 확인과 성공 안내는 LyricsCloud의 URL·제목·메모만 제거하고 Suno 원곡은 삭제하지 않음을 명시한다.
- 자동 썸네일·생성 시간 조회는 하지 않는다고 화면에 알린다. 서버 validation·CAS 충돌·네트워크 실패를 구분하고 편집 dialog와 sessionStorage 브라우저 탭 초안을 유지한다.

## 경계와 인계

URL로 outbound 요청하거나 Suno 자료를 삭제하지 않는다. 기존 곡·가사·연결 자료의 본문과 저장 흐름은 변경하지 않는다. 실제 Windows/iOS/Android 물리 입력은 이번 자동 브라우저 증거로 대체하지 않았다. P4는 실제 PostgreSQL 전체 회귀, soft-delete/restore, 다른 owner, offline/reconnect·응답 역전, 서비스 재시작과 Chromium/Firefox/WebKit 교차 검증을 수행한다.
