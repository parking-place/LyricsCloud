- `LC-080-P3-01`~`LC-080-P3-08`

- 전역 명령은 새 가사·통합 검색·도움말이고, 편집기 명령은 전체 복사·집중 모드·자료 패널·이전/다음 가사다.

## 확인한 동작과 실패 경계

- 설정 화면의 명령 레지스트리와 전역 dialog가 같은 8개 정의를 사용하며 명령·키 검색, 0건 안내와 PC table·모바일 card를 제공한다.
- dialog는 키보드로 열고 Escape로 닫을 수 있고 Tab 순환 뒤 opener로 초점을 복원한다.
- 텍스트 입력과 IME 조합 중 명령을 억제하고 `Ctrl+S`, `Ctrl+F`, Tab을 그대로 유지한다.
- 집중 모드와 자료 패널 전환 뒤 현재 편집기의 selection·scroll·focus를 복원한다.
- 이전·다음 가사 이동과 전역 이동은 전송 대기 초안을 먼저 flush하며 실제 키보드의 `{`·`}`도 bracket 명령으로 인식한다.
- Clipboard API가 없거나 실패하면 현재 원문을 선택 가능한 dialog로 제공한다.
