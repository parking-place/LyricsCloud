# 1.1.0 Phase 3 — 지정 사용자 읽기 공유 UI

## 구현

- 가사 편집기의 desktop header와 mobile action dock에 공유 진입을 추가했다. owner는 비공개/선택 공유 상태, 실제 노출 필드 미리보기, 본인 공유 코드, 만료 기간, grant·회수·링크와 현재 reader를 한 대화상자에서 관리한다.
- 로그인한 reader 전용 `/shared/lyrics/[lyricId]` 화면은 제목·본문·상태만 읽기 전용으로 표시하고 live update와 최소 presence를 수신한다. 수정·삭제·ACL·소유권 이전 액션과 IndexedDB/outbox는 제공하지 않는다.
- 미로그인 사용자는 검증된 return path를 보존해 인증 화면으로 이동한다. 권한 없음·회수·만료·삭제는 자료 존재나 제목을 노출하지 않는 공통 화면을 사용하며, 회수 시 열린 본문과 참가자 상태를 즉시 비운다.
- 참가자 표시가 이메일 또는 내부 UUID처럼 보이면 `참여자`/`공유자`로 치환한다. public link·write·guest 기능은 추가하지 않았다.
