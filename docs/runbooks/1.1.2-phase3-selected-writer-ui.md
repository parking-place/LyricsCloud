# 1.1.2 Phase 3 — 지정 공동 작성자 사용자 흐름

## 구현

- 소유자는 기존 지정 독자 grant를 공동 작성 또는 읽기 전용으로 전환할 수 있다. 실제 reader 집합 안의 계정만 writer가 되며 작성자는 ACL·삭제·탈퇴 같은 관리 권한을 얻지 않는다.
- 공동 작성자는 공유 화면의 CodeMirror에서 본문만 편집한다. 연결·로컬 저장·서버 동기화·오프라인·회수 상태를 문장으로 확인하고 한글 조합 중간값과 local undo를 확정 변경으로 잘못 처리하지 않는다.
- 작성자 update는 actor·grant·permission/write epoch와 durable update ID에 결합된다. ACK 유실은 같은 ID로 복구하고 강등·회수 경계에서 거부된 본인 입력은 서버 원문에 섞지 않은 로컬 복구함에서 복사하거나 텍스트 파일로 저장한다.
- 현재 참여자, 역할, 작업/자리 비움, 선택 구간을 서버가 인증한 presence로 표시한다. 중복 탭은 별도 참여자로 다루며 아직 서버 snapshot에 없는 로컬 커서 위치는 본문 ACK 전까지 보류한 뒤 다시 전송한다.
