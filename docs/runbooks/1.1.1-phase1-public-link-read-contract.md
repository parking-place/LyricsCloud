## 확정한 capability와 자료 경계

1. 공개 링크는 가입·로그인·개인 workspace 권한을 만들지 않는다. capability가 가리키는 가사 한 개의 승인된 읽기 projection만 허용한다.
2. raw token은 CSPRNG 32바이트(256비트)를 unpadded base64url 43자로 표현한다. DB에는 domain-separated SHA-256 digest만 저장하고 생성 응답에서 한 번만 반환한다.
3. 공유 URL은 `/shared/public#<raw-token>`이다. fragment는 HTTP 요청·서버/access log·Referer에 전달되지 않는다. 클라이언트는 값을 tab `sessionStorage`에 옮긴 뒤 주소에서 제거하고, 고정 경로 POST body와 WebSocket 최초 인증 frame에서만 보낸다. request body·frame·오류에는 redaction을 적용한다.
4. 한 가사에는 활성 공개 읽기 링크 하나만 둔다. 재발급은 새 256비트 token과 epoch를 원자 생성하고 이전 링크를 즉시 폐기한다. owner 목록/API는 raw token을 다시 보여 주지 않으며 잃어버린 token은 재발급한다.
5. 만료는 필수이며 1일·7일(기본)·30일 preset만 제공한다. 최장 30일을 넘기지 않는다. 회수·만료·재발급·자료 삭제는 이후 HTTP/WS 읽기와 신규 update 수신을 막고 기존 socket을 닫는다.
6. 이미 화면에서 읽거나 사용자가 복사한 내용의 원격 삭제는 약속하지 않는다. 일반 텍스트 선택·복사는 허용하지만 서버 search·export·duplicate·revision·workspace API는 제공하지 않는다.

## 공개 필드·화면·캐시

- 필수 공개 필드는 가사 제목과 본문이다. owner는 공개 확인 단계에서 공유용 owner 표시 이름·상태·수정 시각을 각각 명시 선택하며 기본값은 모두 숨김이다.
- 작업 메모, 곡/다른 가사, 라임, 프롬프트, Suno 링크, revision, 개인 설정, 이메일·내부 사용자 ID·선택 공유 참가자 presence는 어떤 선택에도 공개되지 않는다.
- 익명 화면은 로그인 CTA를 보여 줄 수 있지만 로그인·beta code 없이 private workspace·계정 API로 이어지는 권한은 부여하지 않는다.
- `/shared/public`의 서버 HTML과 OG는 일반 제목·설명만 제공한다. `robots=noindex,nofollow,noarchive`, `Referrer-Policy: no-referrer`, 엄격한 CSP를 적용하고 실제 가사·owner·token을 metadata에 넣지 않는다.
- HTML/API 응답은 `Cache-Control: private, no-store, max-age=0`, `Pragma: no-cache`를 사용하고 CDN·Next/PWA/service worker cache 대상에서 제외한다. 오류 페이지도 같은 정책을 쓴다.

## 저장·API·실시간 인터페이스

### 저장

- `lyric_public_read_links`: `id`, `resource_id`, `owner_id`, `token_digest`, 공개 필드 flags, `state`, `permission_epoch`, `expires_at`, `created_at`, `revoked_at`, `rotated_at`을 보관한다.
- `(resource_id)`의 활성 링크는 하나, `token_digest`는 전체 unique다. owner만 생성·조회·회수하고 public lookup은 유효 digest·active·expiry·resource 상태를 한 번에 검사하는 최소 projection 함수로 제한한다.
- raw token, IP, user-agent, Referer는 테이블에 저장하지 않는다. rate/concurrency 판단용 값은 최소 시간 창 aggregate만 사용하고 창 종료 후 폐기한다.

### HTTP

- owner 관리: `GET/POST /api/lyrics/:lyricId/public-link`, `DELETE /api/lyrics/:lyricId/public-link/:linkId`. POST는 `requestId`, expiry preset, 공개 field flags를 받고 최초 생성/재발급 때 URL을 한 번만 반환한다.
- public read: `POST /api/public/shared-lyric`의 4KiB 이하 JSON body `{ token }`. 성공 응답은 공개 projection과 비밀이 아닌 `linkId`, `permissionEpoch`만 반환한다.
- invalid·unknown·revoked·expired·deleted·field/resource 변조는 모두 같은 404 unavailable shape와 유사한 처리 경로를 사용한다. body/형식 초과는 일반 400, rate limit은 일반 429다.
- 공개 read는 IP당 분당 30회, link digest당 분당 120회로 제한한다. owner 생성/재발급은 owner+resource당 시간당 10회로 제한한다. raw token은 rate key·log label로 쓰지 않고 digest만 메모리 키로 쓴다.

### WebSocket

- 고정 `/collaboration/public` 연결 뒤 첫 frame에서 raw token과 공개 `linkId`를 받고 서버가 digest·resource·epoch를 바인딩한다. token을 URL/query/subprotocol에 넣지 않는다.
- public reader는 허용 projection의 snapshot/update만 수신한다. client update·revision·presence identity·cursor·search/export는 거부한다.
- link당 동시 socket 20개, IP당 handshake 분당 10회로 제한한다. subscribe·재연결·각 broadcast 전에 active/expiry/epoch를 다시 검사하고 실패 시 일반 unavailable로 닫으며 이후 update를 보내지 않는다.

## 호환·되돌림·파일 담당

- 1.1.0 `lyric_read_grants`, owner API, selected reader 화면, CRDT document key와 원문 형식은 변경하지 않는다. public link는 별도 table·route·access mode로 추가한다.
- 기능 flag를 끄면 신규 발급과 public HTTP/WS를 모두 거부하되 링크 행·원문은 보존한다. 애플리케이션을 1.1.0으로 먼저 rollback할 수 있다.
- schema 역삭제는 활성 링크가 없고 별도 승인된 격리 restore가 있을 때만 수행한다. 가사·grant·revision·sync update를 파괴하는 rollback은 금지한다.

## 미실행과 P2 인계

P1은 설계-only라 runtime, migration, CI, 서버 배포를 실행하지 않았다. P2는 `1110_public_lyric_read_links.sql`과 rollback, capability helper, owner/public API, collaboration public access의 실패 시험부터 시작한다. P3는 공개 확인·one-time copy·anonymous PC/mobile 상태를 연결하고, P4는 실제 PostgreSQL·지원 브라우저·서비스 재시작·회수 중 열린 socket·cache/log artifact를 검증한다. 실제 OS/물리 기기와 `OPS-100-001` 예외는 미실행 위험으로 유지한다.
