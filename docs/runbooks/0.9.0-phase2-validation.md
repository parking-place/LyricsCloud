## 원격 인수

기능 SHA의 원격 branch·CI·네 image digest·동일 SHA 개발 배포·공개 smoke 결과는 실제 성공 뒤 기록한다. 릴리스 서버·`main`·`Release`·`latest`는 별도의 현재 사용자 지시가 없으면 변경하지 않는다.
