## 실패 우선과 수정 범위

세 목록 카드가 매번 전체 배열을 `filter`하고 `findIndex`하던 O(n²) 경로를 재현했다. 구현 전 계약 검사는 공통 module 부재로 실패했다. `buildPinnedGroupPositions`는 입력을 두 번만 순회해 각 ID의 pin 그룹 내 1-based 위치와 그룹 크기를 만든다. 중복 ID는 잘못된 UI 입력으로 거부하며, 곡·라임·프롬프트 목록은 같은 memoized map을 소비한다. API 응답, DB rank, owner/RLS, pin 그룹과 표시 문구의 의미는 바꾸지 않았다.
