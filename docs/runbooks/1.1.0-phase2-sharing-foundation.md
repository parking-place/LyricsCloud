# 1.1.0 Phase 2 — 지정 사용자 읽기 공유 서버 기반

## 구현

- `1100_selected_lyric_sharing.sql`에 비열거 공유 식별자, 가사별 reader grant와 요청 기록, owner/reader를 분리한 강제 RLS를 추가했다. owner 쓰기 경로는 그대로 유지하고 reader는 승인된 가사의 최소 필드만 읽는다.
- owner의 grant 목록·생성·회수, 본인 공유 식별자, reader 조회 API를 추가했다. 존재하지 않거나 권한 없는 대상은 동일한 비노출 응답을 사용하며 이메일과 내부 계정 ID를 공개하지 않는다.
- collaboration HTTP/WebSocket 읽기 경로에 검증 actor와 grant를 결합했다. reader는 snapshot/update/presence만 수신하고 쓰기는 거부되며, 회수·만료 뒤 최대 1초 이내 기존 연결을 닫는다.
- 공유 범위에는 제목·본문·최소 owner 표시만 포함한다. 연결 라임·프롬프트·메모·revision·다른 가사와 검색/내보내기 경로는 열지 않았다.
