# 1.0.3 Phase 2 프롬프트 모드 저장 인수

## 구현 결과

- `1000_prompt_modes.sql`은 기존 migration을 바꾸지 않고 prompt와 prompt template에 `tags | sentence` mode와 문장 raw 열을 추가한다.
- 기존 `plain_text`와 token occurrence는 태그 표현으로 유지한다. API의 `plainText`는 현재 mode의 복사 본문이고 `tagText`·`sentenceText`는 두 표현을 분리해 전달한다.
- 문장 raw는 trim, Unicode 정규화, 쉼표 분해, 중복 제거, 줄바꿈 변환을 하지 않는다.
- prompt CRDT는 `prompt-title`, `prompt-mode`, `prompt-tokens`, `prompt-sentence`를 사용한다. mode와 새 active 본문은 하나의 Yjs transaction으로 바뀌며 다른 mode의 지연 변경은 active projection에 섞이지 않는다.
- 문장형 collaboration 연결은 `prompt-mode-v1` capability가 필요하다. 구버전 tag payload의 읽기·복사와 신규 tag 생성은 그대로 지원한다.
- 복제, template 생성·복제·적용, revision v2·v1 복원, 목록·통합 검색, raw·읽기 쉬운 export가 mode와 원문을 보존한다.

## rollback과 남은 범위

- 앱 rollback은 additive 열을 둔 채 1.0.2 이미지를 먼저 복구한다. 문장형 편집은 capability가 없어 차단된다.
- schema rollback은 문장형 prompt와 문장 template가 한 건이라도 있으면 중단한다. 빈 경우에만 검색 생성 열과 기존 trigger·constraint를 복원한다.
- 사용자 mode selector, raw textarea, 명시 변환 preview/confirm/undo와 PC/mobile 화면은 P3 책임이다.
- `OPS-100-001` 외부 backup 미구축 예외는 이 Phase에서 닫지 않는다.
