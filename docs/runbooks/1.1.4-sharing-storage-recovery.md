# 1.1.4 공유 저장·복구 안내

- 적용 후보: `375ea78f6925f5032dd90b848286c3f0b351168e`
- 범위: 선택 공동 작성자, 읽기 전용 사용자, 공개 게스트, 소유자 공유 관리
- 기준 계약: [Phase 1 공유 안정성 계약](1.1.4-phase1-sharing-stability-contract.md)

## 화면에서 보이는 저장 상태

| 화면 상태 | 의미 | 사용자 조치 |
|---|---|---|
| `모든 변경 저장됨` | 현재 입력의 서버 ACK를 받았다. | 그대로 이동하거나 탭을 닫을 수 있다. |
| `이 기기에 입력을 저장하는 중` | 브라우저의 로컬 snapshot과 outbox를 기록 중이다. | 완료 또는 명시적 오류가 나올 때까지 기다린다. |
| `서버에 변경을 저장하는 중` | 로컬 기록은 끝났고 서버 ACK를 기다린다. | 연결을 유지한다. ACK가 끊기면 같은 update를 재전송한다. |
| `오프라인` | 로그인 작성자는 해당 계정·기기에, 공개 게스트는 현재 탭의 guest session에 입력을 보관한다. | 같은 계정/탭으로 다시 연결한다. |
| `쓰기 제한` 또는 `실시간 연결을 확인하지 못함` | 새 입력이 서버에 반영됐다고 보장하지 않는다. | 다시 연결을 시도하고 복구함이 나타나면 자기 작성문을 먼저 복사한다. |
| 공유 종료 | 새 입력·재전송은 허용하지 않는다. | 표시된 자기 미전송 작성문만 복사·파일 저장한 뒤 제거한다. |

읽기 전용 화면은 서버에서 마지막으로 받은 내용만 표시한다. 수정 대기 outbox나 복구 항목을 새로 만들지 않는다.

## actor별 보관 경계

- 로그인 공동 작성자의 로컬 자료는 사용자 ID hash prefix 아래에 저장한다. 다음 계정 로그인 시 이전 계정의 local/session key와 owner-hash IndexedDB를 제거한다.
- 공개 게스트의 로컬 자료는 서버가 발급한 guest session과 탭의 recovery ID로 분리한다. 계정 작업 공간이나 다른 공개 탭과 합치지 않는다.
- 권한 회수·만료·삭제 뒤 복구함에는 해당 actor가 작성했지만 ACK 받지 못한 텍스트만 남긴다. 공유 원문 snapshot, 다른 참여자의 입력, 메모, 연결 자료, ACL, revision은 복구함으로 내보내지 않는다.
- 가사 또는 상위 곡을 삭제하면 기존 선택/공개 capability와 두 epoch가 끝난다. 휴지통 복원은 본문을 복구하지만 과거 공유 권한을 되살리지 않는다.

## 소유자 운영 절차

1. 공유 관리에서 현재 선택 사용자와 공개 링크를 확인한다.
2. 강한 편집 절단이 필요하면 먼저 공동 작성 권한을 읽기 전용으로 내리거나 권한/링크를 회수한 뒤 revision을 복원한다.
3. 가사나 곡 삭제 전에 열린 작성자에게 `모든 변경 저장됨` 확인을 요청한다. 삭제 자체는 기존 capability를 즉시 끝낸다.
4. 사고 대응 시 자료를 복원해도 과거 grant/link를 재활성화하지 않는다. 필요한 대상에게 새 capability를 발급한다.

## 오류 대응

1. 작성자가 보고한 화면 상태, 계정/게스트 구분, 자료 ID, 발생 시각을 확인한다. 공유 비밀 URL과 세션 token은 수집하지 않는다.
2. `오프라인`이면 네트워크 복귀 뒤 같은 actor 문맥에서 재접속한다. `모든 변경 저장됨` 전에는 다른 계정으로 전환하지 않는다.
3. 공유가 이미 끝났다면 복구함의 자기 작성문을 먼저 복사하거나 텍스트 파일로 저장한다. 자동 replay는 하지 않는다.
4. 소유자 화면의 서버 본문·revision과 작성자가 보관한 자기 원문을 비교한다. 서버 ACK 없이 화면에만 있던 문장을 저장 완료로 간주하지 않는다.
5. 계정 전환 뒤 이전 actor의 문장이나 자료가 보이면 P0 개인정보 격리 사고로 취급해 새 작업을 중지하고 해당 브라우저의 사이트 데이터를 격리한다.

## 증거 제한

자동 Playwright의 모바일 viewport·composition/undo와 빠른 재접속은 S1/S2 증거다. 실제 Android/iOS 가상 키보드, Windows/macOS 한국어 IME, 절전·복귀, 장시간 wall-clock soak를 대신하지 않는다. 실행하지 않은 조합은 P4/P5에서 미실행으로 그대로 기록한다.
