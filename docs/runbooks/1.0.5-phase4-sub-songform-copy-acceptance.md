# 1.0.5 Phase 4 서브 송폼·가사 복사 교차 인수

## 수용 결과

- `[Verse: whisper]`와 `[Verse: a:b]`는 첫 콜론 앞의 `Verse`만 탐색 이름으로 사용하며 콜론 이후 suffix와 원문 전체를 표시·저장·복사한다.
- 최종 LF payload 2999·3000자는 안내하지 않고 3001자만 안내하며 자동·단축키·수동 복사를 막지 않는다.
- 독립 브라우저의 한글 suffix 조합 중 원격 입력은 보류되고 조합 종료 뒤 자모·cursor·undo·탐색 이름을 손상하지 않고 합류한다.
- 다른 계정, offline/재접속, 저장 후 재진입, 기존 prompt 기능과 공개 개발 collaboration 재시작 뒤에도 원문과 document key를 유지한다.

## 자동·실제 환경 증거

- 구현·검증 후보: `d0ad04d9e74e393809318b05134fe4ef0b54ad33`
- Node 24.20.0, pnpm 11.25.0, 격리 PostgreSQL 18: migration 반복 적용과 unit/integration 270 PASS, 환경상 별도 beta signup 4 skip.
- Chromium desktop/mobile 전체: 316건 중 284 PASS, 기존 조건부 32 skip.
- 신규 기능 5-project 행렬: Chromium desktop/mobile, Firefox desktop, WebKit desktop/mobile 11 PASS, 합성 composition 자동화가 의미 있는 Chromium desktop 외 4 skip.
- `pnpm check`, production `pnpm build` PASS.
- 동일 SHA 개발 서버: version `1.0.5`, channel `dev`, phase `p4`, schema `1000_prompt_modes.sql`, postgres/web/collaboration/worker healthy.
- 공개 HTTPS: suffix 2종, 주 이름 탐색, 3001자 exact copy·비차단 안내 PASS. collaboration container 재시작 전후 같은 document key와 3001자 DB 원문을 확인하고 합성 자료를 제거했다.

첫 전체 Chromium 실행은 이전 1.0.4 metadata 기대값 4건, mobile copy 버튼의 보이는 문자 수가 접근 이름에 합쳐진 2건, 같은 context가 IndexedDB까지 공유한 조합 시험 1건을 드러냈다. 현재 1.0.5 P4 기대값, 고정 접근 이름, 독립 context로 최소 수정하고 영향 시험 13건과 전체 316건을 다시 실행했다. 첫 Firefox 합성 composition은 자동 `fill`이 실제 엔진의 조합 상태를 종료해 제품 결함과 구분했고, 조합 수용은 Chromium desktop 자동화로 제한했다. Firefox/WebKit의 표시·복사 시험은 그대로 통과했다.

실제 Windows/iOS/Android 물리 입력은 이번 Phase에서 새로 수행하지 않았으며 자동 브라우저 결과로 대체했다고 표시하지 않는다.
