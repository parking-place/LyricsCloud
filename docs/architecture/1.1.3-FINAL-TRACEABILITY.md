# 1.1.3 공개 링크 비로그인 공동 편집 최종 추적

이 문서는 1.1.3 P1~P5의 `NF-REQ-035`, `NF-REQ-036` 부분 범위와 `AC-1.1.3-01`~`04`를 source·migration·검증 증거에 연결한다.

## 변경·데이터 경계

- owner가 별도 위험을 확인한 active public-read link만 같은 가사 본문을 비로그인 guest에게 쓰기 허용할 수 있다. public write는 기본 off이며 선택 독자 공유와 동시에 켤 수 없다.
- guest는 서버 발급 무작위 session과 표시 이름으로 구분되고 본문 CRDT update만 보낸다. workspace·목록·제목·상태·메모·연결 자료·revision·ACL·삭제·소유권·계정 권한은 얻지 않는다.
- 각 update는 link token digest·resource·guest session digest·permission/write epoch·durable update ID를 서버에서 확인한다. guest별·link별 지속 budget과 socket 상한을 적용하고 owner 중지·link 회수 시 열린 연결과 새 update를 차단한다.
- ACK 전 원문은 tab 격리 저장소에 두고 거부되면 서버 확인본으로 복귀한다. 자기 입력만 복사·다운로드 가능한 rejected 복구함에 남기며 재허용·재연결 뒤 자동 replay하지 않는다.
- 최신 schema는 `1130_public_lyric_guest_write.sql`이며 28개 migration 이름·checksum을 `config/migrations.1.1.3.json`에 봉인한다.

| `AC-1.1.3-02` | guest token/session의 다른 자료 재사용과 private API·메모·연결 자료·revision·export 접근 | PASS |
