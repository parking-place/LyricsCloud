## 안전성·후속 계약

- 서버가 owner/parent를 세션에서 결정하고 RLS·CAS·request idempotency를 적용한다. 같은 요청 재전송은 한 번만 반영하고 오래된 버전은 부분 쓰기 없이 거부한다.
- 외부 URL은 공식 Suno HTTPS song/short-share 형태만 저장하며 userinfo·비표준 port·다른 host/path를 거부한다. 자동 metadata 조회·scraping·외부 삭제 요청은 없다.
- 제거 안내는 LyricsCloud의 수동 URL·제목·메모만 제거하며 Suno 원곡을 삭제하지 않는다고 명시한다. 새 탭은 `noopener noreferrer`를 사용한다.
- 브라우저 탭 초안은 네트워크 실패 뒤 유지되지만 서버 저장 완료로 오인시키지 않는다. export는 owner의 활성/삭제 workspace를 기존 resource lifecycle 계약대로 포함한다.
- P4까지 신규 P0/P1, 원문 유실, 인증 우회, 교차 owner 노출, 무음 저장 실패는 0건이다.
- 실제 Windows/iOS/Android 물리 입력은 새로 실행하지 않았고 `OPS-100-001` 외부 backup 예외는 유지한다.
- 1.0.11의 자동 metadata는 공식·허가된 제공 경로가 확인될 때만 별도 계약으로 추가하며 1.0.10의 수동 값을 덮어쓰지 않는다.
