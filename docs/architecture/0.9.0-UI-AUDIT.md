# 0.9.0 UI 완성도 감사 기준선

이 문서는 0.9.0 Phase 1의 감사 기준선과 Phase 5의 최종 판정을 함께 유지하는 단일 UI 감사 원본이다. 보호된 목업은 수정하지 않고, 15개 README와 현재 route/component, 합성 데이터 캡처를 대조했다. `구현`은 기능 존재 여부이고 `차이`는 목업과의 간극이므로 둘을 섞지 않는다.

## Phase 5 최종 자동 판정

- Phase 2~4에서 `GAP-01`~`GAP-08`을 닫았고, `GAP-09`는 같은 기능 위계 안의 허용 가능한 밀도·배치 차이로 승인했다.
- `docs/runbooks/evidence/0.9.0-phase5/<viewport>/<screen>.png`에 15개 화면×4 viewport의 최종 60장을 새로 생성했다.
- 네 viewport 접촉 시트를 직접 검토한 결과 필수 조작의 잘림·소실, 가로 overflow, 중첩 modal, 제목·본문 위계 붕괴에 해당하는 P0/P1은 0개였다.
- 실제 iOS Safari·Android Chrome 판정은 [0.9.0 출시 후보 인수표](../runbooks/0.9.0-release-candidate.md)에 분리해 자동 에뮬레이션과 혼동하지 않는다.

## 공통 셸·편집 패널 계약

- PC(961px 이상): 13.5rem 좌측 rail, 상단 창작 tab, 가사 편집의 송폼/본문/자료 패널을 사용한다.
- 좁은 PC(721~960px): 좌측 rail을 11.5rem으로 줄인다. 현재 상단 tab이 압축되며 1024px에서도 글자가 세로로 꺾이는 문제가 있어 item 축약 또는 overflow affordance가 필요하다 (`GAP-01`).
- 태블릿(721~960px): 현재 desktop shell을 유지하면서 가사 우측 패널과 라임 side만 숨긴다. 모바일 sheet/dock은 720px 이하에서만 생기므로 필수 기능이 사라지는 중간 구간을 제거해야 한다 (`GAP-03`).
- 모바일(720px 이하): header, 7칸 하단 nav와 중앙 빠른 추가, 편집기 dock/sheet를 사용한다. 템플릿·휴지통은 해당 route 안에서만 프롬프트 자리를 대체하므로 일반 화면에서 접근 가능한 `더보기`가 필요하다 (`GAP-02`).
- panel/dialog는 제목, 닫기, focus trap, Escape, 닫힌 뒤 trigger focus를 공통 계약으로 삼는다. 현재 구현별 편차는 Phase 4에서 닫는다.

## 토큰 감사

`packages/ui/src/tokens.css`의 safe-area 4개와 `styles.css`의 light/dark 의미 색상 13개가 기준이다. 현재 앱은 의미 색상을 광범위하게 재사용하지만 단일 CSS에 raw color 257회/131종, radius 32종, shadow 22종, font-size 73종이 남아 있다. 이 수치는 곧 131개 제품 색이라는 뜻이 아니라 alpha·gradient까지 문자열로 반복됐다는 뜻이며, Phase 2에서 토큰 계층을 만들 때의 정리 기준이다.

- 색상: 상태 색 5종과 overlay/alpha를 `--color-*` 계열로 분리하고 양 theme 값을 갖게 한다. light theme가 없는 raw dark surface가 다수다.
- 간격: `.35rem`부터 큰 page padding까지 직접 값이 반복된다. page gutter, control gap, card padding, section gap의 4계층으로 먼저 묶는다.
- 타이포그래피: page title/body/meta/control/code 역할로 축약하되 사용자가 고른 가사 글쓰기 값은 UI token과 분리한다.
- 모서리·그림자: chip/circle, control, card, sheet/dialog와 4단 elevation만 남기는 것을 목표로 한다.
- 포커스: 공통 button/link outline은 있으나 일부 input/select는 `:focus` 또는 `focus-within`만 쓴다. `--focus` 기반 `:focus-visible` 계약으로 통일한다.
- 오류: `.saved-filters select`가 정의되지 않은 `--text`를 사용한다 (`GAP-07`). `--ink` 또는 명시된 semantic token으로 교정한다.

|---|---|---|

| `GAP-06` | 해결 | Phase 4 의미 token·양 테마 대비·focus-visible·Axe serious/critical 0 |
| `GAP-08` | 해결 | Phase 3 online/offline 공급과 Phase 4 공통 상태·재시도 표현 |
| `GAP-09` | 승인된 차이 | 네 viewport 최종 접촉 시트에서 기능·정보 위계가 같고 P0/P1 붕괴가 없어 배치·밀도 차이를 허용 |

따라서 자동·시각 기준의 미해결 P0/P1은 0개다. 0.9.0 범위는 위 차이의 반응형·접근성·PWA·상태 마감에 한정하며 공유·AI·미디어 업로드·framework 교체는 포함하지 않는다.
