## 0.6.0 소비 계약

- 곡 화면은 prompt 원본을 복제하지 않고 `song_resource_links`의 동일 owner·활성 N:M 관계와 unique pair를 사용한다.
- 연결·해제는 관계만 바꾸고 prompt·song 원본과 다른 연결을 보존한다. mutation 시 session owner와 두 resource의 활성 상태를 다시 확인한다.
- 카드와 패널은 `plainText`를 Suno용 정확한 복사 값으로 사용하되, 편집 원본은 occurrence ID가 있는 Yjs sequence다.
- 곡 패널은 prompt의 favorite·pin·최근 사용을 자체 상태로 복제하지 않고 공통 resource/query 결과를 소비한다.

## 0.8.0 소비 계약

- 템플릿 적용 입력은 occurrence ID가 있는 현재 token sequence와 템플릿 token sequence이며, 출력은 새 occurrence ID를 가진 하나의 명시적 CRDT transaction이다.
- 기본 적용은 현재 내용을 덮어쓰지 않는다. 교체·앞/뒤 병합 선택과 결과 preview를 제공하고, NFKC 정규화 key가 같은 token은 첫 표시 값과 결정된 순서를 보존한다.
- 적용 전 `template_apply` 중요 revision checkpoint를 남기고 안정적 request ID로 재시도한다. 실패하면 기존 sequence와 평문 projection을 바꾸지 않는다.
- 0.8.0 전에는 템플릿 control을 활성화하지 않으며, Suno API 전송·브라우저 자동 입력은 별도 범위다.
