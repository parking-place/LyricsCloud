## 안전성 판정

- P4까지 확인된 범위에서 새 P0/P1, 원문 유실, 인증 우회, 교차 사용자 노출, 무음 저장 성공은 0건이다.
- 이 판정은 합성 자료와 자동화된 PostgreSQL·브라우저·image 회귀 범위다. 1.0.1의 실제 Google signup, Windows Chrome·Edge IME, iOS/Android update 증거를 자동화 결과로 대체하지 않는다.
- 공식 릴리스 서버의 외부 암호화 backup·24시간 RPO·복원 훈련 미구축 `OPS-100-001`은 사용자가 승인한 기존 운영 예외이며 1.0.2가 해결한 것으로 표시하지 않는다.
- P5 전체 CI 또는 동일 SHA 개발 인수가 실패하면 후보를 완료하지 않고 `review`로 남긴다.

## 후속 호환 계약

1.0.3 이후 구현은 계정별 초안 key, 저장 상태의 로컬/서버 구분, volatile 입력 이탈 guard, 가입 intent 멱등성, build별 PWA cache namespace를 보존해야 한다. 새 기능이 이 경계를 우회하면 원문 유실 또는 중복 가입 회귀로 간주하고 배포를 중단한다.
