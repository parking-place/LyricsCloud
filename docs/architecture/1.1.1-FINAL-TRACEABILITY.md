# 1.1.1 공개 링크 읽기 최종 추적

이 문서는 1.1.1 P1~P5의 `NF-REQ-034`, `NF-REQ-036` 부분 범위와 `AC-1.1.1-01`~`04`를 source·migration·검증 증거에 연결한다.

## 변경·데이터 경계

- owner가 지정한 한 가사의 제목·본문·상태·제한된 owner 표시 이름만 공개하는 256비트 capability 링크를 발급한다. raw token은 URL fragment로 한 번 전달한 뒤 탭 저장소로 옮기고 서버에는 SHA-256 digest만 저장한다.
- 공개 페이지는 same-origin 고정 POST와 read-only WebSocket만 사용한다. workspace·메모·연결 자료·다른 가사·revision·export·ACL·presence·write는 권한을 상속하지 않는다.
- 링크는 최대 30일 안에서 만료·rotation·즉시 회수할 수 있다. 만료·회수는 열린 socket과 이후 요청을 차단하고 존재 여부를 구분하지 않는 응답, no-store/noindex/no-referrer를 유지한다.
- 최신 schema는 `1110_public_lyric_read_links.sql`이며 26개 migration 이름·checksum을 `config/migrations.1.1.1.json`에 봉인한다. public write·guest identity·공동 cursor는 1.1.1에 없다.

## 수용 추적

| 기준 | 증거 | 결과 |
|---|---|---|
| `AC-1.1.1-01` | 비로그인 PC/mobile 유효 링크, 지정 필드와 live update, workspace·private API 격리 | PASS |
| `AC-1.1.1-02` | 열린 탭·REST·WebSocket 회수, offline/reconnect와 이후 owner 수정 미수신 | PASS |
| `AC-1.1.1-03` | revision·메모·연결 자료·export·public write 직접 조작, 401/403/404·4403 기본 거부 | PASS |
| `AC-1.1.1-04` | fragment 즉시 제거, digest-only DB, no-store/noindex/no-referrer, token 비로그 | PASS |

P2 후보 `571398d`는 schema·capability·owner/public API·read-only WebSocket 기반, P3 후보 `175fd74`는 PC/mobile owner·비로그인 reader 흐름, P4 제품 후보 `b920049`는 실제 DB·5-browser·offline/reconnect·만료/회수·presence 비노출·collaboration 재시작 회귀를 통과했다. P5 최종 후보는 별도 전체 CI와 동일 SHA 개발 인수로 봉인한다.

미해결 제품 P0/P1은 0건이다. 실제 OS/물리 기기는 P4/P5에서 새로 실행하지 않았고 자동화 브라우저 엔진·viewport를 실기기 증거로 확대하지 않는다. `OPS-100-001` 외부 backup 예외는 사용자 승인대로 열려 있다. `NF-REQ-036`의 selected/public write와 guest identity·공동 cursor는 1.1.2~1.1.4가 담당한다.
