## 안전성·후속 계약

- 보기 설정은 창작물 본문과 분리된 owner-only 설정이며 API 검사와 RLS를 함께 적용한다.
- P4까지 확인한 범위에서 새 P0/P1, 원문 유실, 인증 우회, 교차 owner 노출, 무음 저장 실패는 0건이다.
- 실제 물리 기기는 새로 실행하지 않았고 `OPS-100-001` 외부 backup 예외는 유지한다.
- 1.0.8의 사용자 지정 정렬은 보기 모드와 별도 설정으로 추가하고 1.0.7의 필터·순서 불변 및 owner 격리를 회귀로 유지한다.
- P5는 같은 후보 SHA의 네 dev image 게시·서명과 동일 SHA 개발 인수에서 공개 live/ready, 보기 저장 및 web·collaboration·worker 재시작 뒤 지속성을 확인하고 합성 자료를 제거했다.
