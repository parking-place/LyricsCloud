## 다음 버전 소비 계약

### 0.5.0 프롬프트

- 공통 `resources`의 owner, 제목, pin, favorite, color, row version, timestamps와 soft delete 규칙을 재사용한다.
- 목록은 문자 그대로 검색·URL 상태·cursor·loading/empty/no-result/error·낙관적 명령 queue를 같은 패턴으로 구현한다.
- 태그와 곡 N:M 관계는 기존 테이블을 재사용하되 prompt subtype과 owner 복합 FK를 migration으로 명시한다.
- 프롬프트 본문도 순수 텍스트로 취급하고 사용자 내용을 로그나 관측 label에 넣지 않는다.

### 0.6.0 통합 작업 화면

- [PROD-0006](../product/PROD-0006-rhyme-lyric-insertion.md)의 `RhymeInsertionRequest` version 1을 변경 없이 소비한다.
- 열린 가사 target lifecycle은 화면이 소유하고, 명령 시점에 source/target resource·sync document가 활성·동일 owner인지 서버가 다시 검증한다.
- source 선택과 target cursor는 절대 offset이 아닌 Yjs relative position으로 해석하며, 삽입은 멱등 request ID를 가진 하나의 CRDT transaction·undo 단위다.
- `no_open_target`, `target_deleted`, `target_changed`는 가사 변경 없이 끝나며 선택 복사와 수동 복사 대안을 유지한다.

실제 가사 cursor 삽입은 0.4.0 범위가 아니며 0.6.0 전에는 활성화하지 않는다.
