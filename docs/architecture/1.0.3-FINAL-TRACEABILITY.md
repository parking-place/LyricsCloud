# 1.0.3 프롬프트 mode/raw 후보 추적

이 문서는 1.0.3 P1~P5가 다룬 `NF-REQ-022`의 mode/raw 부분과 수용 사례를 source·migration·검증 증거에 연결한다. `NF-REQ-022` 전체의 ASCII 마침표별 카드 표시는 1.0.4 책임이며, 이 문서는 1.0.3 main 병합·tag·정식 image·릴리스 서버 승인을 뜻하지 않는다.

## 변경·검증 경계

- domain/API/store: `packages/domain/src/prompt-contract.ts`, `packages/database/src/prompts.ts`, web prompt API routes.
- CRDT/editor: `packages/editor/src/prompt-crdt.ts`, `prompt-browser-sync.ts`, collaboration store/server.
- UI: prompt 신규·편집·목록·템플릿과 공통 prompt 출력 소비자.
- 검증: 관련 unit/integration, migration 1000 verifier, `tests/e2e/new-feature-1.0.3.spec.ts`, 전체 E2E, production build와 개발 공개 smoke.
- 환경: `config/environment-schema.1.0.3.json`은 1.0.3 candidate의 여섯 서비스와 secret-file 경계를 검사한다. 봉인된 1.0.2 release artifact와 checksum은 변경하지 않는다.

## 안전성·후속 계약

- P5까지 확인된 범위에서 새 P0/P1, 원문 유실, 인증 우회, 교차 사용자 노출, 무음 저장 실패는 0건이다. 전체 CI와 동일 SHA 개발 공개 smoke가 이 판정을 확정했다.
- 실제 Google 가입·Windows Chrome/Edge IME·iOS/Android update의 이전 사용자 인수는 보존하며 자동 WebKit/Chromium 결과로 대체하지 않는다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련 미구축은 사용자가 승인한 운영 예외로 남는다.
- 1.0.4는 raw를 바꾸지 않는 ASCII `.` 표시 카드와 별도 길이 advisory를 추가해야 한다. 1.0.3의 capability guard, mode/raw schema, 명시 변환, revision·복제·owner 격리를 우회하면 회귀로 간주한다.
