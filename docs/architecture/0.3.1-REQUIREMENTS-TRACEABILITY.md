## Phase 5 통합 근거와 남는 인수 항목

새 인증·장애 회귀와 저장 상태별 영속화 대조는 [Phase 5 로컬 검증](../runbooks/0.3.1-phase5-local-validation.md)을 따른다. `logout-drafts.spec.ts`는 계정 전환·세션 만료·미전송 초안·변조한 로컬 key·명시적 삭제·여러 탭 로그아웃을 검증한다. `lyric-durability.spec.ts`는 실제 projection 실패와 UI 표시를 대조한다. `lyric-sync-resilience.spec.ts`는 PC 두 탭과 별도 모바일 browser context를 통합하고 10만 자 입력을 측정한다. `verify-production-recovery.mjs`는 최종 이미지의 실제 DB·서비스 재시작과 pending projection·재전송·복원을 검증한다.

물리 모바일·OS 한글 IME·가상 키보드·서로 다른 네트워크는 Chromium 화면/합성 composition 검증과 구분한다. 오프라인 cold start는 Phase 2 제외 범위이며 0.9.0 PWA 항목이다. ADR-0005에는 binding과 presence의 현행 구현 대조를 덧붙였으며 라이브러리를 교체하지 않았다. 원격 Phase 완료는 별도 증거가 필요하다.
