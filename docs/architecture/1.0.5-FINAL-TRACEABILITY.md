## 안전성·후속 계약

- 저장·CRDT·schema·권한을 바꾸지 않는 표시·복사 projection이며 다른 계정 API/화면 비노출을 유지한다.
- P4까지 확인한 범위에서 새 P0/P1, 원문 유실, 인증 우회, 교차 사용자 노출, 무음 저장 실패는 0건이다.
- 실제 Windows/iOS/Android 물리 입력은 이번 후보에서 새로 수행하지 않았으며 자동 엔진 결과로 대체하지 않는다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련 미구축은 사용자가 승인한 운영 예외로 남는다.
- 1.0.6의 Extend·추천 삽입은 이 버전에 포함하지 않으며, 첫 콜론 주 이름·lossless suffix·비차단 copy 계약을 소비해야 한다.
- P5 동일 SHA 개발 인수에서 공개 live/ready, 네 서비스 health, suffix·주 이름 탐색·3,001자 exact copy, collaboration 재시작 뒤 원문 보존을 다시 확인했고 합성 자료를 제거했다.
