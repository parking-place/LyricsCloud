# 1.0.14 자체 호스팅 웹폰트 최종 추적

이 문서는 1.0.14 P1~P5의 `NF-REQ-044`, `AC-1.0.14-01`~`05`와 남은 외부 gate를 source·검증 증거에 연결한다.

## 변경·데이터 경계

- Noto Sans KR 2.004 Regular OTF와 OFL 1.1 전문을 같은 origin에 번들하고 hash 경로·1년 immutable cache·`font-display: swap`을 적용했다.
- `1004_web_font_selection.sql`은 기존 계정/가사 표시 설정의 허용값에 `noto_sans_kr`만 추가한다. owner RLS·CAS·기존 값·창작 원문은 유지하고 rollback은 새 선택값만 `sans`로 변환한다.
- 계정 기본값과 가사별 override를 서버에 영속하며 가사·라임·프롬프트 편집기는 동일 CSS family/fallback을 소비한다. CodeMirror·CRDT·textarea를 재생성하지 않는다.
- 최신 schema는 `1004_web_font_selection.sql`이며 24개 migration의 이름과 checksum을 `config/migrations.1.0.14.json`에 봉인한다.
- 외부 CDN·원문 외부 전송·추가 weight·동적 subset·1.0.13 사전 우회는 없다.
