## 안전성·후속 계약

- 저장 schema·API·owner 권한을 바꾸지 않는 copy projection과 인증된 문서의 CRDT insertion이며 다른 계정 API/화면 비노출을 유지한다.
- P4까지 확인한 범위에서 새 P0/P1, 원문 유실, 인증 우회, 교차 사용자 노출, 무음 저장 실패는 0건이다.
- 실제 Windows/iOS/Android 물리 입력은 이번 후보에서 새로 수행하지 않았으며 자동 엔진 결과로 대체하지 않는다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련 미구축은 사용자가 승인한 운영 예외로 남는다.
- 1.0.7은 곡·라임·프롬프트 목록 보기/밀도 개인 설정을 별도 계약으로 시작하며 1.0.6의 raw 보존·상대 위치·IME/undo 경계를 회귀로 유지해야 한다.
- P5는 전체 CI·네 dev image와 같은 SHA의 공개 live/ready·revision/export·collaboration 재시작을 확인했고 합성 자료를 제거했다.
