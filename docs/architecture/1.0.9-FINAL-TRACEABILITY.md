## 안전성·후속 계약

- 공유 조회의 text projection 별칭이 numeric rank 정렬을 가로채던 결함을 qualified 열 정렬과 연속 이동 실제 DB 회귀로 닫았다.
- P4까지 신규 P0/P1, 원문 유실, 인증 우회, 교차 owner 노출, 무음 저장 실패는 0건이다.
- 실패한 낙관 이동은 이전 목록으로 원복하고 명시 재시도를 제공하며 stale 응답은 최신 서버 상태를 다시 읽는다.
- 실제 Windows/iOS/Android 물리 입력은 새로 실행하지 않았고 `OPS-100-001` 외부 backup 예외는 유지한다.
- P5는 같은 후보 SHA의 전체 CI·네 dev image 게시/서명과 동일 SHA 개발 인수를 통과한 뒤 정식 릴리스로 이동한다.
- 1.0.10은 수동 Suno 모델명과 여러 링크 metadata를 다루며 1.0.9 순서·원문·권한 계약을 변경하지 않는다.
