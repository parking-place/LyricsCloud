## DB·CI·개발 경계

새 웹 DB, populated a DB, 기존 native 1150+1151 DB를 일회용으로 검사했고 `1152_prompt_dictionary_cascade.sql`을 순방향 적용·반복했다. 복원 DB의 계정 cascade 오류를 보정하되 기존 migration checksum과 native 객체는 보존했다. a 및 native 포함 이전 웹 image의 application-first rollback에서 b 작성 원문·사진·export를 확인했다. 실제 PC 설치물이나 개발 서버 live downgrade는 실행하지 않았다.

P4 push Actions [35990242886](https://github.com/parking-place/LyricsCloud/actions/runs/35990242886)의 verify·네 signed image/provenance, PR Actions [35991662815](https://github.com/parking-place/LyricsCloud/actions/runs/35991662815)의 verify가 SUCCESS다. 격리 DB Vitest 509 PASS/8 조건부 skip, production Chromium 432 PASS/54 조건부 skip, 교차 엔진 20 PASS다. 같은 SHA 개발 서버의 공개 ready는 `1.1.7b/dev/p4`·schema 1152, PC/mobile 합성 prompt 저장·재조회·타 계정 404, 서비스 재시작 뒤 원문 영속 PASS다. 공개 edge의 변동 XFF 제한 429와 Cloudflare의 위조 CF-IP 거부 403은 별개 증거다.

P5의 `동일 SHA 개발 인수`는 새 최종 기능 SHA를 확정한 뒤 별도 수행한다. 정식 tag `v1.1.7b`, `main` 병합, 릴리스 서버, Release/latest image는 승인·실행되지 않았다. `OPS-100-001` 외부 backup/RPO 예외는 잠금 코드 보정과 별개이며 24시간 RPO를 보장하지 않는다. 외부 Google 장애, 실제 Windows/iOS/Android·OS IME·AT, 운영 backup/timer·릴리스 proxy는 PASS로 기록하지 않는다.
