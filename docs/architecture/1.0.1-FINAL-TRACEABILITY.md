## 열린 예외와 즉시 중단 조건

`OPS-100-001` 공식 릴리스 host의 외부 암호화 backup·일일 timer·24시간 RPO·실제 복원 훈련은 사용자의 현재 위험 승인 예외로 열린다. 이는 격리 restore PASS로 닫히지 않는다. 인증 우회, 교차 owner 노출, 저장 후 재진입 손실, migration/schema 불일치, image signature·digest 불일치가 발견되면 P0/P1 0 판정을 취소하고 tag 승격·운영 배포를 중단한다.
