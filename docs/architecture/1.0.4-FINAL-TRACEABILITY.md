## 안전성·후속 계약

- 저장·CRDT·schema·권한을 바꾸지 않는 순수 표시 projection이며 다른 계정 API/화면 비노출을 유지한다.
- P4까지 확인한 범위에서 새 P0/P1, 원문 유실, 인증 우회, 교차 사용자 노출, 무음 저장 실패는 0건이다. P5 전체 CI와 동일 SHA 개발 인수 뒤 후보 판정을 확정한다.
- 실제 Windows/iOS/Android 물리 입력은 이번 후보에서 새로 수행하지 않았으며 자동 엔진 결과로 대체하지 않는다.
- `OPS-100-001` 외부 암호화 backup·24시간 RPO·복원 훈련 미구축은 사용자가 승인한 운영 예외로 남는다.
- 1.0.5는 가사 최종 copy 3,000자 안내와 `[TAG:sub tag]` 표시·탐색을 추가하되 1.0.4의 공통 payload·비차단·원문 보존 계약을 유지한다.
