## 안전성·후속 계약

- 사용자정렬은 owner와 `song` 자료 유형에 묶인 별도 rank이며 본문·핀·보기 설정을 덮어쓰지 않는다.
- P4까지 신규 P0/P1, 원문 유실, 인증 우회, 교차 owner 노출, 무음 저장 실패는 0건이다.
- 실패한 낙관 이동은 이전 목록으로 원복하고 재시도 안내를 제공하며 stale 응답은 최신 서버 상태를 다시 읽는다.
- 실제 물리 기기는 새로 실행하지 않았고 `OPS-100-001` 외부 backup 예외는 유지한다.
- P5는 같은 후보 SHA의 네 dev image 게시·서명과 동일 SHA 개발 인수를 통과했으며 공개 desktop/mobile 이동·reload·manual URL·overflow 검증 뒤 합성 자료를 제거했다.
- 1.0.9는 같은 계약을 라임·프롬프트로 확장하되 곡 order state나 rank를 공유하지 않는다.
