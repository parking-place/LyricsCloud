## 범위와 source

- 요구: `NF-REQ-037`, `NF-REQ-039`.
- 승인 입력: UX P5의 B-1 통합 workspace + Flat-depth와 `LC_UI_VARIANT=classic|b1` rollback 계약.
- 제품 source: P4 후보 `25d71022184c4873d97bd432d3f31a53e803bb60`; P5 최종 후보 `7f4ac5bad29d910a26e5256e9714cd3b94a49015`.
- 변경 경계: 가사·라임·프롬프트 편집기, 자료 패널, 생성·연결, 가입·공유·복구 surface와 회귀/문서다. API·DB·migration·공유 capability·copy payload는 변경하지 않는다.

## 봉인 경계

- 최신 schema는 `1140_sharing_stability.sql`이며 29개 migration 이름·checksum을 `config/migrations.1.1.6.json`에 봉인한다.
- release 환경은 `APP_VERSION=1.1.6`, `APP_CHANNEL=release`, `LC_UI_VARIANT=b1`이고 `APP_PHASE`를 두지 않는다.
- P1~P5에서 확인된 신규 P0/P1·원문 유실·인증 우회·무음 저장 실패는 0건이다. P5 두 CI·네 signed dev image·동일 SHA 개발 공개/재시작 인수를 완료했다.
- 실제 Windows/Linux/macOS/Android/iOS 물리 기기, 실제 OS IME·screen reader·200% OS zoom은 새로 실행하지 않았으며 Linux browser engine 자동화로 대신하지 않는다.
- 외부 독립 backup·24시간 RPO는 사용자 승인 예외 `OPS-100-001`로 계속 열려 있다.

## P5 및 후속 인계

P5는 요구·환경·migration·license·release manifest와 사용자/지원/보안/자가호스팅 문서를 같은 후보에 봉인하고 최종 CI·네 dev image·동일 SHA 개발 인수를 완료했다. push/PR Actions는 `34864142932`·`34864188502`이고 네 개발 image tag와 Sigstore referrer, `1.1.6/dev/p5` 공개 생성/연결·저장 재진입·서비스 재시작을 확인했다. 정식 릴리스 후 1.1.7은 같은 CodeMirror/store/API/DB·B-1 더보기/탐색과 classic rollback을 유지한 채 승인 디자인의 남은 화면 범위만 소비한다.
