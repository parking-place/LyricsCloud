## 안전성·후속 계약

- 세 목록의 pin group·manual rank·button/drag 의미는 그대로이며 계산만 item별 전체 scan에서 공통 O(n) map으로 바뀐다. 중복 ID는 거부한다.
- 가사 CRDT 원문, 문장형 prompt raw, copy/export, Suno 수동 모델·링크, owner/RLS·CAS·idempotency, 삭제·복원 계약은 변경하지 않는다.
- P4까지 신규 제품 P0/P1, 원문 유실, 인증 우회, 교차 owner 노출, 무음 저장 실패는 0건이다.
- `NF-REQ-032` 자동 Suno metadata는 1.0.11 provider no-go로 미완료이며 scraping으로 우회하지 않는다.
- 실제 Windows/iOS/Android 물리 입력은 새로 실행하지 않았고 `OPS-100-001` 외부 backup 예외는 유지한다.
- P5 전체 CI와 동일 SHA 개발 인수 완료 전에는 정식 릴리스 완료로 보지 않는다.
