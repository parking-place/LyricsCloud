- 요구: `NF-REQ-037`, `NF-REQ-039`.
- 승인 입력: UX P5의 B-1 통합 workspace + Flat-depth와 `LC_UI_VARIANT=classic|b1` rollback 계약.
- 제품 source: P4 후보 `8fb03becfe27a95f019defb4cbdfee10b55f6812`; P5 최종 후보 SHA는 CI 완료 기록에 고정한다.
- 변경 경계: 공통 shell·context header·rail/mobile navigation·flat surface와 회귀/문서. API·DB·migration·공유 capability는 변경하지 않는다.

## 봉인 경계

- 최신 schema는 `1140_sharing_stability.sql`이며 29개 migration 이름·checksum을 `config/migrations.1.1.5.json`에 봉인한다.
- release 환경은 `APP_VERSION=1.1.5`, `APP_CHANNEL=release`, `LC_UI_VARIANT=b1`이고 `APP_PHASE`를 두지 않는다.
- 다섯 Phase에서 확인된 신규 P0/P1·원문 유실·인증 우회·무음 저장 실패는 0건이다. P5 전체 CI·동일 SHA 개발 인수 전에는 최종 판정을 완료하지 않는다.
- 실제 Windows/Linux/macOS/Android/iOS 물리 기기, 실제 OS IME·screen reader·200% OS zoom은 새로 실행하지 않았으며 Linux browser engine 자동화로 대신하지 않는다.
- 외부 독립 backup·24시간 RPO는 사용자 승인 예외 `OPS-100-001`로 계속 열려 있다.

## P5 및 후속 인계

P5는 요구·환경·migration·license·release manifest와 사용자/지원/보안/자가호스팅 문서를 같은 후보에 봉인하고 최종 CI·네 dev image·동일 SHA 개발 인수를 수행한다. 정식 릴리스 후 1.1.6은 같은 child/store/API/DB와 classic rollback을 유지한 채 다음 승인 디자인 적용 범위만 소비한다.
