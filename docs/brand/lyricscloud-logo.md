# LyricsCloud 주 로고와 아이콘

상태: 1.0.1 Phase 7 승인 자산

## 선택 기록

2026-09-10에 기존 `lyricscloud-192-0903.svg`와 `lyricscloud-512-0903.svg`의 `L`과 음표 점 조합을 주 로고 후보로 검토해 채택했다. 이미 제품에 사용하던 형태를 유지하므로 사용자가 앱을 다시 식별할 수 있고, 새 외부 자산이나 글꼴에 의존하지 않는다. 기존 2026-09-03 원본 파일은 비교와 이력 보존을 위해 수정하지 않는다.

| 용도 | 자산 | 기준 |
|---|---|---|
| 밝은 화면 | `lyricscloud-mark-light.svg` | 짙은 바탕과 acid 문자 |
| 어두운 화면 | `lyricscloud-mark-dark.svg` | acid 바탕과 짙은 문자 |
| 작은 favicon | `lyricscloud-favicon.svg` | 16~32px에서도 `L`과 점 분리 |
| PWA maskable | `lyricscloud-maskable.svg` | 핵심 문양을 중앙 safe area 안에 배치 |
| 단색 출력 | `lyricscloud-monochrome.svg` | 색 없이도 외곽과 문양 구분 |

접근성 이름은 `LyricsCloud`다. 화면에서는 아이콘을 장식 이미지로 처리하고, 보이는 `LYRICS CLOUD` 문자와 build label을 합친 브랜드 컨테이너에 이름을 한 번만 제공한다.

## 출처와 사용권

도형과 변형 자산은 이 저장소에서 직접 작성한 LyricsCloud 제품 자산이다. 외부 이미지, 상표, 아이콘 묶음 또는 생성형 이미지 결과를 포함하지 않는다. 저장소에는 별도 공개 라이선스가 없으므로 외부 재사용 권한을 자동으로 부여하지 않으며, 배포물 안의 LyricsCloud 식별 용도로만 관리한다.

전면 morphism 시안과 애니메이션은 이 로고 승인과 분리된 후속 UX 작업이다.
