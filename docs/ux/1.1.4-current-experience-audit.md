## viewport·keyboard·접근성 관찰

- 320/360/390px, 768px, 좁은 PC, 1440px에서 주 navigation과 곡 조작은 reachable 판정을 통과했다. 390px 회전과 Chromium/WebKit sheet 개폐 중 한글 합성 초안 보존도 통과했다.
- 15개 화면의 light/dark Axe serious/critical, dialog focus trap/Escape/trigger 복귀, empty/server error/offline/permission 구분, 200% root font reflow를 통과했다.
- global shortcut는 입력/IME 중 가로채지 않고, 도움말·검색·새 가사 이동 뒤 draft/cursor/copy fallback을 보존했다.
- 직접 캡처에서는 390px 가사 editor의 9개 도구 dock label이 여러 줄과 세로 글자 수준으로 압축된다. 기능은 reachable하지만 현재 행동의 이름을 빠르게 스캔하기 어렵고 editor 본문·저장 상태보다 dock이 큰 시각 잡음을 만든다. 1.1.5의 최우선 shell/editor 경계 과제다.
- mobile 곡 dashboard는 가사·Suno·연결 자료·메모·삭제가 긴 단일 열로 이어져 현재 창작 단계와 위험 행동 사이 이동 거리가 크다. PC는 좌측 rail과 상단 workspace tab에 동일 destination이 반복되고 editor 상단 보조 행동 밀도가 높다.
- 실제 NVDA/VoiceOver/TalkBack 탐색 순서·발화, 물리 touch target, 실제 iOS/Android safe-area/keyboard, 실제 OS 200% zoom은 미실행이다. 자동 Axe와 CSS font-size 200%를 실제 보조기기 PASS로 확대하지 않는다.

## 유지할 브랜드·기능 계약

- 1.0.1 LyricsCloud mark·wordmark·acid accent·light/dark 자산과 접근성 이름을 입력으로 유지한다. 로고 교체는 별도 승인 대상이다.
- URL/deep link, owner·actor·resource·capability/epoch 권한, API/DB schema, exact-copy, 저장/CRDT/outbox/rejected draft, history/undo, account-scoped local cache를 바꾸지 않는다.
- shell이나 panel을 바꿔도 CodeMirror/Yjs editor를 재마운트하지 않고 IME composition·selection·undo·미전송 초안을 보존한다.
- 저장/오프라인/동기화/회수는 색상만으로 표현하지 않고 짧은 문장·icon/label·복구 행동을 함께 제공한다.
